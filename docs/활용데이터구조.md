## 11. `video_file_name` — 원천 비디오 파일 매핑 (확장 필드)

> **AI Hub 원본 사양에는 없는 프로젝트 확장 필드.**
> 본 프로젝트에서는 `data/toy-data/*.json` 라벨링과 `data/toy-video/*.mp4` 영상을 연결하기 위해 추가한다.

### 11.1 매핑 규칙

JSON 파일에는 **동일 비디오에서 추출된 여러 프레임(시도번호)**에 대한 라벨이 들어 있다.
시도번호 슬롯(`{attempt}`)을 `00`으로 치환하면 해당 원천 비디오 파일명이 된다.

```
JSON  : {prefix}_{idx5}_{attempt}_{YYYYMMDD}.json    # attempt ∈ {01, 02, 03, ...}
VIDEO : {prefix}_{idx5}_00_{YYYYMMDD}.mp4            # attempt 자리가 항상 00
```

> ⚠️ **N:1 관계** — 시도번호가 다른 여러 JSON이 같은 비디오 1개를 가리킨다.
> 데이터로더에서 join 시 비디오가 attempt 수만큼 중복 로드되지 않도록 캐싱/dedup이 필요하다.

### 11.2 변환 예시

| JSON 파일명 | 매핑된 video_file_name |
|---|---|
| `반려동물용품_CR01_강아지공룡알장난감_00018_01_20230923.json` | `반려동물용품_CR01_강아지공룡알장난감_00018_00_20230923.mp4` |
| `반려동물용품_CR01_강아지공룡알장난감_00018_03_20230923.json` | `반려동물용품_CR01_강아지공룡알장난감_00018_00_20230923.mp4` |
| `반려동물용품_CR01_강아지공룡알장난감_00262_02_20230923.json` | `반려동물용품_CR01_강아지공룡알장난감_00262_00_20230923.mp4` |
| `반려동물용품_CR01_강아지공룡알장난감_00262_03_20230923.json` | `반려동물용품_CR01_강아지공룡알장난감_00262_00_20230923.mp4` |
| `반려동물용품_CR02_강아지공룡알장난감_00021_02_20230919.json` | `반려동물용품_CR02_강아지공룡알장난감_00021_00_20230919.mp4` |

### 11.3 변환 정규식 / 의사코드

**정규식 치환:**

```regex
s/_(\d{5})_\d{2}_(\d{8})\.json$/_$1_00_$2.mp4/
```

**TypeScript 의사코드:**

```ts
function jsonToVideoFileName(jsonName: string): string {
  return jsonName.replace(
    /_(\d{5})_\d{2}_(\d{8})\.json$/,
    '_$1_00_$2.mp4',
  );
}
```
