## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 40, `payload.schema.drift`) payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) ← 트립 앵커 → 현재 검증 로직과 고정 컬럼 구조가 신규 키를 허용하지 않아 매핑 중단 및 필드 유실을 유발 [corr:5e762361-be8d-4c27-88ca-7464f08e34bd]
- src/insert/dto/toy-data.dto.ts의 toyDataSchema는 .passthrough() 없이 정의되어 있어, 이벤트 payload에 정의되지 않은 키가 포함되면 Zod 검증이 실패하거나 키를 제거함.
- src/projection/projector/grip-result.projector.ts와 multimodal.projector.ts의 map() 메서드에서 toyDataSchema.parse(event.payload)를 호출하며, 검증 실패 시 throw err로 투영을 중단함.
- src/shared/database/schema/service/read-grip-result.ts와 read-multimodal.ts의 Drizzle 스키마는 고정 컬럼만 정의되어 있어, 신규 키를 수용할 물리적 저장 공간(컬럼)이 부재함.
- 로그의 payload.schema.drift는 적재 단계에서 이미 스키마 불일치를 감지했으나, Read Model 투영 로직이 이를 유연하게 처리하지 못해 데이터 유실로 이어졌음.

### Decision Drivers
- 데이터 무결성 유지 (신규 키 유실 방지 및 투영 성공 보장)
- 스키마 확장성 (미래 키 변화에 대한 유연한 대응)
- 재투영 비용/리스크 (기존 데이터 호환성 및 마이그레이션 부담)

### Considered Options
#### Read Model 메타데이터 JSONB 컬럼 추가 (수용성 중심)
- 접근: read_grip_result와 read_multimodal Drizzle 스키마에 metadata: jsonb("metadata") 컬럼 추가. Zod 스키마를 .passthrough()로 변경하여 신규 키를 유지하고, 프로젝트터 map에서 알려진 필드 매핑 후 나머지 키를 metadata 객체에 할당.
- 제안 필드: read_grip_result.metadata, read_multimodal.metadata
- 트레이드오프: 재투영 시 과거 이벤트의 신규 키도 메타데이터로 보존 가능. 조회 쿼리에서 메타데이터 내 특정 키 필터링 시 GIN 인덱스 추가 필요. 스키마 변경 리스크 최소화.
```typescript
const extendedSchema = toyDataSchema.passthrough(); try { const payload = extendedSchema.parse(event.payload); return { ...baseRow, metadata: Object.fromEntries(Object.entries(payload).filter(([key]) => !KNOWN_KEYS.includes(key))) }; } catch (error) { logger.error({ action: LogAction.MAP_FAILED, error }, "이벤트 매핑 실패"); throw error; }
```

#### 필드별 명시적 확장 (정규화 중심)
- 접근: 도메인 요구사항에 따라 신규 키의 용도가 명확해지면, Read Model 스키마에 해당 컬럼 추가 및 프로젝트터 map에서 직접 매핑. Zod 스키마는 .passthrough() 유지하되 신규 키 타입 정의 추가.
- 제안 필드: read_grip_result.new_field_1, read_multimodal.new_field_2
- 트레이드오프: 쿼리 성능 최적화 및 타입 안전성 유지 유리. 키가 계속 유입되면 스키마 변경 빈도 높아지고 마이그레이션 비용 발생.
```typescript
const extendedSchema = toyDataSchema.extend({ new_field_1: z.string().optional() }); try { const payload = extendedSchema.parse(event.payload); return { ...baseRow, newField1: payload.new_field_1 }; } catch (error) { logger.error({ action: LogAction.MAP_FAILED, error }, "이벤트 매핑 실패"); throw error; }
```

### Decision Outcome
Read Model 메타데이터 JSONB 컬럼 추가 (수용성 중심)

### Consequences
- (+) 신규 키 유입 시 Read Model 투영 중단 방지
- (+) 메타데이터를 통해 모든 이벤트 데이터 보존 가능
- (−) 메타데이터 컬럼 조회 시 인덱스 관리 필요
- (−) 특정 필드만 필터링하는 쿼리 성능이 JSONB 연산에 따라 변동 가능

### Non-Goals
- Event Store 원본 스키마 변경
- 실시간 검증 로직의 대폭 재설계
- 기존 Read Model 컬럼명 변경

### 마이그레이션 절차

- 하위호환 변경: 기존 v1 테이블(read_grip_result) 및 엔드포인트(/projection/grip-result, /projection/insert-all)는 변경 없음; v2 프로젝트는 독립적인 테이블과 프로젝터 name(grip-result-v2-projector)을 사용하므로 기존 CatchUpRunner 파이프라인과 충돌 없음
- 파괴적 변경: 없음
- 컷오버 전 테스트: 1. v2 프로젝터 실행 후 read_grip_result_v2 테이블의 row count가 v1과 일치하는지 확인
2. payload_snapshot 컬럼에 신규 키가 정상적으로 직렬화되어 저장되었는지 JSON 구조 검증
3. /v2/grip-result 엔드포인트 호출 시 200 OK 응답 및 처리된 ProjectionResult 확인
4. 기존 /projection/grip-result 엔드포인트가 여전히 v1 데이터를 정상 투영하는지 병렬 검증
- 롤백 창/조건: 컷오버 전 v2 테이블에 대한 쓰기 트래픽이 발생하지 않도록 라우팅을 v1로 유지. 문제가 감지될 경우 /v2/grip-result 엔드포인트 비활성화 및 read_grip_result_v2 테이블 DROP. 기존 v1 서비스/컨트롤러 코드는 수정되지 않았으므로 즉시 정상화됨.
- Insight 카드 등록: §2의 카드 등록 SQL을 DDL과 함께 적용(카탈로그 동기화)

### 사유·호환성

- 사유: 기존 v1 프로젝트는 payload의 명시적 필드만 추출하여 Read Model에 매핑하므로, 이벤트 스키마 드리프트 발생 시 신규 키가 유실됩니다. v2는 원천 payload를 payload_snapshot 컬럼에 보존하여 스키마 진화 시 데이터 무결성을 보장합니다.
- 트리거 근거: | 06:16:51.938 | 40 | payload.schema.drift | 5e762361-be8d-4c27-88ca-7464f08e34bd | payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) ← 트립 앵커 |
- v1 호환성: v1 테이블(read_grip_result)과 v2 테이블(read_grip_result_v2)은 독립적으로 존재하며, 기존 API/프로젝터는 변경되지 않습니다. v2는 신규 엔드포인트(/v2/grip-result)로 독립 실행됩니다.

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripContext } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripContextInsert = InferInsertModel<typeof readGripContext>;

@Injectable()
export class GripContextProjector implements Projector<ReadGripContextInsert> {
  readonly name: string = "grip-context-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripContextProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripContextInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      dataKey: payload.data_key,
      boxType: payload.box_type,
      cameraName: payload.camera_info.camera_name,
      cameraType: payload.camera_info.camera_type,
      cameraIntrinsicParam: payload.camera_info.camera_intrinsic_param,
      image3dFileName: payload["3D_image_file_name"],
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripContextInsert): Promise<void> {
    await tx
      .insert(readGripContext)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripContext.sceneKey, readGripContext.attemptNum],
        set: {
          dataKey: row.dataKey,
          boxType: row.boxType,
          cameraName: row.cameraName,
          cameraType: row.cameraType,
          cameraIntrinsicParam: row.cameraIntrinsicParam,
          image3dFileName: row.image3dFileName,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```

```typescript
      attemptNum: event.attemptNum,
      objectName: payload.objects[0].class_name,
      gripSucceed: payload.grip_succeed,
      gripperType: "finger",
      occurredAt: event.occurredAt,
      grip2dPose: payload.grip_data.grip_2d_pose,
      grip3dPose: payload.grip_data.grip_3d_pose,
      robotTf: payload.robot_tf,
      humanAnnotationGrasp: payload.human_annotation_grasp,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
      payloadSnapshot: event.payload as Record<string, unknown>,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripResultV2Insert): Promise<void> {
    await tx
      .insert(readGripResultV2)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripResultV2.sceneKey, readGripResultV2.attemptNum],
        set: {
          objectName: row.objectName,
          gripSucceed: row.gripSucceed,
          gripperType: row.gripperType,
          occurredAt: row.occurredAt,
          grip2dPose: row.grip2dPose,
          grip3dPose: row.grip3dPose,
          robotTf: row.robotTf,
          humanAnnotationGrasp: row.humanAnnotationGrasp,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
          payloadSnapshot: row.payloadSnapshot,
        },
      });
  }

  toSensorValueMessages(rows: ReadGripResultV2Insert[]): SensorValueMessage[] {
    return rows.map((row) => ({
      sceneKey: row.sceneKey,
      attemptNumber: row.attemptNum,
      streamId: row.streamId,
      globalSequence: row.globalSeq,
      occurredAt: row.occurredAt.toISOString(),
      objectName: row.objectName,
      gripSucceed: row.gripSucceed,
      grip2dPose: row.grip2dPose,
      grip3dPose: row.grip3dPose,
      robotTf: row.robotTf,
      humanAnnotationGrasp: row.humanAnnotationGrasp,
    }));
  }
```

```typescript
import { Injectable } from '@nestjs/common';
import { PinoLogger } from 'nestjs-pino';
import { InsertResult, InsertService } from '@/insert/insert.service';
import { GripResultProjector } from '@/projection/projector/grip-result.projector';
import { GripResultV2Projector } from '@/projection/projector/grip-result-v2.projector';
import { MultiModalProjector } from '@/projection/projector/multimodal.projector';
import { ProjectionResult } from '@/projection/projector/projector';
import { CatchUpRunner } from '@/projection/runner/catch-up.runner';
import { LogAction } from '@/shared/logger/logging-context';

export type CatchUpAllResult = {
  multimodal: ProjectionResult;
  gripResult: ProjectionResult;
  gripResultV2: ProjectionResult;
};

export type InsertAndProjectionAllResult = {
  insert: InsertResult;
  projection: CatchUpAllResult;
};

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly gripResultV2: GripResultV2Projector,
    private readonly insertService: InsertService,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  catchUpMultimodal(): Promise<ProjectionResult> {
    return this.runner.run(this.multimodal);
  }

  catchUpGripResult(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResult);
  }

  catchUpGripResultV2(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResultV2);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();
    const gripResultV2: ProjectionResult = await this.catchUpGripResultV2();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult, gripResultV2 };
  }

  async insertAllAndProjectAll(): Promise<InsertAndProjectionAllResult> {
    this.logger.info(
      { action: LogAction.PROJECTION_START },
      "전체 적재+투영 시작",
    );

    const insert: InsertResult = await this.insertService.insertToyData();
    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
}
```
