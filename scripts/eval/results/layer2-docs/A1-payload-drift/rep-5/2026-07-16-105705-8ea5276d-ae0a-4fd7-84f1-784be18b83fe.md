## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 40, `payload.schema.drift`) payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) ← 트립 앵커 → 이벤트 페이로드에 기존 도메인 스키마와 Read Model 컬럼으로 정의되지 않은 신규 키가 포함되어, 투영 파이프라인이 해당 필드를 인식하지 못해 데이터가 유실됨을 나타냄. [corr:8ea5276d-ae0a-4fd7-84f1-784be18b83fe]
- src/insert/dto/toy-data.dto.ts의 toyDataSchema는 Zod로 엄격하게 정의되어 있어, 정의되지 않은 키가 유입될 경우 검증 실패 또는 드리프트 경고로 이어지며, 현재 read_grip_result와 read_multimodal 테이블에는 해당 신규 키를 담을 컬럼이 부재함.
- src/projection/projector/multimodal.projector.ts의 map() 메서드에서 image2dUri와 videoUri 필드를 명시적으로 null로 할당하고 있으며, 이는 기존 Read Model이 미디어 URI 매핑 로직을 아직 구현하지 않았음을 보여줌.
- src/shared/database/schema/service/read-multimodal.ts와 read-grip-result.ts는 각각 image2dUri, videoUri를 text 타입으로 정의하지만, 실제 투영 데이터는 유실되거나 빈 값으로 남음.

### Decision Drivers
- 데이터 무결성 보장(신규 키 유실 방지)
- 스키마 안정성(Breaking Change 최소화)
- 유지보수 비용(재투영 및 쿼리 복잡도)

### Considered Options
#### 기존 Read Model에 payloadSnapshot jsonb 컬럼 추가 및 매핑
- 접근: read_multimodal, read_grip_result 스키마에 payloadSnapshot: jsonb 추가, MultiModalProjector.map()과 GripResultProjector.map()에서 event.payload 전체를 저장.
- 제안 필드: payloadSnapshot
- 트레이드오프: 재투영 비용 낮음, 쿼리 유연성↑, 하지만 jsonb 인덱싱 오버헤드 발생.
```typescript
return { ...row, payloadSnapshot: event.payload as Record<string, unknown>, };
```

#### 신규 분리 Read Model 생성
- 접근: read_payload_drift 테이블 및 프로젝터 신규 생성. 기존 모델은 변경 안 함.
- 제안 필드: readPayloadDrift
- 트레이드오프: 초기 개발 비용↑, 쿼리 분산 발생, 하지만 기존 모델 안정성 최우선.
```typescript
const driftRow = { sceneKey, attemptNum, payloadData: event.payload as Record<string, unknown>, streamId, globalSeq }; await tx.insert(readPayloadDrift).values(driftRow);
```

#### Zod 스키마에 passThrough 허용 후 기존 컬럼 매핑 (기각 대안)
- 접근: toyDataSchema에 .passthrough() 적용하여 신규 키를 허용하고 기존 Read Model 컬럼으로 매핑 시도.
- 제안 필드: -
- 트레이드오프: 스키마 드리프트 허용하지만 타입 안전성↓, 기존 Read Model 컬럼이 부족해 여전히 유실됨. 데이터 무결성 보장 및 스키마 안정성 Driver에서 패배.

### Decision Outcome
기존 Read Model에 payloadSnapshot jsonb 컬럼 추가 및 매핑

### Consequences
- (+) 신규 키 데이터 보존

> upsert 키: scene_key, attempt_num · 리플레이: projection_cursor 초기화 시 catch-up 전체 재투영이 필요하며, 멱등 upsert 전제 하에 동일 키로 덮어씌워도 데이터 정합성이 유지되도록 구현해야 함.

| --- | --- | --- | --- |
| GripAttemptRecorded | 3D_image_file_name | three_d_image_file_name | verbatim |
| GripAttemptRecorded | box_type | box_type | verbatim |
| GripAttemptRecorded | data_key | data_key | verbatim |
| GripAttemptRecorded | camera_info | camera_info | object → jsonb 캐스팅 |

- `stream_id` ← event.streamId 그대로 할당

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripMetadata } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripMetadataInsert = InferInsertModel<typeof readGripMetadata>;

@Injectable()
export class GripMetadataProjector implements Projector<ReadGripMetadataInsert> {
  readonly name: string = "grip-metadata-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripMetadataProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripMetadataInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      threeDImageFileName: payload["3D_image_file_name"],
      boxType: payload.box_type,
      dataKey: payload.data_key,
      cameraInfo: payload.camera_info,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripMetadataInsert): Promise<void> {
    await tx
      .insert(readGripMetadata)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripMetadata.sceneKey, readGripMetadata.attemptNum],
        set: {
          threeDImageFileName: row.threeDImageFileName,
          boxType: row.boxType,
          dataKey: row.dataKey,
          cameraInfo: row.cameraInfo,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```

### 버전 교체 코드 — `src/projection/projection.service.ts` (modifyFile)

```typescript
import { Injectable } from '@nestjs/common';
import { PinoLogger } from 'nestjs-pino';
import { InsertResult, InsertService } from '@/insert/insert.service';
import { GripResultProjector } from '@/projection/projector/grip-result.projector';
import type { GripResultV2Projector } from '@/projection/projector/grip-result-v2.projector';
import { MultiModalProjector } from '@/projection/projector/multimodal.projector';
import { ProjectionResult } from '@/projection/projector/projector';
import { CatchUpRunner } from '@/projection/runner/catch-up.runner';
import { LogAction } from '@/shared/logger/logging-context';

export type CatchUpAllResult = {
  multimodal: ProjectionResult;
  gripResult: ProjectionResult;
  gripResultV2: ProjectionResult;
};

export type InsertAndProjectionAllResult = {
  insert: InsertResult;
  projection: CatchUpAllResult;
};

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly gripResultV2: GripResultV2Projector,
    private readonly insertService: InsertService,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  catchUpMultimodal(): Promise<ProjectionResult> {
    return this.runner.run(this.multimodal);
  }

  catchUpGripResult(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResult);
  }

  catchUpGripResultV2(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResultV2);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();
    const gripResultV2: ProjectionResult = await this.catchUpGripResultV2();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult, gripResultV2 };
  }

  async insertAllAndProjectAll(): Promise<InsertAndProjectionAllResult> {
    this.logger.info(
      { action: LogAction.PROJECTION_START },
      "전체 적재+투영 시작",
    );

    const insert: InsertResult = await this.insertService.insertToyData();
    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
}
```
