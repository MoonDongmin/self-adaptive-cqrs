## 1. 권고 (Recommendation)

### Status

### Context (근거)
- (level 40, `payload.schema.drift`) payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) ← 트립 앵커 → 현재 read_grip_result 및 read_multimodal의 Zod 검증 및 매핑 로직이 정의되지 않은 payload 키를 강제로 제거하거나 무시하여, 해당 필드의 데이터가 Read Model 투영 단계에서 영구 유실됨을 드러냄. [corr:309269d1-ac83-437e-b7e8-88940a9d54fe]
- src/insert/dto/toy-data.dto.ts의 toyDataSchema는 z.object()로 엄격하게 정의되어 있어, 정의되지 않은 키가 들어오면 Zod의 기본 strip 동작으로 매핑 전 제거되며, 이로 인해 payload.schema.drift 경고가 발생하지만 실제 DB 저장 단계에서는 해당 키가 유실됨. [corr:309269d1-ac83-437e-b7e8-88940a9d54fe]
- read_grip_result 스키마에는 이벤트 payload에 존재하는 box_type, data_key 등 Read Model 컬럼으로 매핑되지 않은 필드들이 누락되어 있어, 비즈니스 컨텍스트가 필요한 데이터가 투영 과정에서 손실됨. [corr:309269d1-ac83-437e-b7e8-88940a9d54fe]
- GripResultProjector.map()과 MultiModalProjector.map()은 명시된 필드만 반환하도록 하드코딩되어 있어, Zod가 .passthrough()를 사용하더라도 신규 키는 Drizzle 테이블에 저장되지 않음. [corr:309269d1-ac83-437e-b7e8-88940a9d54fe]
- image_2d_uri와 video_uri가 현재 null로 고정되어 있는 패턴은, 미정형 또는 추후 확장될 필드에 대한 투영 준비가 부족했음을 시사하며, 신규 키 유입 시 동일한 null 또는 유실 패턴이 반복될 위험이 있음. [corr:309269d1-ac83-437e-b7e8-88940a9d54fe]

### Considered Options
#### read_grip_result에 payload_metadata(jsonb) 컬럼 추가 및 프로젝트션 로직 확장
- 접근: read_grip_result Drizzle 스키마에 payloadMetadata(jsonb) 컬럼 추가. GripResultProjector.map()에서 Zod 검증 후 남은 전체 payload 객체를 해당 컬럼에 직렬화하여 저장. 기존 매핑 로직은 유지하되, 신규 키는 메타데이터로 격리.
- 제안 필드: payloadMetadata
- 트레이드오프: 재투영 시 기존 데이터와 메타데이터를 병합해야 하므로 마이그레이션 비용 발생. 조회 성능은 JSONB 인덱싱으로 보완 가능하나, 정형 필드 쿼리보다 복잡함. 리스크는 낮음(기존 구조 파괴 안 함).
```typescript
// schema/service/read-grip-result.ts 추가
payloadMetadata: jsonb("payload_metadata"),
// grip-result.projector.ts map() 수정
const rawPayload = event.payload as Record<string, unknown>;
return { ...baseRow, payloadMetadata: rawPayload };
```

#### 누락 필드(box_type, data_key) 명시적 매핑 및 Zod 스키마 .passthrough() 적용
- 접근: read_grip_result에 boxType, dataKey varchar 컬럼 추가. toyDataSchema에 .passthrough() 적용하여 신규 키를 유지하고, 프로젝트션에서 명시적 필드만 추출.
- 제안 필드: boxType, dataKey
- 트레이드오프: 비즈니스 요구사항이 명확한 필드만 투영하므로 쿼리 성능 최적화. 하지만 신규 키가 계속 유입될 때마다 스키마·프로젝터 수정이 필요해 유지보수 비용 증가. 리스크는 중간(코드 변경 빈도).
```typescript
// toy-data.dto.ts 수정
export const toyDataSchema = z.object({...}).passthrough();
// grip-result.projector.ts map() 수정
return { ...baseRow, boxType: payload.box_type, dataKey: payload.data_key };
```

### Decision Outcome
read_grip_result에 payload_metadata(jsonb) 컬럼 추가 및 프로젝트션 로직 확장 - 스키마 드리프트가 빈번한 Toy-Data 환경에서 데이터 유실 방지와 확장성을 동시에 확보하며, 기존 정형 매핑 로직을 최소한으로 수정함.

### Consequences
- (+) 신규 키 유입 시 데이터 영구 손실 방지
- (+) Read Model 재투영 시 호환성 유지
- (+) 스키마 변경 빈도 감소
- (−) JSONB 컬럼 조회 시 쿼리 복잡도 증가
- (−) 대용량 메타데이터 저장 시 DB 스토리지 비용 미세 증가

### Non-Goals
- read_multimodal의 URI 매핑 로직 구현(현재 null 고정 유지)
- 기존 정형 필드(grip_2d_pose 등)의 데이터 타입 변경
- 이벤트 저장소(ES) 스키마 수정

## 3. API Versioning

### Unreleased (v1 → v2)

#### Added
- read_grip_result_v2 테이블 및 GripResultV2Projector(grip-result-v2-projector) 추가. payload.objects[] 전체 배열, data_key, box_type, image_3d_file_name 매핑 지원.

### 마이그레이션 절차

- 하위호환 변경: 기존 /projection/grip-result 엔드포인트, read_grip_result 테이블, GripResultProjector 클래스는 수정·삭제되지 않음.; 기존 API 응답 구조 및 DB 스키마 호환성 유지. 신규 데이터는 별도 컬렉션(/v2/...)으로 격리됨.
- 파괴적 변경: 없음
- 컷오버 전 테스트: 1. v2 테이블 생성 후 DDL 검증 (컬럼 타입, 기본키 제약). 2. /v2/grip-result 호출 후 read_grip_result_v2에 objects[] 배열 전체 및 신규 키(data_key, box_type 등)가 null 없이 삽입되었는지 확인. 3. v1과 v2의 global_seq 매핑 일관성 검증 (동일 이벤트가 두 테이블에 올바르게 분배됨). 4. 정합성 검사(checkIntegrity) 미구현 프로젝트이므로, payload.objects.length > 0 조건에서 예외가 발생하지 않는지 단위 테스트로 검증.
- 롤백 창/조건: 컷오버 전 /v2/grip-result 라우트 비활성화(컨트롤러에서 @Post 주석 처리 또는 조건부 실행). v2 프로젝트 DI 제거. read_grip_result_v2 테이블은 데이터 보존 필요 시 유지, 불필요 시 DROP. 기존 v1 서비스/컨트롤러는 변경 전 상태로 복원 가능.
- Insight 카드 등록: §2의 카드 등록 SQL을 DDL과 함께 적용(카탈로그 동기화)

### 사유·호환성

- 사유: 기존 GripResultProjector.map()에서 payload.objects[0].class_name으로 첫 번째 객체만 추출하고, objects[] 배열 전체와 신규 키(3D_image_file_name, data_key, box_type)를 Read Model에 매핑하지 않아 배치 적재 시 데이터가 유실됨 [corr:309269d1-ac83-437e-b7e8-88940a9d54fe]. v2는 objects[]를 jsonb로 전체 저장하고 누락된 필드를 신규 컬럼으로 매핑하여 스키마 드리프트에 따른 정보 손실을 방지함.
- 트리거 근거: 00:40:28.436 | 40 | payload.schema.drift | 309269d1-ac83-437e-b7e8-88940a9d54fe | payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) ← 트립 앵커

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripCameraMetadata } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripCameraMetadataInsert = InferInsertModel<typeof readGripCameraMetadata>;

@Injectable()
export class GripCameraMetadataProjector implements Projector<ReadGripCameraMetadataInsert> {
  readonly name: string = "grip-camera-metadata-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripCameraMetadataProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripCameraMetadataInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      dataKey: payload.data_key,
      boxType: payload.box_type,
      cameraName: payload.camera_info.camera_name,
      cameraType: payload.camera_info.camera_type,
      cameraIntrinsicParam: payload.camera_info.camera_intrinsic_param,
      image3dFileName: payload["3D_image_file_name"],
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripCameraMetadataInsert): Promise<void> {
    await tx
      .insert(readGripCameraMetadata)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripCameraMetadata.sceneKey, readGripCameraMetadata.attemptNum],
        set: {
          dataKey: row.dataKey,
          boxType: row.boxType,
          cameraName: row.cameraName,
          cameraType: row.cameraType,
          cameraIntrinsicParam: row.cameraIntrinsicParam,
          image3dFileName: row.image3dFileName,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```

        `grip-result-v2 map: empty objects in event ${event.eventId}`,
      );
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      objectName: payload.objects[0].class_name,
      gripSucceed: payload.grip_succeed,
      gripperType: "finger",
      occurredAt: event.occurredAt,
      grip2dPose: payload.grip_data.grip_2d_pose,
      grip3dPose: payload.grip_data.grip_3d_pose,
      robotTf: payload.robot_tf,
      humanAnnotationGrasp: payload.human_annotation_grasp,
      objects: payload.objects,
      dataKey: payload.data_key,
      boxType: payload.box_type,
      image3dFileName: payload["3D_image_file_name"],
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripResultV2Insert): Promise<void> {
    await tx
      .insert(readGripResultV2)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripResultV2.sceneKey, readGripResultV2.attemptNum],
        set: {
          objectName: row.objectName,
          gripSucceed: row.gripSucceed,
          gripperType: row.gripperType,
          occurredAt: row.occurredAt,
          grip2dPose: row.grip2dPose,
          grip3dPose: row.grip3dPose,
          robotTf: row.robotTf,
          humanAnnotationGrasp: row.humanAnnotationGrasp,
          objects: row.objects,
          dataKey: row.dataKey,
          boxType: row.boxType,
          image3dFileName: row.image3dFileName,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}

import { Injectable } from '@nestjs/common';
import { PinoLogger } from 'nestjs-pino';
import { InsertResult, InsertService } from '@/insert/insert.service';
import { GripResultProjector } from '@/projection/projector/grip-result.projector';
import { MultiModalProjector } from '@/projection/projector/multimodal.projector';
import { GripResultV2Projector } from '@/projection/projector/grip-result-v2.projector';
import { ProjectionResult } from '@/projection/projector/projector';
import { CatchUpRunner } from '@/projection/runner/catch-up.runner';
import { LogAction } from '@/shared/logger/logging-context';

export type CatchUpAllResult = {
  multimodal: ProjectionResult;
  gripResult: ProjectionResult;
  gripResultV2: ProjectionResult;
};

export type InsertAndProjectionAllResult = {
  insert: InsertResult;
  projection: CatchUpAllResult;
};

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly gripResultV2: GripResultV2Projector,
    private readonly insertService: InsertService,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  catchUpMultimodal(): Promise<ProjectionResult> {
    return this.runner.run(this.multimodal);
  }

  catchUpGripResult(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResult);
  }

  catchUpGripResultV2(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResultV2);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();
    const gripResultV2: ProjectionResult = await this.catchUpGripResultV2();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult, gripResultV2 };
  }

  async insertAllAndProjectAll(): Promise<InsertAndProjectionAllResult> {
    this.logger.info(
      { action: LogAction.PROJECTION_START },
      "전체 적재+투영 시작",
    );

    const insert: InsertResult = await this.insertService.insertToyData();
    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
}
