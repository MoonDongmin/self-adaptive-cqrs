## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 40, `payload.schema.drift`) payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) ← 트립 앵커 → read_multimodal 및 read_grip_result의 Projection 파이프라인이 Zod 검증을 통과하지 못하거나, 스키마에 정의되지 않은 필드를 묵시적으로 drop하여 신규 키 데이터를 유실시키고 있음을 드러냄. [corr:333c1735-0437-4d41-9023-1a43407d6bc3]
- src/insert/dto/toy-data.dto.ts의 toyDataSchema는 .passthrough() 없이 엄격하게 정의되어 있어, 신규 키가 유입될 경우 검증 실패 또는 묵시적 drop을 유발함.
- read_multimodal과 read_grip_result Drizzle 테이블은 고정 컬럼 구조로, 신규 키를 저장할 물리적 공간이 없음.
- MultiModalProjector.map() 및 GripResultProjector.map()은 toyDataSchema.parse(event.payload)에 의존하므로, 스키마 미적용 시 매핑 단계에서 예외 발생 또는 데이터 유실이 확정됨.

### Decision Drivers
- Schema Evolution Cost (마이그레이션 및 재투영 부담)
- Type Safety vs Flexibility (타입 안전성 대 유연한 드리프트 수용)
- Backward Compatibility (기존 Read Model 계약 및 하위 호환 유지)

### Considered Options
#### 스키마 확장 및 컬럼 추가 (Explicit Extension)
- 접근: toyDataSchema에 신규 키 필드 추가, Drizzle 테이블(read_multimodal, read_grip_result)에 대응 컬럼 생성, Projector의 map() 함수에서 해당 필드 매핑.
- 제안 필드: toyDataSchema 신규 키 정의, read_multimodal.extraData jsonb, read_grip_result.extraData jsonb
- 트레이드오프: 타입 안전성 및 명시적 설계 유지. 단, 신규 키 발생 시마다 DB 마이그레이션과 전체 Read Model 재투영(re-projection) 비용이 발생하며, 기존 파이프라인 중단 리스크가 있음.
```typescript
const toyDataSchema = z.object({ ... }).passthrough(); // DTO 수정
export const readMultimodal = pgTable("read_multimodal", { ... extraData: jsonb("extra_data"), ... }); // 테이블 수정
return { ... image2dFileName: payload["2D_image_file_name"], extraData: payload, ... }; // Projector 수정
```

#### 유연한 메타데이터 저장소 도입 (Graceful passthrough + jsonb)
- 접근: toyDataSchema에 .passthrough() 적용하여 unknown 키 허용, Read Model에 extraPayload jsonb 컬럼 추가, Projector에서 검증된 payload 전체를 해당 컬럼에 저장.
- 제안 필드: toyDataSchema .passthrough() 적용, read_multimodal.extraPayload jsonb, read_grip_result.extraPayload jsonb
- 트레이드오프: 스키마 드리프트에 대한 내구성 확보, 재투영 없이 신규 키 즉시 반영. 단, 하위 호환성 유지가 어렵고, 동적 JSON 처리로 인한 쿼리 성능 저하 및 타입 안전성 약화.
```typescript
const toyDataSchema = z.object({ ... }).passthrough(); // DTO 수정
export const readMultimodal = pgTable("read_multimodal", { ... extraPayload: jsonb("extra_payload"), ... }); // 테이블 수정
return { ... image2dFileName: payload["2D_image_file_name"], extraPayload: payload, ... }; // Projector 수정
```

### Decision Outcome
유연한 메타데이터 저장소 도입 (Graceful passthrough + jsonb)

### Consequences
- (+) 신규 키 유입 시 Read Model 매핑 실패 없이 데이터가 extraPayload 컬럼에 안전하게 저장됨.
- (+) 기존 핵심 Read Model 컬럼의 타입 안정성 및 쿼리 성능이 유지됨.
- (+) 재투영(re-projection) 없이 신규 키 반영이 가능하여 운영 중단 시간이 제거됨.
- (−) extraPayload 컬럼의 동적 JSON 구조로 인해 하위 호환성 유지가 어렵고, 신규 키에 대한 명시적 타입 안전성이 약화됨.
- (−) 동적 필드 조회 시 인덱스 활용도가 낮아져 특정 쿼리 성능 저하가 발생할 수 있음.
- (−) 하위 시스템에서 extraPayload를 파싱할 때 런타임 검증 로직 추가 필요.

### Non-Goals
- Event Store 원본 스키마(GripAttemptRecorded) 변경 또는 Insert 계층 검증 로직 수정.
- 기존 Read Model의 핵심 컬럼(scene_key, attempt_num, grip_2d_pose 등) 구조 변경.
- URI 매핑(image_2d_uri, video_uri) 로직 구현 (현재 null 고정 유지).

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripContext } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripContextInsert = InferInsertModel<typeof readGripContext>;

@Injectable()
export class GripContextProjector implements Projector<ReadGripContextInsert> {
  readonly name: string = "grip-context-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripContextProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripContextInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      dataKey: payload.data_key,
      boxType: payload.box_type,
      cameraInfo: payload.camera_info,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripContextInsert): Promise<void> {
    await tx
      .insert(readGripContext)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripContext.sceneKey, readGripContext.attemptNum],
        set: {
          dataKey: row.dataKey,
          boxType: row.boxType,
          cameraInfo: row.cameraInfo,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```

```typescript
import { ProjectionResult } from '@/projection/projector/projector';
import { CatchUpRunner } from '@/projection/runner/catch-up.runner';
import { LogAction } from '@/shared/logger/logging-context';

export type CatchUpAllResult = {
  multimodal: ProjectionResult;
  gripResult: ProjectionResult;
};

export type CatchUpAllV2Result = {
  gripResult: ProjectionResult;
};

export type InsertAndProjectionAllResult = {
  insert: InsertResult;
  projection: CatchUpAllResult;
};

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly gripResultV2: GripResultV2Projector,
    private readonly insertService: InsertService,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  catchUpMultimodal(): Promise<ProjectionResult> {
    return this.runner.run(this.multimodal);
  }

  catchUpGripResult(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResult);
  }

  catchUpGripResultV2(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResultV2);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult };
  }

  async catchUpAllV2(): Promise<CatchUpAllV2Result> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "v2 전체 투영 시작");

    const gripResult: ProjectionResult = await this.catchUpGripResultV2();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "v2 전체 투영 완료");

    return { gripResult };
  }

  async insertAllAndProjectAll(): Promise<InsertAndProjectionAllResult> {
    this.logger.info(
      { action: LogAction.PROJECTION_START },
      "전체 적재+투영 시작",
    );

    const insert: InsertResult = await this.insertService.insertToyData();
    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
}
```
