### 투영 매핑 명세 (이벤트 → 컬럼)

> upsert 키: sceneKey,attemptNum · 리플레이: projection_cursor 초기화 시 전체 재투영이 필요하며, catch-up 중 중복 이벤트 발생을 대비해 upsert는 멱등성(idempotent)을 보장해야 한다.

| 원천 이벤트 | payload 필드 | 컬럼 | 변환 |
| --- | --- | --- | --- |
| GripAttemptRecorded | attempt_num | attemptNum | verbatim |
| GripAttemptRecorded | objects[].class_name | objectName | verbatim |
| GripAttemptRecorded | grip_succeed | gripSucceed | verbatim |
| GripAttemptRecorded | stream_id | streamId | verbatim |

파생 컬럼(이벤트 payload 아님):
- `sceneKey` ← stream_id에서 'grip-attempt:' 접두사 제거
- `objectTotalAttempts` ← objectName 기준 누적 시도 수 (COUNT)
- `objectSuccessCount` ← objectName 기준 gripSucceed 합계 (SUM)
- `objectSuccessRate` ← (objectSuccessCount / objectTotalAttempts) * 100
- `occurredAt` ← 2D_image_file_name에서 YYYYMMDD 추출 후 timestamptz 변환
- `globalSeq` ← ES 이벤트의 전역 시퀀스 번호 (projection_cursor 기준)

## 3. API Versioning

> 실행 게이트: 아래 변경은 인간 승인 후에만 적용한다 (human-in-the-loop).

### Unreleased (v1 → v2)

#### Added
- object_name별 파지 성공률 집계를 위한 Read Model v2(read_object_grasp_stats_v2) 및 대응 투영 라우트 POST /projection/object-grasp-stats-v2 추가

### 마이그레이션 절차

- 하위호환 변경: v1 read_grip_result 테이블 및 GripResultProjector는 시도(attempt) 단위 상세 저장 로직을 유지하며 변경되지 않음; 기존 Insight 카드 조회 실패(warn)는 v2 활성화 후 정상 응답으로 대체되며 기존 상세 조회 기능은 중단되지 않음
- 파괴적 변경: 없음
- 컷오버 전 테스트: v2 프로젝터(ObjectGraspStatsV2Projector) catch-up 실행 후 read_object_grasp_stats_v2 테이블에 object_name별 집계 행이 정확히 생성되었는지 확인. v1 read_grip_result의 원본 시도 데이터와 v2 집계 수치를 샘플 객체 기준으로 비교하여 성공률 계산식 검증. Insight 카드 조회 API 호출 시 insight.card.miss가 발생하지 않고 집계 데이터 반환 확인.
- 롤백 창/조건: v2 프로젝터 비활성화 및 해당 커서 초기화. 라우트 /projection/object-grasp-stats-v2 제거 또는 404 반환. v1 read_grip_result 기반의 기존 상세 조회 로직은 그대로 유지되므로 기능 중단 없음. 집계 부재로 인한 warn 로그는 재발생하나 핵심 파지 데이터 손실은 없음.
- Insight 카드 등록: §2의 카드 등록 SQL을 DDL과 함께 적용(카탈로그 동기화)

### 사유·호환성

- 사유: 기존 v1 GripResultProjector.map 메서드는 payload.objects[0].class_name만 추출해 시도(attempt) 단위 상세 행으로 저장한다. 객체(object_name)별 집계(시도 수, 성공 수, 성공률)를 위한 Read Model이 부재하여 Insight 카드 조회 시 miss가 발생한다. [corr:edf81375-f3f1-4524-bca6-bc1bdd67053d]
- 트리거 근거: 03:19:40.249 | 40 | insight.card.miss | edf81375-f3f1-4524-bca6-bc1bdd67053d | insight 카드 없음: 객체(object_name)별 파지 성공률을 한 번에 조회하고 싶다. 시도 수, 성공 수, 성공률이 필요하다. ← 트립 앵커
- v1 호환성: v1 read_grip_result 테이블 및 GripResultProjector는 시도(attempt) 단위 상세 데이터 저장 로직을 유지하며 변경·삭제되지 않는다. v2는 object_name별 집계 데이터를 별도 테이블(read_object_grasp_stats_v2)에 병렬로 유지하며, 기존 엔드포인트와 프로젝트터 클래스명은 그대로 보존된다.

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { eq } from 'drizzle-orm';
import type { InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import type { ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readObjectGraspStats } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadObjectGraspStatsInsert = InferInsertModel<typeof readObjectGraspStats>;

@Injectable()
export class ObjectGraspStatsProjector implements Projector<ReadObjectGraspStatsInsert> {
  readonly name: string = "object-grasp-stats-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(ObjectGraspStatsProjector.name);
  }

  map(event: EventStoreEventRow): ReadObjectGraspStatsInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    if (payload.objects.length === 0) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
        },
        "objects 비어 있음",
      );

      throw new Error(
        `object-grasp-stats map: empty objects in event ${event.eventId}`,
      );
    }

    const objectName: string = payload.objects[0].class_name;
    const gripSucceed: number = payload.grip_succeed;

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      objectName,
      gripSucceed,
      objectTotalAttempts: 0,
      objectSuccessCount: 0,
      objectSuccessRate: 0.0,
      occurredAt: event.occurredAt,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadObjectGraspStatsInsert): Promise<void> {
    const objectName = row.objectName;

    const rows = await tx.select().from(readObjectGraspStats).where(eq(readObjectGraspStats.objectName, objectName));
    const totalAttempts: number = rows.length;
    const successCount: number = rows.reduce((acc, r) => acc + r.gripSucceed, 0);
    const successRate: number = totalAttempts > 0 ? (successCount / totalAttempts) * 100 : 0.0;

    await tx
      .insert(readObjectGraspStats)
      .values({
        ...row,
        objectTotalAttempts: totalAttempts,
        objectSuccessCount: successCount,
        objectSuccessRate: successRate,
      })
      .onConflictDoUpdate({
        target: [readObjectGraspStats.sceneKey, readObjectGraspStats.attemptNum],
        set: {
          objectName: row.objectName,
          gripSucceed: row.gripSucceed,
          objectTotalAttempts: totalAttempts,
          objectSuccessCount: successCount,
          objectSuccessRate: successRate,
          occurredAt: row.occurredAt,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```

```typescript
import { Injectable } from '@nestjs/common';
import { PinoLogger } from 'nestjs-pino';
import { InsertResult, InsertService } from '@/insert/insert.service';
import { GripResultProjector } from '@/projection/projector/grip-result.projector';
import { MultiModalProjector } from '@/projection/projector/multimodal.projector';
import { ObjectGraspStatsV2Projector } from '@/projection/projector/object-grasp-stats-v2.projector';
import { ProjectionResult } from '@/projection/projector/projector';
import { CatchUpRunner } from '@/projection/runner/catch-up.runner';
import { LogAction } from '@/shared/logger/logging-context';

export type CatchUpAllResult = {
  multimodal: ProjectionResult;
  gripResult: ProjectionResult;
  objectGraspStatsV2: ProjectionResult;
};

export type InsertAndProjectionAllResult = {
  insert: InsertResult;
  projection: CatchUpAllResult;
};

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly objectGraspStatsV2: ObjectGraspStatsV2Projector,
    private readonly insertService: InsertService,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  catchUpMultimodal(): Promise<ProjectionResult> {
    return this.runner.run(this.multimodal);
  }

  catchUpGripResult(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResult);
  }

  catchUpObjectGraspStatsV2(): Promise<ProjectionResult> {
    return this.runner.run(this.objectGraspStatsV2);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();
    const objectGraspStatsV2: ProjectionResult = await this.catchUpObjectGraspStatsV2();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult, objectGraspStatsV2 };
  }

  async insertAllAndProjectAll(): Promise<InsertAndProjectionAllResult> {
    this.logger.info(
      { action: LogAction.PROJECTION_START },
      "전체 적재+투영 시작",
    );

    const insert: InsertResult = await this.insertService.insertToyData();
    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
}
```
