- 도메인 정합성: 집계 로직이 이벤트 소스와 Read Model 간 명확히 분리되어야 함.

### Considered Options
#### 기존 DB Materialized View 생성
- 접근: read_grip_result 테이블을 기반으로 DB 레벨에서 Materialized View를 생성하여 object_name별 시도 수, 성공 수, 성공률을 집계. 기존 Projector 변경 없이 스키마 확장만으로 해결.
- 제안 필드: object_name, total_attempts, success_count, success_rate
- 트레이드오프: 재투영 불필요, 구현 비용 낮음. 하지만 MV refresh 주기 설정 필요로 실시간성 약함, 대량 데이터에서 뷰 쿼리 성능이 제한적일 수 있음.
```typescript
import { sql } from 'drizzle-orm';
export const readGripResultByObject = pgTable('read_grip_result_by_object', {
  objectName: varchar('object_name').primaryKey(),
  totalAttempts: integer('total_attempts').notNull().default(0),
  successCount: integer('success_count').notNull().default(0),
  successRate: decimal('success_rate', { precision: 5, scale: 2 }).notNull().default('0.00'),
});
// DB에서 CREATE MATERIALIZED VIEW read_grip_result_by_object AS SELECT object_name, COUNT(*) as total_attempts, SUM(grip_succeed) as success_count, AVG(grip_succeed)::numeric(5,2) as success_rate FROM read_grip_result GROUP BY object_name;
```

#### 신규 집계 Read Model + 전용 Projector
- 접근: read_grip_success_rate_by_object 테이블 신규 생성. GripSuccessRateByObjectProjector가 이벤트 매핑 시 object_name별 카운터 집계 후 upsert. CQRS 관례에 따라 별도 Projector로 관리.
- 제안 필드: objectName, totalAttempts, successCount, successRate
- 트레이드오프: 실시간 집계 가능, 쿼리 성능 우수. 하지만 테이블/프로젝터 추가 관리 비용 발생, 기존 read_grip_result 재투영 시 집계 테이블도 함께 갱신해야 하므로 ProjectionService에 로직 추가 필요.
```typescript
import { Injectable } from '@nestjs/common';
import type { InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripSuccessRateByObject } from '@/shared/database/schema/service/read-grip-success-rate-by-object';
import { LogAction, LogContext } from '@/shared/logger/logging-context';
type ReadGripSuccessRateByObjectInsert = InferInsertModel<typeof readGripSuccessRateByObject>;
@Injectable()
export class GripSuccessRateByObjectProjector implements Projector<ReadGripSuccessRateByObjectInsert> {
  readonly name: string = 'grip-success-rate-by-object-projector';
  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripSuccessRateByObjectProjector.name);
  }
  map(event: EventStoreEventRow): ReadGripSuccessRateByObjectInsert {
    const payload = event.payload as { objects: Array<{ class_name: string }>; grip_succeed: number }>;
    const objectName = payload.objects[0].class_name;
    return {
      objectName,
      totalAttempts: 1,
      successCount: payload.grip_succeed,
      successRate: payload.grip_succeed === 1 ? '1.00' : '0.00',
    };
  }
  async upsert(tx: DrizzleTx, row: ReadGripSuccessRateByObjectInsert): Promise<void> {
    await tx.insert(readGripSuccessRateByObject).values(row).onConflictDoUpdate({
      target: [readGripSuccessRateByObject.objectName],
      set: {
        totalAttempts: sql`${readGripSuccessRateByObject.totalAttempts} + ${row.totalAttempts}`,
        successCount: sql`${readGripSuccessRateByObject.successCount} + ${row.successCount}`,
        successRate: sql`ROUND(CAST(${readGripSuccessRateByObject.successCount} + ${row.successCount}) AS NUMERIC(5,2)) / NULLIF(${readGripSuccessRateByObject.totalAttempts} + ${row.totalAttempts}, 0)`,
      },
    });
  }
}
```

### Decision Outcome
신규 집계 Read Model + 전용 Projector

### Consequences
- (+) object_name별 성공률 조회가 O(1) 또는 인덱스 스캔으로 처리되어 응답 지연 최소화.
- (+) 이벤트 기반 집계로 실시간 일관성 확보.
- (+) 기존 read_grip_result Projector 변경 없이 확장 가능.
- (−) 신규 테이블 스키마 및 Projector 추가 관리 부담 발생.
- (−) read_grip_result 재투영 시 집계 테이블도 함께 갱신해야 하므로 ProjectionService에 로직 추가 필요.

### Non-Goals
- read_multimodal의 image2d_uri, video_uri null 매핑 해결.
- 다른 Insight 카드(예: 카메라별/장면별 통계) 조회 로직 구현.
- 이벤트 스키마(GripAttemptRecorded) 변경 또는 objects[].class_name 구조 수정.

```typescript
import { Injectable } from '@nestjs/common';
import { PinoLogger } from 'nestjs-pino';
import { InsertResult, InsertService } from '@/insert/insert.service';
import { GripResultProjector } from '@/projection/projector/grip-result.projector';
import { MultiModalProjector } from '@/projection/projector/multimodal.projector';
import { GripSuccessRateV2Projector } from '@/projection/projector/grip-success-rate-v2.projector';
import { ProjectionResult } from '@/projection/projector/projector';
import { CatchUpRunner } from '@/projection/runner/catch-up.runner';
import { LogAction } from '@/shared/logger/logging-context';

export type CatchUpAllResult = {
  multimodal: ProjectionResult;
  gripResult: ProjectionResult;
  gripSuccessRateV2: ProjectionResult;
};

export type InsertAndProjectionAllResult = {
  insert: InsertResult;
  projection: CatchUpAllResult;
};

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly insertService: InsertService,
    private readonly gripSuccessRateV2: GripSuccessRateV2Projector,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  catchUpMultimodal(): Promise<ProjectionResult> {
    return this.runner.run(this.multimodal);
  }

  catchUpGripResult(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResult);
  }

  catchUpGripSuccessRateV2(): Promise<ProjectionResult> {
    return this.runner.run(this.gripSuccessRateV2);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();
    const gripSuccessRateV2: ProjectionResult = await this.catchUpGripSuccessRateV2();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult, gripSuccessRateV2 };
  }

  async insertAllAndProjectAll(): Promise<InsertAndProjectionAllResult> {
    this.logger.info(
      { action: LogAction.PROJECTION_START },
      "전체 적재+투영 시작",
    );

    const insert: InsertResult = await this.insertService.insertToyData();
    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
}
```
