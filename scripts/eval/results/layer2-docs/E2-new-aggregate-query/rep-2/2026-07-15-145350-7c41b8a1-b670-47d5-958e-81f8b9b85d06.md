- read_grip_result 스키마는 (scene_key, attempt_num)을 복합 키로 하며 object_name과 grip_succeed를 개별 행에 저장함. 집계 쿼리가 가능하지만 Insight 카드 조회는 미리 계산된 집계 테이블을 요구함.
- GripResultProjector.map()은 payload.objects[0].class_name을 objectName에, payload.grip_succeed를 gripSucceed에 매핑하지만 집계 로직은 포함하지 않음.
- 현재 시스템에는 object_name별 성공률 집계를 위한 전용 Read Model이나 데이터베이스 뷰가 정의되지 않음.
- Insight 카드 조회는 insight.card.miss로 이어지며, 이는 집계 데이터가 Read Model에 존재하지 않아 캐시/조회 실패로 처리됨을 의미.
- 소스 코드에서 read-grip-result.ts는 집계용 인덱스가 있지만 실제 집계 테이블은 없음.

### Decision Drivers
- 조회 성능 (O(1) vs O(N))
- 구현 복잡도/유지보수성
- 기존 Read Model 구조 변경 범위

### Considered Options
#### Option 1: 데이터베이스 뷰 기반 집계 (기존 보강)
- 접근: 기존 read_grip_result 테이블 위에 object_name별 집계 뷰 생성.
- 제안 필드: object_name, total_attempts, success_count, success_rate
- 트레이드오프: 재투영 불필요(비용 낮음), 조회 시 실시간 계산 오버헤드 발생. 기각 대안: 조회 성능(Driver 1)에서 실시간 계산 오버헤드로 인해 낙선.
```typescript
CREATE VIEW v_read_grip_object_stats AS SELECT object_name, COUNT(*) AS total_attempts, SUM(grip_succeed) AS success_count, ROUND(SUM(grip_succeed)::numeric / COUNT(*), 4) AS success_rate FROM read_grip_result GROUP BY object_name;
```

#### Option 2: 신규 집계 Read Model (신규 분리)
- 접근: read_grip_object_stats 테이블 신규 생성 및 GripResultProjector에 집계 로직 병행 투영.
- 제안 필드: object_name, totalAttempts, successCount, successRate
- 트레이드오프: 읽기 성능 최적화(고정 비용), 기존 데이터 재투영 필요, 프로젝트터 로직 복잡도 증가.

> upsert 키: objectName · 리플레이: projection_cursor 초기화 후 catch-up 전체 재투영 시, 기존 레코드 전량 삭제 없이 upsert로 덮어쓰므로 멱등성 보장 필수. 동일 object_name에 대한 집계 값은 최신 이벤트 기준 정확히 재계산됨.

| --- | --- | --- | --- |
| GripAttemptRecorded | objects[0].class_name | objectName | verbatim |

파생 컬럼(이벤트 payload 아님):
- `totalAttempts` ← objectName 기준 GROUP BY COUNT(*)
- `successCount` ← grip_succeed = 1인 이벤트 건수 SUM
- `successRate` ← successCount / totalAttempts (0으로 나누기 방지)

- 롤백 창/조건: 라우트 비활성화(또는 Nginx/网关 차단) → ProjectionService에서 ObjectGripRateV2Projector 의존성 제거 및 catchUpObjectGripRateV2 호출 삭제 → v2 테이블 DROP(필요 시) → 기존 v1 서비스 재시작. 롤백 창은 30분 내, 조건은 집계 정확도 검증 실패 또는 서비스 지연 발생 시.
- Insight 카드 등록: §2의 카드 등록 SQL을 DDL과 함께 적용(카탈로그 동기화)

### 사유·호환성

- 사유: 기존 read_grip_result는 개별 파지 시도(attempt) 단위 행만 저장하며, objects[0].class_name만 추출해 object_name으로 매핑한다. 이로 인해 동일 장면 내 다중 객체나 시도 횟수에 따른 집계(시도 수, 성공 수, 성공률)를 조회할 수 없어 insight.card.request가 모두 miss로 처리된다. v2는 object_name별 집계 테이블(read_object_grip_rate_v2)을 도입해 이벤트 스트림에서 객체별 성공/실패를 집계·업데이트하며, 조회 요청을 즉시 충족한다. - v1 호환성: 기존 read_grip_result 테이블, GripResultProjector, 관련 엔드포인트(/projection/grip-result)는 그대로 유지된다. v1은 개별 시도 상세 조회 및 센서 관찰용 메시지로 계속 사용되며, v2는 집계 전용으로 병행 운영된다.

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel, sql } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripObjectStats } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripObjectStatsInsert = InferInsertModel<typeof readGripObjectStats>;

@Injectable()
export class GripObjectStatsProjector implements Projector<ReadGripObjectStatsInsert> {
  readonly name: string = "grip-object-stats-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripObjectStatsProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripObjectStatsInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (err) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          err,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw err;
    }

    if (payload.objects.length === 0) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
        },
        "objects 비어 있음",
      );

      throw new Error(
        `grip-object-stats map: empty objects in event ${event.eventId}`,
      );
    }

    const objectName = payload.objects[0].class_name;
    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      objectName,
      totalAttempts: 1,
      successCount: payload.grip_succeed,
      successRate: payload.grip_succeed === 1 ? 1.0 : 0.0,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripObjectStatsInsert): Promise<void> {
    await tx
      .insert(readGripObjectStats)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripObjectStats.objectName],
        set: {
          totalAttempts: sql`${readGripObjectStats.totalAttempts} + ${row.totalAttempts}`,
          successCount: sql`${readGripObjectStats.successCount} + ${row.successCount}`,
          successRate: sql`(${readGripObjectStats.successCount} + ${row.successCount}) / (${readGripObjectStats.totalAttempts} + ${row.totalAttempts})`,
        },
      });
  }
}
```
