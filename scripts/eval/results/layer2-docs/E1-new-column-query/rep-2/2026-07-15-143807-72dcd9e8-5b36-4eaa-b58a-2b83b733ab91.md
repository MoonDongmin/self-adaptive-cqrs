- (level 40, `insight.card.miss`) insight 카드 없음: 최근 적재 데이터에 gripper_temperature 필드가 들어오기 시작했다. 이 값을 시간대별로 조회하고 싶다. 현재 Read Model로 가능한가? 안 되면 어떻게 해야 하나? → read_grip_result 테이블에 해당 필드 컬럼이 부재하여 시간대별 조회 요청이 실패함을 드러냄 [corr:4ee188b5-c51d-4af8-908d-7dc56b85533b]
- src/insert/dto/toy-data.dto.ts의 toyDataSchema에 gripper_temperature 필드가 정의되지 않아, 이벤트 적재 시 해당 키가 검증 과정에서 필터링되거나 무시될 수 있음 [corr:72dcd9e8-5b36-4eaa-b58a-2b83b733ab91].
- src/shared/database/schema/service/read-grip-result.ts의 Drizzle 테이블 정의에 gripper_temperature 컬럼이 존재하지 않으며, 기존 occurred_at(데이터 촬영 일자)과 gripper_type(그리퍼 종류) 등 핵심 조회/정렬 컬럼만 구성되어 있음.
- src/projection/projector/grip-result.projector.ts의 map() 함수는 payload에서 gripper_type, grip_succeed, object_name 등만 추출하고 있으며, 신규 키를 매핑하는 코드가 없음. 이로 인해 read_grip_result에 데이터가 유실됨 [corr:72dcd9e8-5b36-4eaa-b58a-2b83b733ab91].
- 조회 요청은 occurred_at 기준 시간대별 정렬/필터를 기대하나, 현재 스키마에는 온도 데이터가 투영되지 않아 insight.card.miss로 이어짐 [corr:4ee188b5-c51d-4af8-908d-7dc56b85533b].

### Decision Drivers
- 도메인 응집도: 파지 시도 1건의 메타데이터를 단일 조회 관점에서 어떻게 묶을 것인가.
- 마이그레이션 비용: 기존 read_grip_result 재투영 및 스키마 변경 리스크 vs 신규 테이블 구축 비용.
- 쿼리 성능: 시간대별 occurred_at 정렬/필터링에 최적화된 인덱스 구조.
- 확장성: 향후 센서 데이터 추가 시 스키마 드리프트 대응 유연성.

### Considered Options
#### 기존 read_grip_result 컬럼 보강

- 제안 필드: gripper_temperature
- 트레이드오프: 재투영 필요하나 단일 테이블 유지로 조인/쿼리 단순화. 리스크: 기존 행 마이그레이션 필요.

### Consequences

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripTemperature } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripTemperatureInsert = InferInsertModel<typeof readGripTemperature>;

@Injectable()
export class GripTemperatureProjector implements Projector<ReadGripTemperatureInsert> {
  readonly name: string = "grip-temperature-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripTemperatureProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripTemperatureInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      gripperTemperature: payload.gripper_temperature ?? null,
      occurredAt: event.occurredAt,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripTemperatureInsert): Promise<void> {
    await tx
      .insert(readGripTemperature)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripTemperature.sceneKey, readGripTemperature.attemptNum],
        set: {
          gripperTemperature: row.gripperTemperature,
          occurredAt: row.occurredAt,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```

```typescript
import { Injectable } from '@nestjs/common';
import type { InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripResultV2 } from '@/shared/database/schema/service/read-grip-result-v2';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripResultV2Insert = InferInsertModel<typeof readGripResultV2>;

function isRecord(val: unknown): val is Record<string, unknown> {
  return typeof val === 'object' && val !== null;
}

@Injectable()
export class GripResultV2Projector implements Projector<ReadGripResultV2Insert> {
  readonly name: string = "grip-result-v2-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripResultV2Projector.name);
  }

  map(event: EventStoreEventRow): ReadGripResultV2Insert {
    const rawPayload = event.payload;

    if (!isRecord(rawPayload)) {
      throw new Error(`grip-result-v2 map: invalid payload type in event ${event.eventId}`);
    }

    const p = rawPayload;
    const objects = p["objects"];

    if (!Array.isArray(objects) || objects.length === 0) {
      throw new Error(`grip-result-v2 map: empty objects in event ${event.eventId}`);
    }

    const gripperTemperature = p["gripper_temperature"];

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      objectName: String(objects[0]["class_name"] ?? ""),
      gripSucceed: Number(p["grip_succeed"] ?? 0),
      gripperType: "finger",
      occurredAt: event.occurredAt,
      grip2dPose: isRecord(p["grip_data"]) ? p["grip_data"]["grip_2d_pose"] : null,
      grip3dPose: isRecord(p["grip_data"]) ? p["grip_data"]["grip_3d_pose"] : null,
      robotTf: p["robot_tf"],
      humanAnnotationGrasp: p["human_annotation_grasp"],
      gripperTemperature,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripResultV2Insert): Promise<void> {
    await tx
      .insert(readGripResultV2)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripResultV2.sceneKey, readGripResultV2.attemptNum],
        set: {
          objectName: row.objectName,
          gripSucceed: row.gripSucceed,
          gripperType: row.gripperType,
          occurredAt: row.occurredAt,
          grip2dPose: row.grip2dPose,
          grip3dPose: row.grip3dPose,
          robotTf: row.robotTf,
          humanAnnotationGrasp: row.humanAnnotationGrasp,
          gripperTemperature: row.gripperTemperature,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```
