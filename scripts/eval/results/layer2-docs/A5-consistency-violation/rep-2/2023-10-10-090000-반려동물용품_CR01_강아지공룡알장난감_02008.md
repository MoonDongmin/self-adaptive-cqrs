## 1. 권고 (Recommendation)

> gripSucceed=1 레코드에서 robotTfTranslationZ 및 grip3dPoseZ가 물리적 작업범위와 파지 깊이를 이탈하여 잡을 수 없는 위치에서 성공으로 기록됨 — Read Model에 오염된 정합성 오류가 영구 persist됨.

### 심각도 — critical

오염 컬럼: gripSucceed(성공 여부)와 robotTfTranslation/grip3dPoseZ(물리적 포즈)의 도메인 정합성 위반. 영향 행수: 2개 장면(02008, 02009)의 시도 행이 물리적으로 불가능한 성공 상태로 영구 기록됨. 복구 가능성: event_store 원천 데이터는 유효하나, 기존 투영 로직이 정합성 검사를 누락하여 재투영 시 새 규칙 적용 필요.

### 기대-실측 델타 근거

- (반려동물용품_CR01_강아지공룡알장난감_02008#1, `robotTf` / robotTfTranslation) 관측 `1.5` vs 기준 `robotTfTranslationZ_workspace` [0.95, 1.15] m → 델타 0.35m (upper bound exceeded) · gripSucceed=1 but Z translation outside workspace, physically unreachable grasp
- (반려동물용품_CR01_강아지공룡알장난감_02009#1, `grip3dPose` / grip3dPose) 관측 `0.39799954290582784` vs 기준 `grip3dPoseZ_depth` [0.01, 0.30] m → 델타 0.09799954290582784m (upper bound exceeded) · gripSucceed=1 but Z depth outside graspable range, physically impossible success

### 관찰

- 반려동물용품_CR01_강아지공룡알장난감_02008#1: gripSucceed=1인데 robotTfTranslationZ=1.5가 작업범위 [0.95, 1.15]m 밖으로 이탈.
- 반려동물용품_CR01_강아지공룡알장난감_02009#1: gripSucceed=1인데 grip3dPoseZ(z1~z8)가 파지 가능 깊이 [0.01, 0.30]m 밖으로 이탈.
- 프로젝터가 물리적 불가능성(gripSucceed=1 but unreachable pose)을 감지해 에러로 차단하지 않고 경고만 남기고 투영함.

### 영향 범위

- event_store(GripAttemptRecorded) → grip-result-projector(map/upsert) → read_grip_result(grip_succeed, robot_tf, grip_3d_pose 컬럼) → ProjectionController(POST /projection/grip-result) → API v1(read_grip_result 조회 엔드포인트)

### 근본원인 — projectionOrPipelineFault

1. Why: gripSucceed=1인데 robotTfTranslationZ와 grip3dPoseZ가 물리적 한계를 벗어나 성공으로 기록됨.
2. Why: 투영 로직(map)에서 이벤트 매핑 후 Read Model에 직접 upsert하며 값 검증 없이 저장함.
3. Why: Zod 스키마(toyDataSchema)는 타입과 배열 길이만 검증하고, gripSucceed와 포즈 간 물리적 정합성(gripSucceed_poseConsistency) 규칙을 포함하지 않음.
4. Why: 프로젝트 초기 구조 검증(zod)에 집중하다 도메인 규칙(물리적 불가능성 차단)을 정합성 검사(checkIntegrity) 단계로 분리하지 못함.
5. Why: Read Model 스키마에 외래키나 CHECK 제약 대신 애플리케이션 레이어에서 도메인 규칙을 강제해야 한다는 아키텍처 원칙이 GripResultProjector에 구현되지 않음.

### 의사결정 기준

- 데이터 정합성 보장 수준 (물리적 모순 차단 여부)
- 기존 파이프라인 변경 범위 (프로젝터 수정 vs Read Model 스키마 변경)
- 운영 중단/재투영 비용 (기존 오염 데이터 처리 및 재처리 필요성)
- 유지보수성 (규칙 중앙화 vs 분산 검증)

#### [fix] 프로젝터 정합성 검사 추가 및 재투영

```sql
checkIntegrity(row: ReadGripResultInsert): IntegrityViolation[] {
  const violations: IntegrityViolation[] = [];
  if (row.gripSucceed === 1) {
    const tf = row.robotTf as { translation_3x1: number[] };
    const pose = row.grip3dPose as { z1: number; z8: number };
    const zTrans = tf?.translation_3x1[2];
    if (zTrans !== undefined && (zTrans < 0.95 || zTrans > 1.15)) {
      violations.push({ readModelName: 'read_grip_result', sceneKey: row.sceneKey, attemptNum: row.attemptNum, streamId: row.streamId, globalSeq: row.globalSeq, ruleName: 'gripSucceed_poseConsistency', affectedColumns: ['robot_tf'], observedValue: String(zTrans), expected: '[0.95, 1.15] m', detail: 'gripSucceed=1 but robotTfTranslationZ outside workspace.' });
    }
    if (pose?.z1 !== undefined && (pose.z1 < 0.01 || pose.z1 > 0.30)) {
      violations.push({ readModelName: 'read_grip_result', sceneKey: row.sceneKey, attemptNum: row.attemptNum, streamId: row.streamId, globalSeq: row.globalSeq, ruleName: 'gripSucceed_poseConsistency', affectedColumns: ['grip_3d_pose'], observedValue: String(pose.z1), expected: '[0.01, 0.30] m', detail: 'gripSucceed=1 but grip3dPoseZ outside graspable depth.' });
    }
  }
  return violations;
}
```

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripResultV2 } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripResultV2Insert = InferInsertModel<typeof readGripResultV2>;

const WORKSPACE_Z_MIN = 0.95;
const WORKSPACE_Z_MAX = 1.15;
const DEPTH_Z_MIN = 0.01;
const DEPTH_Z_MAX = 0.30;

@Injectable()
export class GripResultV2Projector implements Projector<ReadGripResultV2Insert> {
  readonly name: string = "grip-result-v2-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripResultV2Projector.name);
  }

  map(event: EventStoreEventRow): ReadGripResultV2Insert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    if (payload.objects.length === 0) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
        },
        "objects 비어 있음",
      );

      throw new Error(
        `grip-result-v2 map: empty objects in event ${event.eventId}`,
      );
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    const sceneKey = event.streamId.replace(/^grip-attempt:/, "");
    let gripOutlierFlag = 0;
    let poseConsistencyStatus = "normal";

    if (payload.grip_succeed === 1) {
      const robotTfZ = payload.robot_tf.translation_3x1[2];

      if (robotTfZ < WORKSPACE_Z_MIN || robotTfZ > WORKSPACE_Z_MAX) {
        gripOutlierFlag = 1;
        poseConsistencyStatus = "workspace_z_violation";
      } else {
        const zValues: number[] = [
          payload.grip_data.grip_3d_pose.z1,
          payload.grip_data.grip_3d_pose.z2,
          payload.grip_data.grip_3d_pose.z3,
          payload.grip_data.grip_3d_pose.z4,
          payload.grip_data.grip_3d_pose.z5,
          payload.grip_data.grip_3d_pose.z6,
          payload.grip_data.grip_3d_pose.z7,
          payload.grip_data.grip_3d_pose.z8,
        ];

        const hasDepthViolation = zValues.some(
          (z) => z < DEPTH_Z_MIN || z > DEPTH_Z_MAX,
        );

        if (hasDepthViolation) {
          gripOutlierFlag = 1;
          poseConsistencyStatus = "depth_z_violation";
        }
      }
    }

    return {
      sceneKey,
      attemptNum: event.attemptNum,
      objectName: payload.objects[0].class_name,
      gripSucceed: payload.grip_succeed,
      gripperType: "finger",
      occurredAt: event.occurredAt,
      grip2dPose: payload.grip_data.grip_2d_pose,
      grip3dPose: payload.grip_data.grip_3d_pose,
      robotTf: payload.robot_tf,
      humanAnnotationGrasp: payload.human_annotation_grasp,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
      gripOutlierFlag,
      poseConsistencyStatus,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripResultV2Insert): Promise<void> {
    await tx
      .insert(readGripResultV2)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripResultV2.sceneKey, readGripResultV2.attemptNum],
        set: {
          objectName: row.objectName,
          gripSucceed: row.gripSucceed,
          gripperType: row.gripperType,
          occurredAt: row.occurredAt,
          grip2dPose: row.grip2dPose,
          grip3dPose: row.grip3dPose,
          robotTf: row.robotTf,
          humanAnnotationGrasp: row.humanAnnotationGrasp,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
          gripOutlierFlag: row.gripOutlierFlag,
          poseConsistencyStatus: row.poseConsistencyStatus,
        },
      });
  }
}
```

```typescript
      target: [readGripResultV2.sceneKey, readGripResultV2.attemptNum],
      set: { ...row },

    if (row.gripSucceed !== 1) return violations;

    const robotTf = row.robotTf as { translation_3x1: number[] } | null;
    if (robotTf?.translation_3x1) {

    if (grip3dPose) {

      for (const key of zKeys) {
        const z = grip3dPose[key];

            expected: `[${DEPTH_Z_MIN}, ${DEPTH_Z_MAX}]`,
            detail: `read_grip_result_v2 정합성 위반[gripSucceed_poseConsistency]: gripSucceed=1(성공)인데 grip3dPoseZ(${key})=${z} 파지 가능 깊이 [${DEPTH_Z_MIN}, ${DEPTH_Z_MAX}]m 밖 — 닿지 않는 깊이에서 성공은 모순.`,
          });
        }
      }
    }

    return violations;
  }

  toSensorValueMessages(rows: ReadGripResultV2Insert[]): SensorValueMessage[] {
    return rows.map((row) => ({

      attemptNumber: row.attemptNum,
```

```typescript
import { Injectable } from '@nestjs/common';
import { PinoLogger } from 'nestjs-pino';
import { InsertResult, InsertService } from '@/insert/insert.service';
import { GripResultProjector } from '@/projection/projector/grip-result.projector';
import { GripResultV2Projector } from '@/projection/projector/grip-result-v2.projector';
import { MultiModalProjector } from '@/projection/projector/multimodal.projector';
import { ProjectionResult } from '@/projection/projector/projector';
import { CatchUpRunner } from '@/projection/runner/catch-up.runner';
import { LogAction } from '@/shared/logger/logging-context';

export type CatchUpAllResult = {
  multimodal: ProjectionResult;
  gripResult: ProjectionResult;
  gripResultV2: ProjectionResult;
};

export type InsertAndProjectionAllResult = {
  insert: InsertResult;
  projection: CatchUpAllResult;
};

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly gripResultV2: GripResultV2Projector,
    private readonly insertService: InsertService,
  ) {

  }

    return this.runner.run(this.multimodal);
  }

  catchUpGripResult(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResult);
  }

  catchUpGripResultV2(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResultV2);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();
    const gripResultV2: ProjectionResult = await this.catchUpGripResultV2();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult, gripResultV2 };
  }

  async insertAllAndProjectAll(): Promise<InsertAndProjectionAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 적재+투영 시작");

    const insert: InsertResult = await this.insertService.insertToyData();
    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 적재+투영 완료");

    return { insert, projection };
  }
}
```
