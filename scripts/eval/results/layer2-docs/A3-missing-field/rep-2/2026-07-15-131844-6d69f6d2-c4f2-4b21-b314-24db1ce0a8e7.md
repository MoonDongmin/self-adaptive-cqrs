Zod Schema Relaxation & Projector Fallback — 기존 파이프라인을 최소 변경으로 실패 파일의 배치 중단을 방지하고 정합성 검증을 통과한 데이터는 기존 Read Model에 정상 투영 가능.

### Consequences
- (+) 배치 처리 가용성 확보: 실패 파일이 전체 배치 흐름을 차단하지 않음.
- (+) 기존 Read Model 호환성 유지: read_grip_result 및 read_multimodal 구조 변경 없이 동작.
- (+) 개발/운영 부담 최소화: 검증 로직 단순화 및 재투영 비용 발생 안 함.
- (−) 하위 시스템 처리 부담 증가: grip_data 또는 robot_tf가 빈 구조로 투영될 경우 조회 API 또는 분석 파이프라인에서 null/빈 배열 분기 처리 필요.
- (−) 데이터 품질 관점의 모호성: 필수 필드 누락이 허용됨에 따라 일부 행이 부분적 정보만 보유하게 됨.

### Non-Goals
- read_multimodal의 image2dUri, video_uri URI 매핑 로직 변경
- 성공적으로 적재된 파일의 기존 투영 경로 수정
- 이벤트 스토어 원본 데이터 수정 또는 재발행
