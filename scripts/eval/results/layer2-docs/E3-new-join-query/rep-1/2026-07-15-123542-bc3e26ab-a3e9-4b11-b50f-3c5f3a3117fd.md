| GripAttemptRecorded | grip_data.grip_2d_pose | grip2dPose | verbatim |
| GripAttemptRecorded | grip_data.grip_3d_pose | grip3dPose | verbatim |
| GripAttemptRecorded | human_annotation_grasp | humanAnnotationGrasp | verbatim |
| GripAttemptRecorded | 2D_image_file_name | image2dFileName | verbatim |
| GripAttemptRecorded | video_file_name | videoFileName | verbatim |

파생 컬럼(이벤트 payload 아님):
- `sceneKey` ← stream_id에서 'grip-attempt:' 접두사 제거
- `gripperType` ← 상수 'finger' 할당 (현재 고정)
- `occurredAt` ← event.metadata.occurredAt 매핑
- `robotTf` ← payload.robot_tf.rotation_3x3와 translation_3x1을 단일 jsonb 객체로 병합
- `streamId` ← event.metadata.streamId 매핑
- `globalSeq` ← event.metadata.globalSeq 매핑

## 3. API Versioning

> 실행 게이트: 아래 변경은 인간 승인 후에만 적용한다 (human-in-the-loop).

### Unreleased (v1 → v2)

#### Added
- 신규 Read Model `read_grip_with_multimodal_v2` 및 전용 프로젝터(`GripWithMultimodalV2Projector`) 배선
- `POST /projection/v2/grip-with-multimodal` 엔드포인트 추가
#### Changed
- `ProjectionService`에 v2 프로젝터 주입 및 `catchUpGripWithMultimodalV2` 메서드 추가

### 마이그레이션 절차

- 하위호환 변경: 기존 v1 테이블 및 엔드포인트는 수정·삭제되지 않음; v2 프로젝트는 독립적인 커서와 시퀀스를 사용하므로 기존 투영 파이프라인과 충돌 없음
- 파괴적 변경: 없음
- 컷오버 전 테스트: - v2 프로젝터가 v1 데이터 기준 최신 시퀀스까지 정상적으로 catch-up하는지 확인
- POST /projection/v2/grip-with-multimodal 호출 시 read_grip_result과 read_multimodal의 조인 결과가 누락 없이 반환되는지 검증
- 동일 stream_id/attempt_num에 대해 v1과 v2 행의 occurred_at 및 global_seq 일관성 확인
- 롤백 창/조건: - v2 엔드포인트 비활성화 및 라우팅 규칙 revert
- read_grip_with_multimodal_v2 테이블 DROP (데이터 보존 필요 시 별도 백업)
- 기존 v1 Read Model 재시동으로 즉시 복구 가능 (컷오버 전까지 병렬 운영 보장)
- Insight 카드 등록: §2의 카드 등록 SQL을 DDL과 함께 적용(카탈로그 동기화)

### 사유·호환성

- 사유: 기존 v1 Read Model(read_grip_result, read_multimodal)은 파지 결과와 미디어 경로를 별도 테이블로 분리하여 저장한다. 이로 인해 프론트엔드 Insight 카드 렌더링 시 두 테이블을 조인하거나 별도 호출해야 하며, 현재 시스템은 통합 뷰를 지원하지 않아 동일 요청이 3회 연속 miss로 처리되었다 [corr:bc3e26ab-a3e9-4b11-b50f-3c5f3a3117fd]. v2는 파지 결과와 해당 시도의 2D 이미지·비디오 경로를 단일 행으로 통합하여 조인 오버헤드와 누락 없이 즉시 조회할 수 있도록 설계되었다.
- 트리거 근거: 03:35:42.421 | 40 | insight.card.miss | bc3e26ab-a3e9-4b11-b50f-3c5f3a3117fd | insight 카드 없음: 파지 결과와 해당 시도의 이미지·영상 경로를 한 화면에서 함께 보고 싶다.
- v1 호환성: 기존 read_grip_result, read_multimodal 테이블 및 프로젝트는 수정·삭제되지 않으며 v1 레거시 레인에서 계속 동작한다. v2는 신규 테이블(read_grip_with_multimodal_v2)과 전용 프로젝터로 독립 실행되며, 컷오버 전까지 병렬 운영 가능하다.

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripWithMultimodal } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripWithMultimodalInsert = InferInsertModel<typeof readGripWithMultimodal>;

@Injectable()
export class GripWithMultimodalProjector implements Projector<ReadGripWithMultimodalInsert> {
  readonly name: string = "grip-with-multimodal-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripWithMultimodalProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripWithMultimodalInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    if (payload.objects.length === 0) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
        },
        "objects 비어 있음",
      );

      throw new Error(
        `grip-with-multimodal map: empty objects in event ${event.eventId}`,
      );
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      objectName: payload.objects[0].class_name,
      gripSucceed: payload.grip_succeed,
      gripperType: "finger",
      occurredAt: event.occurredAt,
      grip2dPose: payload.grip_data.grip_2d_pose,
      grip3dPose: payload.grip_data.grip_3d_pose,
      robotTf: payload.robot_tf,
      humanAnnotationGrasp: payload.human_annotation_grasp,
      image2dFileName: payload["2D_image_file_name"],
      videoFileName: payload.video_file_name,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripWithMultimodalInsert): Promise<void> {
    await tx
      .insert(readGripWithMultimodal)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripWithMultimodal.sceneKey, readGripWithMultimodal.attemptNum],
        set: {
          objectName: row.objectName,
          gripSucceed: row.gripSucceed,
          gripperType: row.gripperType,
          occurredAt: row.occurredAt,
          grip2dPose: row.grip2dPose,
          grip3dPose: row.grip3dPose,
          robotTf: row.robotTf,
          humanAnnotationGrasp: row.humanAnnotationGrasp,
          image2dFileName: row.image2dFileName,
          videoFileName: row.videoFileName,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```
