## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 40, `payload.schema.drift`) payload 에 스키마가 모르는 신규 키 유입 — 적재 시 필드 유실됨(Read Model 후보) ← 트립 앵커 → Zod DTO 스키마 미비로 신규 키 conveyor_speed, gripper_temperature 가 적재 시 자동 유실(drop) 경고 발생, Read Model 영입 실패. [corr:acd29ed6-c855-4f2f-89e0-ec110e7b48df]
- Insight 카드 read_grip_result 및 read_multimodal 에 conveyor_speed, gripper_temperature 컬럼 부재.
- src/insert/dto/toy-data.dto.ts 의 toyDataSchema 에 해당 키 미등록, Zod parse 시 자동 필터링(filter) 발생.
- src/projection/projector/grip-result.projector.ts 의 map() 메서드 에 conveyor_speed, gripper_temperature 매핑 로직 부재.
- 기존 read_grip_result 테이블 스키마(src/shared/database/schema/service/read-grip-result.ts) 에 환경 파라미터 컬럼 미비.

### Decision Drivers
- payload drift 감지 → 신규 Read Model 생성 우선 검토(drift trigger lane)
- Zod DTO 스키마 미비 → 필드 유실(drop) 방지 및 정밀 영입 필요
- API/Read Model 확ansion → 버전 관리(versionSwitch) 동반 필수
- 결함 격리(무유입 검증) → 신규 테이블 미정립 상태 확인 및 재실행 안전성 확보

### Considered Options
#### newReadModel
- 접근: src/projection/projector/grip-result.projector.ts map() 확ansion + src/shared/database/schema/service/read-grip-env-params.ts Drizzle 테이블 생성.
- 제안 필드: conveyor_speed, gripper_temperature
- 트레이드오프: DB扩容 비용, projection 재실행 필요.
```typescript
return { ...row, sceneKey: event.streamId.replace(/^grip-attempt:/, ""), attemptNum: event.attemptNum, occurredAt: event.occurredAt, conveyorSpeed: payload.conveyor_speed ?? null, gripperTemperature: payload.gripper_temperature ?? null };
```

#### existingBoost
- 접근: src/shared/database/schema/service/read-grip-result.ts 기존 테이블 컬럼 추가 + map() 수정.
- 제안 필드: conveyor_speed, gripper_temperature
- 트레이드오프: 스키마 변경으로 projection 재실행/데이터 마이그레이션 필요, 정합성 검사 수정.
```typescript
gripperType: varchar("gripper_type", { length: 16 }).notNull(), conveyorSpeed: numeric("conveyor_speed"), gripperTemperature: numeric("gripper_temperature"),
```

### Decision Outcome
newReadModel (기존 Read Model 확ansion으로 인한 projection 재실패 및 정합성 검사 수정 부담이 크나, 신규 테이블 생성이 schema drift 격리 lane 규칙에 부합且 기존 pipeline 무해화).

### Consequences
- (+) 신규 환경 파라미터 정밀 영입
- (+) schema drift 격리
- (+) 데이터 무결성 충족
- (−) DB扩容 비용
- (−) projection 재실행(catch-up) 필요
- (−) DTO 스키마 수정으로 기존 pipeline 영향

### Non-Goals
- Zod coerce/defaults 치환 권고
- 기존 Read Model 컬럼 확장(기각 대안)
- poison event rollback 커서 점프

## 2. Read Model 생성 SQL (Read Model DDL)

> 실행 게이트: 아래 변경은 인간 승인 후에만 적용한다 (human-in-the-loop).

- 대상: `read_grip_env_params` · 키: scene_key, attempt_num · 원천 이벤트: GripAttemptRecorded

```sql
CREATE TABLE read_grip_env_params (
  scene_key varchar NOT NULL,
  attempt_num smallint NOT NULL,
  occurred_at timestamptz,
  conveyor_speed numeric,
  gripper_temperature numeric,
  PRIMARY KEY (scene_key, attempt_num)
);
```

### 필드

```mschema
# Table: read_grip_env_params
[
(scene_key:varchar, 장면 식별 키 = stream_id 제거 prefix, Primary Key),
(attempt_num:smallint, 동일 장면 내 파지 시도 번호, Primary Key),
(occurred_at:timestamptz, 데이터 촬영 일자),
(conveyor_speed:numeric, 컨네어 벨트 속도 (payload drift 신규 키)),
(gripper_temperature:numeric, 그리퍼 온도 (payload drift 신규 키))
]
```

### 투영 매핑 명세 (이벤트 → 컬럼)

> upsert 키: scene_key, attempt_num · 리플레이: projection_cursor 초기화 시 global_seq=0 설정. catch-up 전 재투영 시 upsert 전제(idempotent) 필수로 중복 키 충돌 방지.

| 원천 이벤트 | payload 필드 | 컬럼 | 변환 |
| --- | --- | --- | --- |
| GripAttemptRecorded | conveyor_speed | conveyor_speed | string → numeric 캐스팅 |
| GripAttemptRecorded | gripper_temperature | gripper_temperature | string → numeric 캐스팅 |

파생 컬럼(이벤트 payload 아님):
- `scene_key` ← stream_id prefix 'grip-attempt:' 제거
- `attempt_num` ← stream_id 또는 file_name 시도번호 추출 (예: _01_)
- `occurred_at` ← stream_id 또는 file_name 날짜(YYYYMMDD) → ISO timestamp 변환

import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripEnvParamsInsert = InferInsertModel<typeof readGripEnvParams>;

// Local extended schema for type safety in this projector file.
const envPayloadSchema = toyDataSchema.extend({
  conveyor_speed: z.coerce.number().optional(),
  gripper_temperature: z.coerce.number().optional(),
});

type EnvPayloadDto = z.infer<typeof envPayloadSchema>;

@Injectable()
export class GripEnvParamsProjector implements Projector<ReadGripEnvParamsInsert> {
  readonly name: string = "grip-env-params-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripEnvParamsProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripEnvParamsInsert {
    let payload: EnvPayloadDto; // Fixed type to include extended fields
    try {
      payload = envPayloadSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      occurredAt: event.occurredAt,
      conveyorSpeed: payload.conveyor_speed, // Now accessible via EnvPayloadDto
      gripperTemperature: payload.gripper_temperature, // Now accessible via EnvPayloadDto
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripEnvParamsInsert): Promise<void> {
    await tx
      .insert(readGripEnvParams)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripEnvParams.sceneKey, readGripEnvParams.attemptNum],
        set: {
          occurredAt: row.occurredAt,
          conveyorSpeed: row.conveyorSpeed,
          gripperTemperature: row.gripperTemperature,
        },
      });
  }
}

import { Injectable } from '@nestjs/common';
import { PinoLogger } from 'nestjs-pino';
import { InsertResult, InsertService } from '@/insert/insert.service';

  gripEnvParams: ProjectionResult;

    private readonly gripResult: GripResultProjector,

    private readonly gripEnvParams: GripEnvParamsProjector,

  }

  catchUpGripResult(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResult);
  }

  catchUpGripEnvParams(): Promise<ProjectionResult> {
    return this.runner.run(this.gripEnvParams);
  }

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();
    const gripEnvParams: ProjectionResult = await this.catchUpGripEnvParams();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    this.logger.info(
      { action: LogAction.PROJECTION_START },
      "전체 적재+투영 시작",

    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
}
