## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 40, `payload.schema.drift`) payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) ← 트립 앵커 → 기존 Zod DTO 미적 발견으로 신규 키 conveyor_speed, gripper_temperature 유입 감지, 투영 단계 데이터 유실 경고 발생. [corr:a9a4f6b3-af1d-4377-af8a-07564eb1d25c]
- src/insert/dto/toy-data.dto.ts 의 toyDataSchema 정의에는 conveyor_speed, gripper_temperature 키가 미적 존재하여 Zod strict 검증 시 미적 발견 또는 거절 경로로 신규 센서 값이 payload 객체에서 유실됨 [corr:a9a4f6b3-af1d-4377-af8a-07564eb1d25c]
- 기존 Drizzle 스키마 read_grip_result(src/shared/database/schema/service/read-grip-result.ts) 및 read_multimodal(src/shared/database/schema/service/read-multimodal.ts) 에 미적 sensor 관련 컬럼으로, GripResultProjector.map()(src/projection/projector/grip-result.projector.ts) 과 MultiModalProjector.map() 만 기존 payload 필드 매핑만 수행하여 신규 키가 DB row 유입 단계에서 단절됨 [corr:a9a4f6b3-af1d-4377-af8a-07564eb1d25c]
- ProjectionService.catchUpAll()(src/projection/projection.service.ts) 만 기존 두 프로젝터 실행 로직으로, 신규 센서 데이터 투영 경로 미적 존재 [corr:a9a4f6b3-af1d-4377-af8a-07564eb1d25c]

### Decision Drivers
- Schema Drift Detection: Payload 신규 키 미적 발견 DTO/Read Model 정의.
- Data Preservation Requirement: Sensor data 무해화·유지 원칙 준수( coercion 금지).
- Consistency & Versioning Rule: New Read Model adoption 동반 API version switch.
- Separation of Concerns: Grip result vs sensor data 관심 분리 유지.

### Considered Options
#### newReadModel
- 접근: 확정 설계 read_grip_sensor_v2 테이블 생성, 신규 SensorProjector 구현하여 payload 매핑 수행. ProjectionService 에 추가 실행 로직 연동.
- 제안 필드: conveyor_speed, gripper_temperature
- 트레이드오프: DB migration SQL 실행 필요, API version switch 동반해야 하므로 downstream 클라이언트 정렬 overhead 발생. 데이터 유실 risk 제로, 관심 분리 준수.
```typescript
export class SensorProjector implements Projector<ReadGripSensorV2Insert> { readonly name = "sensor-projector"; map(event: EventStoreEventRow): ReadGripSensorV2Insert { const payload = event.payload as Record<string, unknown>; return { sceneKey: event.streamId.replace(/^grip-attempt:/, ""), attemptNum: event.attemptNum, occurredAt: event.occurredAt, conveyorSpeed: Number(payload.conveyor_speed) || null, gripperTemperature: Number(payload.gripper_temperature) || null, streamId: event.streamId, globalSeq: event.globalSeq }; } ... }
```

#### existingReadModelExtension
- 접근: 기존 read_grip_result Drizzle 스키마 추가 컬럼 연동 및 GripResultProjector.map() 수정.
- 제안 필드: conveyor_speed, gripper_temperature
- 트레이드오프: 관심 분리 위배(그리퍼 결과 vs 센서 데이터), 기존 테이블 migration coupling risk 높음, 정합성 규칙 위반으로 기각 대안.

#### zodCoerceFallback
- 접근: DTO 에 .default(null) 또는 .coerce() 적용.
- 제안 필드: -
- 트레이드오프: 결함 값 무해화 원칙 위조(거절·격리 유지 + 원천 데이터 수정 요청), 권장하지.

### Decision Outcome
newReadModel 채택. 사유: 드리프트 트리거 lane 준수, 센서 데이터 무해화 보장, 관심 분리 및 정합성 규칙 충족.

### Consequences
- (+) Sensor data preserved without coercion
- (+) clear separation of concerns
- (+) version switch ensures consumer alignment
- (−) Requires migration SQL execution
- (−) initial catch-up overhead for new projector
- (−) API version bump affects downstream clients

### Non-Goals
- Modifying existing read_grip_result schema
- coercing Zod rejection to defaults
- handling URI mapping logic (deferred)

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripSensor } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripSensorInsert = InferInsertModel<typeof readGripSensor>;

@Injectable()
export class GripSensorProjector implements Projector<ReadGripSensorInsert> {
  readonly name: string = "grip-sensor-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripSensorProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripSensorInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      occurredAt: event.occurredAt,
      conveyorSpeed: payload.conveyor_speed ?? null,
      gripperTemperature: payload.gripper_temperature ?? null,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripSensorInsert): Promise<void> {
    await tx
      .insert(readGripSensor)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripSensor.sceneKey, readGripSensor.attemptNum],
        set: {
          occurredAt: row.occurredAt,
          conveyorSpeed: row.conveyorSpeed,
          gripperTemperature: row.gripperTemperature,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```

### 버전 교체 코드 — `src/projection/projection.service.ts` (modifyFile)

```typescript
import { Injectable } from '@nestjs/common';
import { PinoLogger } from 'nestjs-pino';
import { InsertResult, InsertService } from '@/insert/insert.service';
import { GripResultProjector } from '@/projection/projector/grip-result.projector';
import { MultiModalProjector } from '@/projection/projector/multimodal.projector';
import { ProjectionResult } from '@/projection/projector/projector';
import { CatchUpRunner } from '@/projection/runner/catch-up.runner';
import { LogAction } from '@/shared/logger/logging-context';
import { GripSensorProjector } from '@/projection/projector/grip-sensor.projector';

export type CatchUpAllResult = {
  multimodal: ProjectionResult;
  gripResult: ProjectionResult;
};

export type InsertAndProjectionAllResult = {
  insert: InsertResult;
  projection: CatchUpAllResult;
};

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly insertService: InsertService,
    private readonly gripSensor: GripSensorProjector,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  catchUpMultimodal(): Promise<ProjectionResult> {
    return this.runner.run(this.multimodal);
  }

  catchUpGripResult(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResult);
  }

  catchUpGripSensor(): Promise<ProjectionResult> {
    return this.runner.run(this.gripSensor);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult };
  }

  async insertAllAndProjectAll(): Promise<InsertAndProjectionAllResult> {
    this.logger.info(
      { action: LogAction.PROJECTION_START },
      "전체 적재+투영 시작",
    );

    const insert: InsertResult = await this.insertService.insertToyData();
    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
}
```
