## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 40, `payload.schema.drift`) payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) ← 트립 앵커 → 적재 단계 Zod 검증에서 미등록 키 감지, 기존 스키마 부재로 필드 유실 발생. [corr:3417bd1b-b403-48eb-bea2-e7028115f59a]
- src/insert/dto/toy-data.dto.ts 의 toyDataSchema 정의에는 conveyor_speed, gripper_temperature 키가 미등재, Zod parse 실패 또는 silent drop 유발.
- 기존 Read Model 스키마(read_grip_result, read_multimodal) 의 실제 컬럼명·의미(예: sceneKey/장면 식별 키, attemptNum/시도 번호, objectName/파지 대상 객체명 등) 에 드리프트 키 부재, 투영(Projector map()) 시 해당 payload 필드 유실.
- 확정된 신규 Read Model 설계(read_grip_attempt_drift) 의 conveyor_speed/gripper_temperature numeric 컬럼이 격리 테이블 매핑 전략을 제시, 기존 프로젝트터(GripResultProjector, MultiModalProjector) 는 미적응 상태.

### Decision Drivers
- Data fidelity preservation (silent loss 방지)
- Schema evolution compatibility (의미적 혼성 배제)
- Projection pipeline integration cost (minimal code change)
- API versioning impact tolerance

### Considered Options
#### 신모델 등록(read_grip_attempt_drift)
- 접근: src/insert/dto/toy-data.dto.ts Zod schema 확으로 drift 키 허용 + 신규 DrizzleTx upsert 로직 연동
- 제안 필드: conveyor_speed, gripper_temperature
- 트레이드오프: DB migration & projector wiring 비용 발생, 기존 Read Model 오염 방지

#### 기각 대안: 기존 모델 확장(read_grip_result)
- 접근: readGripResult Drizzle schema 확으로 drift 키 추가
- 제안 필드: conveyor_speed, gripper_temperature
- 트레이드오프: Driver Schema evolution compatibility 졌음(의미적 혼성), existing query pattern breakage

#### 기각 대안: Zod coerce/defaults
- 접근: z.coerce.number() 적용
- 제안 필드: -
- 트레이드오프: Driver 결함 값 무해화 원칙 위반, 원천 데이터 수정 요청 권고 배제

### Decision Outcome
신모델 등록(read_grip_attempt_drift) - 확정 설계의 정적 타입·SQL 매핑 전략을 적용하여 드리프트 키를 격리 테이블로 투영, 기존 Read Model 오염 방지.

### Consequences
- (+) 신규 키 유입 영구 추적 가능
- (+) 기존 파지/모달 모델 스키마 안정화
- (+) Zod 검증 실패 시 graceful drift routing
- (−) 추가 DB 인덱스·프로젝터 등록 작업 비용 발생
- (−) catch-up 커서 관리로 인한 초기 부하 증가

### Non-Goals
- 기존 read_grip_result/read_multimodal 컬럼 수정
- Zod schema coerce 적용
- API endpoint contract 변경

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { z } from 'zod';
import { toyDataSchema, type ToyDataDto } from '@/insert/dto/toy-data.dto';
import { Projector } from '@/projection/projector/projector';
import { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripAttemptDrift } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

const toyDataDriftSchema = toyDataSchema.extend({
  conveyor_speed: z.coerce.number().optional(),
  gripper_temperature: z.coerce.number().optional(),
});

type ToyDataDtoWithDrift = z.infer<typeof toyDataDriftSchema>;
type ReadGripAttemptDriftInsert = InferInsertModel<typeof readGripAttemptDrift>;

@Injectable()
export class GripAttemptDriftProjector implements Projector<ReadGripAttemptDriftInsert> {
  readonly name: string = "grip-attempt-drift-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripAttemptDriftProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripAttemptDriftInsert {
    let payload: ToyDataDtoWithDrift;
    try {
      payload = toyDataDriftSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      conveyorSpeed: payload.conveyor_speed,
      gripperTemperature: payload.gripper_temperature,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripAttemptDriftInsert): Promise<void> {
    await tx
      .insert(readGripAttemptDrift)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripAttemptDrift.sceneKey, readGripAttemptDrift.attemptNum],
        set: {
          conveyorSpeed: row.conveyorSpeed,
          gripperTemperature: row.gripperTemperature,
        },
      });
  }
}
```

```typescript
import { Injectable } from '@nestjs/common';
import { PinoLogger } from 'nestjs-pino';
import { InsertResult, InsertService } from '@/insert/insert.service';
import { GripResultProjector } from '@/projection/projector/grip-result.projector';
import { MultiModalProjector } from '@/projection/projector/multimodal.projector';
import { GripAttemptDriftProjector } from '@/projection/projector/grip-attempt-drift.projector';
import { ProjectionResult } from '@/projection/projector/projector';
import { CatchUpRunner } from '@/projection/runner/catch-up.runner';
import { LogAction } from '@/shared/logger/logging-context';

export type CatchUpAllResult = {
  multimodal: ProjectionResult;
  gripResult: ProjectionResult;
  drift: ProjectionResult;
};

export type InsertAndProjectionAllResult = {
  insert: InsertResult;
  projection: CatchUpAllResult;
};

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly drift: GripAttemptDriftProjector,
    private readonly insertService: InsertService,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  catchUpMultimodal(): Promise<ProjectionResult> {
    return this.runner.run(this.multimodal);
  }

  catchUpGripResult(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResult);
  }

  catchUpDrift(): Promise<ProjectionResult> {
    return this.runner.run(this.drift);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();
    const drift: ProjectionResult = await this.catchUpDrift();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult, drift };
  }

  async insertAllAndProjectAll(): Promise<InsertAndProjectionAllResult> {
    this.logger.info(
      { action: LogAction.PROJECTION_START },
      "전체 적재+투영 시작",
    );

    const insert: InsertResult = await this.insertService.insertToyData();
    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
}
```
