## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 40, `payload.schema.drift`) newKeys={"conveyor_speed": "1.2", "gripper_temperature": "36.5"} → Zod 검증에서 미정의 conveyor_speed, gripper_temperature 키가 적재 시 유실됨, downstream Read Model/프로젝터 참조 정합성 위협. [corr:d9038e7c-5950-48df-933a-ddca67f7d3bd]
- toyDataSchema (src/insert/dto/toy-data.dto.ts) 미정의 conveyor_speed, gripper_temperature 키로 Zod .parse() 시 unknown keys default 스트리핑 발생. [corr:d9038e7c-5950-48df-933a-ddca67f7d3bd]
- 기존 Insight 카드 read_grip_result, read_multimodal 에 conveyor_speed, gripper_temperature 컬럼 미존재, downstream projection 파이프라인 참조 정합성 위협. [corr:d9038e7c-5950-48df-933a-ddca67f7d3bd]
- GripResultProjector.map() (src/projection/projector/grip-result.projector.ts) 에서 toyDataSchema.parse(event.payload) 실행 시 신규 키 유입이 사전 차단되어 ES 적재에 누락됨. [corr:d9038e7c-5950-48df-933a-ddca67f7d3bd]

### Decision Drivers
- Payload schema drift handling (Zod validation vs data preservation)
- Downstream Read Model integrity & projection consistency
- API versioning impact on existing clients/queries
- Defect value sanitization principle compliance (no coercion/default substitution)

### Considered Options
#### 기존 Zod 스키마 보강 & Read Model 컬럼 확장
- 접근: toyDataSchema 추가 필드 정의, read_grip_result Drizzle schema 확장
- 제안 필드: conveyor_speed, gripper_temperature
- 트레이드오프: 기존 DTO/프로젝터/DB 수정 필요, downstream 호환성 저해 위험
```typescript
export const toyDataSchema = z.object({ ... conveyor_speed: z.string().optional(), gripper_temperature: z.string().optional() });
```

#### 신기 신규 Read Model read_machine_state_v2 생성 & 별도 Projector
- 접근: src/shared/database/schema/service/read-machine-state-v2.ts Drizzle schema 생성, MachineStateProjector 구현, ProjectionService 연계
- 제안 필드: object_name, conveyor_speed, gripper_temperature, occurred_at
- 트레이드오프: 신기 테이블/엔드포인트 도입, API 버전 변경 동반 필요
```typescript
export class MachineStateProjector implements Projector<ReadMachineStateV2Insert> { readonly name = "machine-state-projector"; map(event: EventStoreEventRow): ReadMachineStateV2Insert { const payload = toyDataSchema.parse(event.payload); return { objectName: payload.objects[0].class_name, conveyorSpeed: payload.conveyor_speed ?? null, gripperTemperature: payload.gripper_temperature ?? null, occurredAt: event.occurredAt }; } }
```

### Decision Outcome
신기 신규 Read Model read_machine_state_v2 생성 & 별도 Projector

### Consequences
- (+) Machine state parameters(conveyor_speed, gripper_temperature) 영구히 ES 적재 및 downstream 조회 가능.
- (+) 기존 read_grip_result/read_multimodal 파이프라인 정합성 무해화, projection catch-up 안정화.
- (+) Zod strict validation 원칙 준수, 거절된 값은 격리 테이블로 분리 관리.
- (−) 신기 엔드포인트(POST /projection/machine-state) 도입으로 API 버전 변경 동반 필요.
- (−) ProjectionService 및 Controller 연계 수정 작업 부하 증가.
- (−) ES 커서 재실행 시 read_machine_state_v2 초기화(null) 처리 로직 추가 필요.

### Non-Goals
- 기존 Zod 스키마 .parse() default 스트리핑 동작 변경(예: z.coerce 적용).
- read_grip_result/read_multimodal 테이블 schema 직접 수정.
- 미유입 데이터 강제 치환 또는 정상값 꾸미기.

  value: strings.reduce((acc, str, i) => acc + str + String(values[i] ?? ''), ''),
});

type ReadMachineStateInsert = InferInsertModel<typeof readMachineState>;

@Injectable()
export class MachineStateProjector implements Projector<ReadMachineStateInsert> {
  readonly name: string = "machine-state-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(MachineStateProjector.name);
  }

  map(event: EventStoreEventRow): ReadMachineStateInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (err) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          err,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw err;
    }

    if (payload.objects.length === 0) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
        },
        "objects 비어 있음",
      );

      throw new Error(
        `machine-state map: empty objects in event ${event.eventId}`,
      );
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      objectName: payload.objects[0].class_name,
      conveyorSpeed: payload.conveyor_speed?.toString() ?? null,
      gripperTemperature: payload.gripper_temperature?.toString() ?? null,
      occurredAt: event.occurredAt,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadMachineStateInsert): Promise<void> {
    await tx
      .insert(readMachineState)
      .values(row)
      .onConflictDoUpdate({
        target: [readMachineState.objectName],
        set: {
          // 집계(agg) 모델: onConflictDoUpdate 에서 sql`${테이블.컬럼} + excluded 값` 형태의 누적 갱신
          conveyorSpeed: sql`
            ${readMachineState.conveyorSpeed} || excluded.conveyorSpeed
          `,
          gripperTemperature: sql`
            ${readMachineState.gripperTemperature} || excluded.gripperTemperature
          `,
          occurredAt: row.occurredAt,
        },
      });
  }
}
