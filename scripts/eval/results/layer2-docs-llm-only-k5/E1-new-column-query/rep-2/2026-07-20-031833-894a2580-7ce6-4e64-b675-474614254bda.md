- GripResultProjector.map() (src/projection/projector/grip-result.projector.ts)은 toyDataSchema.parse(event.payload) 후 반환 객체에 온도 필드를 매핑하지 않음.
- insight.card.miss 로그는 해당 필드 조회 요청이 Read Model 미지원으로 실패했음을 확인 [corr:1a7545d0-6d21-4cf4-9b2d-19070287893c].

### Decision Drivers
- 원천 이벤트 데이터 보존 및 재투영 가능성
- 기존 Read Model 변경 범위 및 운영 리스크
- 시간대별 조회 성능 및 확장성 요구사항

### Considered Options
#### 기존 read_grip_result 보강
- 접근: src/shared/database/schema/service/read-grip-result.ts에 gripper_temperature 컬럼 추가, src/insert/dto/toy-data.dto.ts Zod 스키마 확장, GripResultProjector.map()에 필드 할당.
- 제안 필드: gripper_temperature
- 트레이드오프: 기존 테이블 구조 변경으로 재투영(CatchUp) 필요. 변경 범위가 명확하고 조회 쿼리 단순화.
```typescript
export const readGripResult = pgTable("read_grip_result", { ... gripperTemperature: numeric("gripper_temperature"), ... }); // map() return 객체에 temperature: payload.gripperTemperature 추가
```

#### 신규 read_gripper_sensor Read Model 분리
- 접근: 온도 전용 테이블 및 Projector 생성. 기존 grip-result 모델은 변경하지 않음.
- 제안 필드: read_gripper_sensor
- 트레이드오프: 신규 모델 생성 및 조인/복합 조회 필요. 기존 시스템에 영향 최소화하나 운영 복잡도 증가.
```typescript
export const readGripperSensor = pgTable("read_gripper_sensor", { sceneKey: varchar(...), attemptNum: smallint(...), gripperTemperature: numeric("gripper_temperature"), ... });
```

### Decision Outcome
기존 read_grip_result 보강

### Consequences
- (+) 단일 테이블 조회로 쿼리 단순화 및 응답 지연 감소.
- (+) 원천 이벤트 데이터 보존으로 재투영 시 온도 값 완전 복원.
- (+) 운영 파이프라인(Insert/Projection) 변경 최소화.
- (−) 재투영(CatchUp) 시 일시적 DB 부하 및 이벤트 처리 지연 발생.
- (−) Drizzle 마이그레이션 및 Zod 스키마 수정으로 인한 코드 변경 리스크.

### Non-Goals
- 3D 이미지/비디오 URI 매핑 (read_multimodal 보강은 별도 작업).
- 카메라 내부 파라미터 조회 성능 최적화.

### 필드

```mschema

[
(scene_key:varchar, 장면 식별 키 (stream_id에서 prefix 제거), Primary Key),
(attempt_num:smallint, 파지 시도 번호, Primary Key),
```

### 투영 매핑 명세 (이벤트 → 컬럼)

> upsert 키: scene_key, attempt_num · 리플레이: projection_cursor 초기화 시 catch-up 구간 전체 재투영이 필요하며, upsert 전제 하에 멱등성(idempotency)을 보장해야 중복 레코드가 생성되지 않는다.

| 원천 이벤트 | payload 필드 | 컬럼 | 변환 |
| --- | --- | --- | --- |
| GripAttemptRecorded | gripper_temperature | gripper_temperature | verbatim |

파생 컬럼(이벤트 payload 아님):
- `scene_key` ← stream_id에서 'grip-attempt:' 접두사 제거
- `attempt_num` ← 2D_image_file_name 또는 stream_id 말미에서 시도번호 추출 후 smallint 캐스팅
- `occurred_at` ← 2D_image_file_name에서 YYYYMMDD 패턴 추출하여 timestamptz 변환
- `stream_id` ← 이벤트 메타데이터의 stream_id 값 그대로 할당
- `global_seq` ← 이벤트 메타데이터의 ES 전역 시퀀스(global_sequence) 값 그대로 할당

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripperTemp } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripperTempInsert = InferInsertModel<typeof readGripperTemp>;

@Injectable()
export class GripperTempProjector implements Projector<ReadGripperTempInsert> {
  readonly name: string = "gripper-temp-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripperTempProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripperTempInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      occurredAt: event.occurredAt,
      gripperTemperature: payload.gripper_temperature ?? null,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripperTempInsert): Promise<void> {
    await tx
      .insert(readGripperTemp)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripperTemp.sceneKey, readGripperTemp.attemptNum],
        set: {
          occurredAt: row.occurredAt,
          gripperTemperature: row.gripperTemperature,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```

### 버전 교체 코드 — `src/projection/projector/grip-result-v2.projector.ts` (addFile)

```typescript
import { Injectable } from '@nestjs/common';
import type { InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import type { Projector, IntegrityViolation } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripResultV2 } from '@/shared/database/schema/service/read-grip-result-v2';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripResultV2Insert = InferInsertModel<typeof readGripResultV2>;

type GripPayload = {
  grip_succeed: number;
  objects: Array<{ class_name: string }>;
  grip_data: { grip_2d_pose: unknown; grip_3d_pose: unknown };
  robot_tf: unknown;
  human_annotation_grasp: unknown;
  gripper_temperature?: number | null;
};

function isGripPayload(value: unknown): value is GripPayload {
  return (
    typeof value === "object" &&
    value !== null &&
    "grip_succeed" in value &&
    typeof (value as GripPayload).grip_succeed === "number" &&
    Array.isArray((value as GripPayload).objects) &&
    (value as GripPayload).objects.length > 0 &&
    typeof (value as GripPayload).objects[0].class_name === "string" &&
    typeof (value as GripPayload).grip_data === "object" &&
    (value as GripPayload).grip_data !== null &&
    typeof (value as GripPayload).robot_tf === "object" &&
    Array.isArray((value as GripPayload).human_annotation_grasp)
  );
}

@Injectable()
export class GripResultV2Projector implements Projector<ReadGripResultV2Insert> {
  readonly name: string = "grip-result-v2-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripResultV2Projector.name);
  }

  map(event: EventStoreEventRow): ReadGripResultV2Insert {
    if (!isGripPayload(event.payload)) {
      const error = new Error("Invalid payload structure");
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
        },

      );
      throw error;

    this.logger.debug(

        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      objectName: payload.objects[0].class_name,
      gripSucceed: payload.grip_succeed,

      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripResultV2Insert): Promise<void> {
```

```typescript
import { Injectable } from '@nestjs/common';
import { PinoLogger } from 'nestjs-pino';
import { InsertResult, InsertService } from '@/insert/insert.service';
import { GripResultProjector } from '@/projection/projector/grip-result.projector';
import { MultiModalProjector } from '@/projection/projector/multimodal.projector';
import { GripResultV2Projector } from '@/projection/projector/grip-result-v2.projector';
import { ProjectionResult } from '@/projection/projector/projector';
import { CatchUpRunner } from '@/projection/runner/catch-up.runner';
import { LogAction } from '@/shared/logger/logging-context';

export type CatchUpAllResult = {
  multimodal: ProjectionResult;
  gripResult: ProjectionResult;
  gripResultV2: ProjectionResult;
};

export type InsertAndProjectionAllResult = {
  insert: InsertResult;
  projection: CatchUpAllResult;
};

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly insertService: InsertService,
    private readonly gripResultV2: GripResultV2Projector,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  catchUpMultimodal(): Promise<ProjectionResult> {
    return this.runner.run(this.multimodal);
  }

  catchUpGripResult(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResult);
  }

  catchUpGripResultV2(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResultV2);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();
    const gripResultV2: ProjectionResult = await this.catchUpGripResultV2();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult, gripResultV2 };
  }

  async insertAllAndProjectAll(): Promise<InsertAndProjectionAllResult> {
    this.logger.info(
      { action: LogAction.PROJECTION_START },
      "전체 적재+투영 시작",
    );

    const insert: InsertResult = await this.insertService.insertToyData();
    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
}
```
