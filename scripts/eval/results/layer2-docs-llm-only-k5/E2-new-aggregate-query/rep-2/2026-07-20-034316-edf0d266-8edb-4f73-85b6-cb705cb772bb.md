## 3. API Versioning

> 실행 게이트: 아래 변경은 인간 승인 후에만 적용한다 (human-in-the-loop).

### Unreleased (v1 → v2)

#### Added
- read_grip_result_v2 테이블(object_name PK, total_attempts, success_count, success_rate) 및 GripResultV2Projector 구현
- POST /projection/v2/grip-result 엔드포인트 추가
#### Changed
- ProjectionService에 GripResultV2Projector DI 배선 및 catchUpAll/catchUpGripResultV2 메서드 추가
- CatchUpAllResult 타입에 gripResultV2 필드 추가

### 마이그레이션 절차

- 하위호환 변경: 기존 read_grip_result 테이블 및 GripResultProjector(v1)은 수정/삭제되지 않음; 기존 /projection/grip-result 엔드포인트는 v1 원시 데이터 조회를 계속 제공
- 파괴적 변경: 없음
- 컷오버 전 테스트: 1. v2 프로젝터 단위 테스트: map()이 payload.objects[0].class_name을 objectName으로 추출하고, upsert()가 SQL 증분 연산(totalAttempts+1, successCount+=succeed)을 정확히 적용하는지 검증
2. 통합 테스트: POST /projection/v2/grip-result 호출 후 read_grip_result_v2 테이블에 object_name별 집계 행이 생성되고, 동일 object_name 이벤트 재처리 시 successRate가 정확히 갱신되는지 확인
3. Insight 카드 연동 테스트: v2 테이블 조회 API를 호출하여 시도 수/성공 수/성공률이 0이 아닌 정수 및 0.0~1.0 범위 float로 반환되는지 검증
- 롤백 창/조건: 컷오버 전 v2 테이블에 인덱스(idx_grip_result_v2_object) 추가 완료. 롤백 시 /projection/v2/grip-result 라우트 비활성화 및 v2 프로젝터 DI 제거. read_grip_result_v2 테이블은 DROP TABLE로 즉시 해제 가능하며, v1 원시 데이터는 영향 없음. 롤백 창: 컷오버 후 24시간 내 v1 라우트로 회귀 가능.
- Insight 카드 등록: §2의 카드 등록 SQL을 DDL과 함께 적용(카탈로그 동기화)

### 사유·호환성

- 사유: 기존 v1(GripResultProjector)은 payload.objects[0].class_name만 매핑하여 scene_key+attempt_num 기반의 원시 행을 저장할 뿐, object_name별 집계 로직이 없습니다. 클라이언트가 객체 단위 파지 성공률(시도 수, 성공 수, 성공률)을 조회할 때 insight.card.miss가 발생하며 [corr:edf0d266-8edb-4f73-85b6-cb705cb772bb] 로그에서 명확히 확인됩니다. v2는 object_name을 PK로 하는 집계 테이블에 증분 upsert를 수행하여 실시간 집계를 제공합니다.
- 트리거 근거: 18:43:16.641 | 40 | insight.card.miss | edf0d266-8edb-4f73-85b6-cb705cb772bb | insight 카드 없음: 객체(object_name)별 파지 성공률을 한 번에 조회하고 싶다. 시도 수, 성공 수, 성공률이 필요하다.
- v1 호환성: v1(read_grip_result)은 scene_key+attempt_num을 PK로 하는 원시 시도 단위 테이블로 완전히 보존됩니다. v2는 object_name별 집계 전용 테이블로 독립적으로 운영되며, 두 모델은 동시 존재 가능합니다.

```ts
import { Injectable } from '@nestjs/common';
import { InferInsertModel, sql } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readObjectGripStats } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadObjectGripStatsInsert = InferInsertModel<typeof readObjectGripStats>;

@Injectable()
export class ObjectGripStatsProjector implements Projector<ReadObjectGripStatsInsert> {
  readonly name: string = "object-grip-stats-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(ObjectGripStatsProjector.name);
  }

  map(event: EventStoreEventRow): ReadObjectGripStatsInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    if (payload.objects.length === 0) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
        },
        "objects 비어 있음",
      );

      throw new Error(
        `object-grip-stats map: empty objects in event ${event.eventId}`,
      );
    }

    const objectName = payload.objects[0].class_name;
    const isSucceed = payload.grip_succeed === 1;

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      objectName,
      totalAttempts: 1n,
      successCount: isSucceed ? 1n : 0n,
      failureCount: isSucceed ? 0n : 1n,
      lastUpdated: event.occurredAt,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadObjectGripStatsInsert): Promise<void> {
    await tx
      .insert(readObjectGripStats)
      .values(row)
      .onConflictDoUpdate({
        target: [readObjectGripStats.objectName],
        set: {
          totalAttempts: sql`total_attempts + ${row.totalAttempts}`,
          successCount: sql`success_count + ${row.successCount}`,
          failureCount: sql`failure_count + ${row.failureCount}`,
          lastUpdated: row.lastUpdated,
        },
      });
  }
}
```

      );

      throw error;
    }

    if (payload.objects.length === 0) {
      this.logger.error(
        { action: LogAction.MAP_FAILED, [LogContext.EVENT_ID]: event.eventId },
        "objects 비어 있음",
      );

      throw new Error(`grip-result-v2 map: empty objects in event ${event.eventId}`);
    }

    this.logger.debug(
      { action: LogAction.EVENT_MAPPED, [LogContext.PROJECTOR_NAME]: this.name },
      "이벤트 매핑",
    );

    const objectName = payload.objects[0].class_name;
    const succeed = payload.grip_succeed;

    return { objectName, totalAttempts: 1n, successCount: BigInt(succeed), successRate: succeed.toString() };
  }

  async upsert(tx: DrizzleTx, row: ReadGripResultV2Insert): Promise<void> {
    await tx.insert(readGripResultV2)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripResultV2.objectName],

          totalAttempts: sql`${readGripResultV2.totalAttempts} + 1`,
          successCount: sql`${readGripResultV2.successCount} + ${row.successCount}`,
          successRate: sql`CASE WHEN (${readGripResultV2.totalAttempts} + 1) = 0 THEN '0.0000'::numeric ELSE (${readGripResultV2.successCount} + ${row.successCount}) / (${readGripResultV2.totalAttempts} + 1) END`,
        },
      });
  }
