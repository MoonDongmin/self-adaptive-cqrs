### Considered Options
#### 신규 집계 Read Model read_object_grip_stats 생성 및 병행 투영
- 접근: src/shared/database/schema/service/read-object-grip-stats.ts에 신규 Drizzle 테이블 정의. GripResultProjector.map()에서 원시 행 투영과 함께 object_name별 집계 값을 계산하여 신규 테이블에 upsert.
- 제안 필드: objectName, totalAttempts, successCount, successRate
- 트레이드오프: 집계 쿼리 성능이 최적화되고 정합성이 높으나 프로젝트터 로직 복잡도가 증가하고 재투영 시 집계 값 갱신 비용이 발생.
```typescript
// src/shared/database/schema/service/read-object-grip-stats.ts
import { bigint, pgTable, primaryKey, smallint, varchar } from 'drizzle-orm/pg-core';
export const readObjectGripStats = pgTable("read_object_grip_stats", {
  objectName: varchar("object_name").notNull(),
  totalAttempts: smallint("total_attempts").notNull().default(0),
  successCount: smallint("success_count").notNull().default(0),
  successRate: varchar("success_rate", { length: 16 }).notNull().default("0.00"),
  updatedAt: bigint("updated_at", { mode: "number" }).notNull(),
}, (t) => [primaryKey({ columns: [t.objectName] })]);

// src/projection/projector/grip-result.projector.ts (map/upsert 일부)
const statsRow = { objectName: payload.objects[0].class_name, totalAttempts: 1, successCount: payload.grip_succeed, successRate: payload.grip_succeed === 1 ? "1.00" : "0.00", updatedAt: Date.now() };
await tx.insert(readObjectGripStats).values(statsRow).onConflictDoUpdate({ target: [readObjectGripStats.objectName], set: { totalAttempts: readObjectGripStats.totalAttempts + 1, successCount: readObjectGripStats.successCount + payload.grip_succeed, successRate: (readObjectGripStats.successCount + payload.grip_succeed) / (readObjectGripStats.totalAttempts + 1).toFixed(2), updatedAt: Date.now() } });
```

#### 기존 read_grip_result 기반 SQL View 생성
- 접근: 데이터베이스에 read_object_grip_stats_view 생성. 프로젝트터 코드 변경 없이 View를 통해 집계 조회.
- 제안 필드: objectName, totalAttempts, successCount, successRate
- 트레이드오프: 코드 변경 비용이 최소화되지만 View 기반 집계는 실시간 정합성 보장력이 낮고 대용량 원시 데이터 증가 시 쿼리 성능이 저하될 수 있음.
```typescript
CREATE OR REPLACE VIEW read_object_grip_stats_view AS
SELECT object_name, COUNT(*) AS total_attempts, SUM(grip_succeed) AS success_count,
       ROUND(SUM(grip_succeed)::numeric / COUNT(*), 2) AS success_rate
FROM read_grip_result GROUP BY object_name;
```
