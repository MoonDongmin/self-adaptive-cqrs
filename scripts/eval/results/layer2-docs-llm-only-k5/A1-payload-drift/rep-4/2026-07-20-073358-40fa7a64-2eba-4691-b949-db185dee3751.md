## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 40, `payload.schema.drift`) payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) ← 트립 앵커 → toyDataSchema의 엄격한 검증이 신규 키를 즉시 거부하여 이벤트 저장 단계에서 차단됨에 따라, read_grip_result와 read_multimodal 투영이 아예 발생하지 못한 Read Model 부재(신규 키 매핑 미구현)를 드러냄. [corr:40fa7a64-2eba-4691-b949-db185dee3751]
- src/insert/dto/toy-data.dto.ts의 toyDataSchema는 .passthrough() 또는 .catch() 없이 정의되어, 정의되지 않은 키가 payload에 포함되면 즉시 Zod 검증 실패를 발생시킴. 이로 인해 GripResultProjector.map()과 MultiModalProjector.map()에서 throw error가 실행되어 투영 파이프라인이 중단됨. [corr:40fa7a64-2eba-4691-b949-db185dee3751]
- 현재 read_grip_result의 object_name, grip_succeed, gripper_type 등 핵심 컬럼은 payload.objects[0].class_name 등에서 매핑되나, 스키마 드리프트로 인해 payload 자체가 저장소에서 차단되어 Read Model 행이 생성되지 않음. [corr:40fa7a64-2eba-4691-b949-db185dee3751]
- read_multimodal의 image_2d_uri, video_uri는 이미 null로 고정되어 있으나, 본 사안은 신규 키 유입으로 인한 전체 적재 차단이므로 URI 매핑 보강보다 검증 유연화 또는 신규 키 격리 컬럼 추가가 선행되어야 함. [corr:40fa7a64-2eba-4691-b949-db185dee3751]

### Decision Drivers
- 데이터 무결성 및 드리프트 대응력
- 기존 Read Model 투영 안정성(중단 방지)
- 스키마 변경 비용
- 운영 복잡도

### Considered Options
#### 신규 키 보존을 위한 .passthrough() + extra_payload 컬럼 추가
- 접근: toy-data.dto.ts의 toyDataSchema에 .passthrough() 추가하여 신규 키를 허용하고, read-grip-result.ts 및 read-multimodal.ts에 extra_payload: jsonb("extra_payload") 컬럼을 추가. Projector의 map()에서 검증 통과 후 남은 키를 복사하여 저장.
- 제안 필드: extra_payload
- 트레이드오프: 재투영 비용 발생, 스키마 확장성 확보
```typescript
export const toyDataSchema = z.object({...}).passthrough(); // map() return 객체에 extraPayload: payload._unknownKeys || {} 추가
```

#### 신규 키 격리 로그용 별도 테이블
- 접근: 신규 키를 별도 read_schema_drift_log 테이블로 격리하고, 기존 Read Model은 검증 통과 키만 투영하는 분리 아키텍처.
- 제안 필드: read_schema_drift_log
- 트레이드오프: 기존 Read Model 변경 없음, 운영 복잡도 증가
```typescript
try { payload = toyDataSchema.parse(event.payload); } catch (error) { await tx.insert(schemaDriftLog).values({ correlationId: event.eventId, unknownKeys: Object.keys(event.payload), streamId: event.streamId }); throw error; }
```

#### 모든 필드 optional화 (기각 대안)
- 접근: 기존 toyDataSchema를 완전히 재작성하여 모든 필드를 optional로 변경.
- 제안 필드: -
- 트레이드오프: 도메인 정합성 붕괴, 데이터 품질 저하로 Driver 1에서 졌음
```typescript

```

### Decision Outcome
신규 키 보존을 위한 .passthrough() + extra_payload 컬럼 추가

### Consequences
- (+) 신규 키 유실 방지, 향후 스키마 변경 시 재투영만으로 대응 가능
- (−) 스키마 마이그레이션 비용 발생, 기존 클라이언트 응답 구조 확장 필요

### 마이그레이션 절차

- 하위호환 변경: 기존 read_grip_result 테이블, GripResultProjector 클래스/이름, /projection/grip-result 엔드포인트는 수정·삭제하지 않음; v2 프로젝트는 원본 payload를 jsonb로 저장하므로 기존 조회용 필드(objectName, gripSucceed 등)는 v1과 동일한 규칙으로 매핑됨
- 파괴적 변경: 없음
- 컷오버 전 테스트: 1. v2 프로젝트 단독 실행: POST /projection/v2/grip-result 호출 후 read_grip_result_v2 테이블에 54건 이상 적재 확인
2. payload 보존 검증: 적재된 행 중 payload 컬럼이 null이 아니며, 신규 키(예: 3D_image_file_name, box_type 등)가 원본 그대로 저장되었는지 SQL로 확인
3. 정합성 비교: v1과 v2의 objectName, gripSucceed 등 기존 필드 값이 동일하게 매핑되었는지 샘플 10건 비교
4. 기존 v1 엔드포인트 정상 동작 확인: POST /projection/grip-result 호출 시 기존 read_grip_result 테이블이 영향받지 않음 확인
- 롤백 창/조건: 컷오버 전 v2 적재 실패 시 POST /projection/v2/grip-result 호출을 중단하고 기존 v1 엔드포인트로 회귀. read_grip_result_v2 테이블은 DROP TABLE로 즉시 제거 가능. v1 서비스/테이블은 변경 이력이 없으므로 무정지 롤백 보장.
- Insight 카드 등록: §2의 카드 등록 SQL을 DDL과 함께 적용(카탈로그 동기화)

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripContext } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripContextInsert = InferInsertModel<typeof readGripContext>;

@Injectable()
export class GripContextProjector implements Projector<ReadGripContextInsert> {
  readonly name: string = "grip-context-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripContextProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripContextInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      dataKey: payload.data_key,
      boxType: payload.box_type,
      cameraName: payload.camera_info?.camera_name ?? null,
      cameraType: payload.camera_info?.camera_type ?? null,
      cameraIntrinsics: payload.camera_info?.camera_intrinsic_param ?? null,
      rawPayload: JSON.stringify(event.payload),
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripContextInsert): Promise<void> {
    await tx
      .insert(readGripContext)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripContext.sceneKey, readGripContext.attemptNum],
        set: {
          dataKey: row.dataKey,
          boxType: row.boxType,
          cameraName: row.cameraName,
          cameraType: row.cameraType,
          cameraIntrinsics: row.cameraIntrinsics,
          rawPayload: row.rawPayload,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```

import { Injectable } from '@nestjs/common';
import type { InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripResultV2 } from '@/shared/database/schema/service/read-grip-result-v2';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripResultV2Insert = InferInsertModel<typeof readGripResultV2>;
type SafePayload = Record<string, unknown> | null;

@Injectable()
export class GripResultV2Projector implements Projector<ReadGripResultV2Insert> {
  readonly name: string = "grip-result-v2-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripResultV2Projector.name);
  }

  map(event: EventStoreEventRow): ReadGripResultV2Insert {
    const payload = event.payload as SafePayload;

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑 (v2 - schema drift 대응)",
    );

    const objects = Array.isArray(payload?.objects) ? payload.objects : [];
    const firstObject = (Array.isArray(objects) && objects.length > 0 ? objects[0] : null) as SafePayload;

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      objectName: (typeof firstObject?.class_name === 'string' ? firstObject.class_name : "unknown") as string,
      gripSucceed: typeof payload?.grip_succeed === 'number' ? payload.grip_succeed : 0,
      gripperType: "finger",
      occurredAt: event.occurredAt,
      grip2dPose: payload?.grip_data?.grip_2d_pose ?? null,
      grip3dPose: payload?.grip_data?.grip_3d_pose ?? null,
      robotTf: payload?.robot_tf ?? null,
      humanAnnotationGrasp: payload?.human_annotation_grasp ?? null,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
      payload: payload ?? null,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripResultV2Insert): Promise<void> {
    await tx
      .insert(readGripResultV2)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripResultV2.sceneKey, readGripResultV2.attemptNum],
        set: {
          objectName: row.objectName,
          gripSucceed: row.gripSucceed,
          gripperType: row.gripperType,
          occurredAt: row.occurredAt,
          grip2dPose: row.grip2dPose,
          grip3dPose: row.grip3dPose,
          robotTf: row.robotTf,
          humanAnnotationGrasp: row.humanAnnotationGrasp,
          streamId: row.streamId,

import { Injectable } from '@nestjs/common';
import { PinoLogger } from 'nestjs-pino';
import { InsertResult, InsertService } from '@/insert/insert.service';
import { GripResultProjector } from '@/projection/projector/grip-result.projector';
import { MultiModalProjector } from '@/projection/projector/multimodal.projector';
import { GripResultV2Projector } from '@/projection/projector/grip-result-v2.projector';
import { ProjectionResult } from '@/projection/projector/projector';
import { CatchUpRunner } from '@/projection/runner/catch-up.runner';
import { LogAction } from '@/shared/logger/logging-context';

export type CatchUpAllResult = {
  multimodal: ProjectionResult;
  gripResult: ProjectionResult;
  gripResultV2: ProjectionResult;
};

export type InsertAndProjectionAllResult = {
  insert: InsertResult;
  projection: CatchUpAllResult;
};

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly gripResultV2: GripResultV2Projector,
    private readonly insertService: InsertService,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  catchUpMultimodal(): Promise<ProjectionResult> {
    return this.runner.run(this.multimodal);
  }

  catchUpGripResult(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResult);
  }

  catchUpGripResultV2(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResultV2);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();
    const gripResultV2: ProjectionResult = await this.catchUpGripResultV2();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult, gripResultV2 };
  }

  async insertAllAndProjectAll(): Promise<InsertAndProjectionAllResult> {
    this.logger.info(
      { action: LogAction.PROJECTION_START },
      "전체 적재+투영 시작",
    );

    const insert: InsertResult = await this.insertService.insertToyData();
    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
}
