## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 40, `payload.schema.drift`) payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) ← 트립 앵커 → payload.schema.drift 로그는 GripAttemptRecorded 이벤트의 payload에 기존 Zod 스키마와 Read Model 컬럼에 정의되지 않은 신규 키가 유입되어, read_grip_result 및 read_multimodal 투영 시 해당 필드가 매핑되지 않고 유실됨을 드러낸다. [corr:75a6d02d-6310-4b9b-ad36-08a7df74f7f8]
- toyDataSchema는 .passthrough() 또는 .strict(false) 없이 객체 리터럴로 정의되어 있어, 실제 이벤트 payload에 신규 키가 포함되면 Zod 검증 단계에서 해당 키를 무시하거나 예외를 던질 수 있다. 현재 grip-result.projector.ts의 map() 메서드는 payload.objects[0].class_name, payload.grip_succeed 등 기존 키만 추출한다. [corr:75a6d02d-6310-4b9b-ad36-08a7df74f7f8]
- read_multimodal 테이블의 image2dUri, videoUri 컬럼은 현재 multimodal.projector.ts에서 명시적으로 null로 할당되어 있으며, 신규 키 매핑을 위한 컬럼이 스키마에 정의되지 않았다. [corr:75a6d02d-6310-4b9b-ad36-08a7df74f7f8]
- 배치 적재 로그(insert.batch.start ~ insert.batch.done)와 투영 로그(projection.request ~ projection.event.mapped)가 동일한 배치 세션에서 순차적으로 발생했으나, 신규 키 유입 감지(payload.schema.drift) 이후 투영 매핑 단계에서 해당 데이터가 Read Model 행에 반영되지 않는 구조적 간극이 확인된다. [corr:75a6d02d-6310-4b9b-ad36-08a7df74f7f8]

### Decision Drivers
- 도메인 정합성 및 조회 일관성 (Read Model의 핵심 필드 매핑 정확도)
- API 레이어 변경 최소화 (하위 호환성 유지 및 기존 클라이언트 영향 차단)
- 스키마 드리프트 대응 유연성 (신규 키 유입 시 재투영/확장 비용 및 리스크 관리)

### Considered Options
#### 기존 Read Model 컬럼 확장
- 접근: read_grip_result 및 read_multimodal Drizzle 스키마에 신규 키 매핑용 컬럼 추가. toyDataSchema에 .passthrough() 적용 또는 신규 키 정의로 검증 통과 후, Projector의 map()에서 해당 필드 추출 및 upsert에 반영.
- 제안 필드: read_grip_result.extra_payload, read_multimodal.metadata_json
- 트레이드오프: 재투영 필요로 인한 초기 처리 부하 증가. 기존 API 응답 구조에 신규 필드 추가 시 하위 호환성 유지가 필수적이나, null 허용 및 선택적 매핑으로 리스크 최소화 가능.

#### 신규 키 전용 JSONB 메타데이터 컬럼 추가
- 접근: 기존 Read Model의 핵심 조회 성능을 해치지 않기 위해 read_grip_result에 extraMetadata jsonb 컬럼을 추가. 신규 키는 이 컬럼에 원본 그대로 저장. Projector map()에서 payload를 JSON.stringify하여 할당.
- 제안 필드: read_grip_result.extraMetadata
- 트레이드오프: 신규 키에 대한 개별 인덱싱 및 정렬 쿼리 성능 저하. 데이터 정합성 검증이 원본 저장으로 인해 지연되나, 스키마 드리프트에 대한 즉각 대응 및 기존 컬럼 구조 변경 리스크 제로.

// grip-result.projector.ts map() 내
return {

### Decision Outcome
기존 Read Model 컬럼 확장

### Consequences
- (+) 도메인 핵심 조회 시 신규 키를 직접 참조 가능하여 API 응답 구조 일관성 유지
- (+) 기존 Drizzle 스키마 및 Projector 패턴을 그대로 활용하므로 학습 곡선 및 유지보수 비용 최소화
- (+) 하위 호환성 유지(신규 컬럼 null 허용)로 기존 클라이언트 중단 사고 방지

- (−) 신규 키의 데이터 타입 및 길이 검증이 Zod 단계에서 누락될 경우 Read Model 오염 가능성

- 배치 적재 파이프라인 구조 재설계 또는 Kafka 메시지 포맷 변경

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripContext } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripContextInsert = InferInsertModel<typeof readGripContext>;

@Injectable()
export class GripContextProjector implements Projector<ReadGripContextInsert> {
  readonly name: string = "grip-context-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripContextProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripContextInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      dataKey: payload.data_key,
      boxType: payload.box_type,
      cameraName: payload.camera_info.camera_name,
      cameraType: payload.camera_info.camera_type,
      cameraIntrinsicParam: payload.camera_info.camera_intrinsic_param,
      image3dFileName: payload["3D_image_file_name"],
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripContextInsert): Promise<void> {
    await tx
      .insert(readGripContext)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripContext.sceneKey, readGripContext.attemptNum],
        set: {
          dataKey: row.dataKey,
          boxType: row.boxType,
          cameraName: row.cameraName,
          cameraType: row.cameraType,
          cameraIntrinsicParam: row.cameraIntrinsicParam,
          image3dFileName: row.image3dFileName,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}

```

import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripResultV2Insert = InferInsertModel<typeof readGripResultV2>;

@Injectable()

import { InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import { IntegrityViolation, Projector } from '@/projection/projector/projector';
import { DrizzleTx } from '@/shared/database/drizzle.provider';

import { LogAction, LogContext } from '@/shared/logger/logging-context';
import type { EventStoreEventRow } from '../repository/event-store-reader.repository';

type ReadMultimodalV2Insert = InferInsertModel<typeof readMultimodalV2>;

const MODAL_FILE_NAME_RE: RegExp = /_(\d{5})_(\d{2})_\d{8}\.[A-Za-z0-9]+$/;
const SCENE_KEY_NUM_RE: RegExp = /_(\d{5})$/;

type ParsedModalFileName = {
  sceneNum: string;
  attemptNum: number;
};

function parseModalFileName(fileName: string): ParsedModalFileName | null {
  const matched = MODAL_FILE_NAME_RE.exec(fileName);

  if (matched === null) {
    return null;
  }

  return { sceneNum: matched[1], attemptNum: Number(matched[2]) };
}

function pad2(value: number): string {
  return String(value).padStart(2, "0");
}

@Injectable()
export class MultiModalV2Projector implements Projector<ReadMultimodalV2Insert> {
  readonly name: string = "multimodal-v2-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(MultiModalV2Projector.name);
  }

  map(event: EventStoreEventRow): ReadMultimodalV2Insert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      occurredAt: event.occurredAt,
      image2dFileName: payload["2D_image_file_name"],
      image2dUri: null,
      image3dFileName: payload["3D_image_file_name"] ?? null,
      videoFileName: payload.video_file_name,
      videoUri: null,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadMultimodalV2Insert): Promise<void> {
    await tx
      .insert(readMultimodalV2)
      .values(row)
      .onConflictDoUpdate({
        target: [readMultimodalV2.sceneKey, readMultimodalV2.attemptNum],
        set: {
          occurredAt: row.occurredAt,
          image2dFileName: row.image2dFileName,
          image2dUri: row.image2dUri,
          image3dFileName: row.image3dFileName,
          videoFileName: row.videoFileName,
          videoUri: row.videoUri,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }

  checkIntegrity(row: ReadMultimodalV2Insert): IntegrityViolation[] {
    const violations: IntegrityViolation[] = [];

    const sceneKeyMatch = SCENE_KEY_NUM_RE.exec(row.sceneKey);
    const expectedSceneNum: string | null = sceneKeyMatch?.[1] ?? null;

    const modals: {
      column: string;
      dimension: string;
      fileName: string | null | undefined;
      expectedAttempt: number | null;
    }[] = [
      {
        column: "image_2d_file_name",
        dimension: "2D 이미지",
        fileName: row.image2dFileName,
        expectedAttempt: row.attemptNum,
      },
      {
        column: "image_3d_file_name",
        dimension: "3D 이미지",
        fileName: row.image3dFileName,
        expectedAttempt: null,
      },
      {
        column: "video_file_name",
        dimension: "비디오",
        fileName: row.videoFileName,
        expectedAttempt: null,
      },
    ];

    for (const modal of modals) {
      if (modal.fileName === null || modal.fileName === undefined) {
        continue;
      }

      const parsed = parseModalFileName(modal.fileName);

      if (parsed === null) {
        violations.push({
          readModelName: "read_multimodal_v2",
          sceneKey: row.sceneKey,
          attemptNum: row.attemptNum,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
          ruleName: "modalFileNameParseable",
          affectedColumns: [modal.column],
          observedValue: modal.fileName,
          expected: "{scene}_{attempt}_{date}.{ext} 형식",
          detail: `read_multimodal_v2 정합성 위반[modalFileNameParseable]: ${modal.dimension} 파일명이 표준 형식을 벗어나 scene/attempt 를 판별할 수 없음. scene_key=${row.sceneKey}, column=${modal.column}, observed="${modal.fileName}".`,
        });

        continue;
      }

      if (
        modal.expectedAttempt !== null &&
        parsed.attemptNum !== modal.expectedAttempt
      ) {
        violations.push({
          readModelName: "read_multimodal_v2",
          sceneKey: row.sceneKey,
          attemptNum: row.attemptNum,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
          ruleName: "modalFileNameAttemptConsistency",
          affectedColumns: [modal.column],
          observedValue: modal.fileName,
          expected: `attempt=${pad2(modal.expectedAttempt)} (event attempt_num 기준)`,
          detail: `read_multimodal_v2 정합성 위반[modalFileNameAttemptConsistency]: ${modal.dimension} 파일명의 attempt(${pad2(parsed.attemptNum)})가 이 행의 권위 attempt(${pad2(modal.expectedAttempt)})와 불일치 — 다른 시도의 미디어가 scene_key=${row.sceneKey} 행에 매핑됨. column=${modal.column}, observed="${modal.fileName}".`,
        });
      }

      if (expectedSceneNum !== null && parsed.sceneNum !== expectedSceneNum) {
        violations.push({
          readModelName: "read_multimodal_v2",
          sceneKey: row.sceneKey,
          attemptNum: row.attemptNum,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
          ruleName: "modalFileNameSceneConsistency",
          affectedColumns: [modal.column],
          observedValue: modal.fileName,
          expected: `scene=${expectedSceneNum} (scene_key 기준)`,
          detail: `read_multimodal_v2 정합성 위반[modalFileNameSceneConsistency]: ${modal.dimension} 파일명의 scene(${parsed.sceneNum})이 scene_key(${expectedSceneNum})와 불일치 — 다른 장면의 미디어가 매핑됨. column=${modal.column}, observed="${modal.fileName}".`,
        });
      }
    }

    return violations;
  }
}

import { Injectable } from '@nestjs/common';

    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,

    private readonly gripResult: GripResultProjector,

    private readonly gripResultV2: GripResultV2Projector,

  }

    return this.runner.run(this.gripResultV2);
  }

    const gripResult: ProjectionResult = await this.catchUpGripResult();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    this.logger.info(

    );

    const insert: InsertResult = await this.insertService.insertToyData();
    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
}
