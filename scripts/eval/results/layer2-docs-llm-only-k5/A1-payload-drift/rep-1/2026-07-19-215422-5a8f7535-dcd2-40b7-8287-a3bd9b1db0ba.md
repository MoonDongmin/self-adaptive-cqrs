## 1. 권고 (Recommendation)

### Status

### Context (근거)
- (level 40, `payload.schema.drift`) payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) → toyDataSchema의 Zod 검증이 알려지지 않은 키를 제거하여 read_grip_result와 read_multimodal에 신규 필드 투영이 누락되는 스키마 드리프트 결함을 드러냄 [corr:5a8f7535-dcd2-40b7-8287-a3bd9b1db0ba] [corr:5a8f7535-dcd2-40b7-8287-a3bd9b1db0ba]
- src/insert/dto/toy-data.dto.ts의 toyDataSchema는 기본 Zod 동작을 따르며, parse 시 알려지지 않은 키를 자동으로 제거함 [corr:5a8f7535-dcd2-40b7-8287-a3bd9b1db0ba]
- read_grip_result의 objectName, gripSucceed 등 고정 컬럼과 read_multimodal의 image2dFileName, videoFileName에는 신규 키를 담을 수 있는 컬럼이 정의되지 않음
- GripResultProjector.map()과 MultiModalProjector.map() 모두 toyDataSchema.parse(event.payload)를 호출하며, 검증 통과 시 누락된 키 값을 Read Model에 반영하지 못해 정적 데이터 유실이 발생함 [corr:5a8f7535-dcd2-40b7-8287-a3bd9b1db0ba]

### Decision Drivers
- 데이터 무결성 (실시간 유실 방지 vs 검증 실패 차단)
- 스키마 진화 비용 (기존 Read Model 수정 vs 신규 모델 분리)
- 운영 리스크 (재투영 부하 및 커서 관리 복잡도)

### Considered Options
#### toyDataSchema passthrough 적용 및 Read Model extraPayload 컬럼 추가
- 접근: src/insert/dto/toy-data.dto.ts의 toyDataSchema에 .passthrough()를 추가하여 알려지지 않은 키를 유지하고, read_grip_result와 read_multimodal에 structured_object 타입의 extraPayload 컬럼을 추가하여 누락된 키 값을 격리 저장함
- 제안 필드: extraPayload
- 트레이드오프: 재투영 비용 발생하지만 기존 컬럼 구조 및 엔드포인트 계약을 해치지 않으며 신규 키 유입에 유연함. 리스크는 저장소 용량 증가.
```typescript
export const toyDataSchema = z.object({ ... }).passthrough(); Drizzle schema에 extraPayload: structured_object("extra_payload").nullable() 추가. Projector map()에서 extraPayload: payload 할당.
```

#### Zod 검증 실패 시 이벤트 투영 차단 (Fail-Fast)
- 접근: toyDataSchema에 .strict()를 적용하여 알려지지 않은 키가 유입될 경우 parse 실패로 던지도록 변경. GripResultProjector와 MultiModalProjector의 map()에서 throw error가 CatchUpRunner에 전달되어 해당 이벤트 투영을 건너뛰게 함
- 제안 필드: -
- 트레이드오프: 데이터 유실을 원천 차단하나, 기존 배치 트랜잭션이 롤백되지 않은 상태에서는 해당 이벤트가 poison event로 고착될 수 있음. 재투영을 위해 스키마 수정 후 커서 조정 필요.
```typescript
export const toyDataSchema = z.object({ ... }).strict();
```

#### 신규 Raw Read Model 분리
- 접근: read_grip_attempt_raw 테이블을 신설하여 원본 payload 전체를 저장하고, 기존 Read Model은 변경하지 않음
- 제안 필드: rawPayload
- 트레이드오프: 기존 드라이버/쿼리 변경 없이 격리 가능하나, Read Model 수 증가로 유지보수 복잡도가 Driver '스키마 진화 비용'에서 패배하여 기각.
```typescript
export const readGripAttemptRaw = pgTable("read_grip_attempt_raw", { rawPayload: structured_object("raw_payload").notNull(), ... });
```

### Decision Outcome
toyDataSchema passthrough 적용 및 Read Model extraPayload 컬럼 추가

### Consequences
- (+) 신규 키 유입 시 데이터 유실 방지 및 원본 정보 보존
- (+) 기존 Read Model 컬럼 구조 및 엔드포인트 계약 유지
- (+) Zod 검증 통과로 배치 트랜잭션 안정성 확보
- (−) read_grip_result 및 read_multimodal 테이블에 extraPayload 컬럼 추가를 위한 DDL 마이그레이션 필요
- (−) 재투영 시 기존 데이터에 extraPayload 값 채우기 위한 추가 처리 부하 발생
- (−) structured_object 컬럼으로 인한 저장소 용량 미세 증가

### Non-Goals
- 기존 objectName, gripSucceed 등 핵심 필드의 타입/의미 변경
- 엔드포인트 응답 스키마에 extraPayload 노출 또는 클라이언트 계약 변경
- toy-data 외 이벤트 페이로드 검증 로직 수정

## 2. Read Model 생성 SQL (Read Model DDL)

> 실행 게이트: 아래 변경은 인간 승인 후에만 적용한다 (human-in-the-loop).

- 대상: `read_grip_attempt_full` · 키: scene_key, attempt_num · 원천 이벤트: GripAttemptRecorded

```sql
CREATE TABLE read_grip_attempt_full (
  scene_key VARCHAR NOT NULL,
  attempt_num SMALLINT NOT NULL,
  stream_id VARCHAR NOT NULL,
  global_seq BIGINT NOT NULL,
  occurred_at TIMESTAMPTZ NOT NULL,
  event_payload JSONB NOT NULL,
  PRIMARY KEY (scene_key, attempt_num)
);

CREATE INDEX idx_grip_attempt_full_occurred ON read_grip_attempt_full (occurred_at);
```

### 필드

```mschema
# Table: read_grip_attempt_full
[
```

### 투영 매핑 명세 (이벤트 → 컬럼)

> upsert 키: scene_key, attempt_num · 리플레이: projection_cursor 초기화 후 catch-up 시 전체 재투영이 필요하며, upsert는 scene_key+attempt_num 기준 멱등성 보장 전제.

| 원천 이벤트 | payload 필드 | 컬럼 | 변환 |
| --- | --- | --- | --- |
| GripAttemptRecorded | payload | event_payload | verbatim |

파생 컬럼(이벤트 payload 아님):
- `scene_key` ← stream_id에서 'grip-attempt:' 접두사 제거
- `attempt_num` ← stream_id 또는 data_key의 파일명 패턴에서 시도번호 추출
- `stream_id` ← 이벤트 메타데이터 stream_id 직접 할당
- `global_seq` ← 이벤트 메타데이터 global_seq 직접 할당
- `occurred_at` ← data_key 또는 파일명에서 YYYYMMDD 패턴 파싱하여 timestamptz 변환

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripAttemptFull } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripAttemptFullInsert = InferInsertModel<typeof readGripAttemptFull>;

@Injectable()
export class ReadGripAttemptFullProjector implements Projector<ReadGripAttemptFullInsert> {
  readonly name: string = "grip-attempt-full-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(ReadGripAttemptFullProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripAttemptFullInsert {
    try {
      toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
      occurredAt: event.occurredAt,
      eventPayload: event.payload as Record<string, unknown>,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripAttemptFullInsert): Promise<void> {
    await tx
      .insert(readGripAttemptFull)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripAttemptFull.sceneKey, readGripAttemptFull.attemptNum],
        set: {
          streamId: row.streamId,
          globalSeq: row.globalSeq,
          occurredAt: row.occurredAt,
          eventPayload: row.eventPayload,
        },
      });
  }
}
```
