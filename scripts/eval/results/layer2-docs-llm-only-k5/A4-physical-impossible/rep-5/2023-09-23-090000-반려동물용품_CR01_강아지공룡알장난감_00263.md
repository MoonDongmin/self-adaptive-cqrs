## 1. 권고 (Recommendation)

> read_grip_result의 grip3dPose와 grip2dPose jsonb 컬럼에 물리적 타당성 검증이 누락되어 깊이 음수 및 이미지 경계 초과 값이 오염된 상태로 영구 저장되었으며 심각도는 critical이다.

### 심각도 — critical

오염 컬럼(grip3dPose, grip2dPose)은 물리 법칙을 직접 위반하여 하위 분석 신뢰성을 근본적으로 훼손함. 영향 행수(2행)는 적으나 event_store 재투영으로 오염 제거가 가능함. 델타 크기 단독으로 critical을 결정하지 않으나, 물리 불가능값이 Read Model에 영구 침투한 구조적 결함이 critical을 유발함.

### 기대-실측 델타 근거

- (반려동물용품_CR01_강아지공룡알장난감_02006#1, `grip3dPose` / grip3dPose) 관측 `z1=-0.05` vs 기준 `grip3dPoseZ_depth` [0.01, 0.30] m → 델타 -0.06 (하한 0.01 대비 -0.06 m) · 카메라 프레임 기준 깊이 음수 값으로 물리적으로 불가능한 측정치
- (반려동물용품_CR01_강아지공룡알장난감_02007#1, `grip2dPose` / grip2dPose) 관측 `xl=2500` vs 기준 `grip2dPose_withinImage` x in [0, 1920], y in [0, 1110] → 델타 +580 (상한 1920 대비 +580 px) · 이미지 너비(1920px)를 초과한 화면 밖 픽셀 좌표

### 관찰

- grip3dPose.z1이 베이스라인 하한(0.01m)을 -0.06m 이탈하여 카메라 뒤/평면 위 물체를 가정하는 물리 불가능값임
- grip2dPose.xl이 베이스라인 상한(1920px)을 +580px 이탈하여 이미지 경계 밖 좌표임

### 영향 범위

- event_store(GripAttemptRecorded) → grip-result-projector(map/upsert) → read_grip_result(grip_3d_pose, grip_2d_pose jsonb 컬럼) → ProjectionController(POST /projection/grip-result) → API v1

### 근본원인 — projectionOrPipelineFault

1. 왜 물리 불가능값이 Read Model에 저장되었는가? → GripResultProjector의 map/upsert 로직이 jsonb 컬럼에 값 범위 검증을 수행하지 않기 때문이다.
2. 왜 검증 로직이 없는가? → 기존 구현은 Zod를 통해 구조적 유효성(타입/길이)만 검증하고, 의미적 물리 타당성 검사는 checkIntegrity 메서드로 구현되지 않았기 때문이다.
3. 왜 checkIntegrity가 미구현인가? → 초기 설계 시 jsonb의 유연성을 우선시하여 스키마 레벨 CHECK 제약 대신 애플리케이션 로직으로 처리하기로 했으나, 실제 물리 규칙(깊이/경계)에 대한 검증 로직이 누락되었기 때문이다.
4. 왜 스키마 레벨 제약이 없는가? → Drizzle 스키마 정의(read-grip-result.ts)에서 jsonb 컬럼에 CHECK 제약을 추가하지 않고, 애플리케이션 측 위임으로만 설계했기 때문이다.
5. 왜 구조적 갭이 방치되었는가? → 값 이상 판정 부재(구조적 zod만 존재)가 파이프라인의 근본 결함으로 인식되지 않아, 오염 데이터가 Read Model에 영구 침투하는 구조적 허점이 지속되었기 때문이다.

### 의사결정 기준

- 데이터 정합성 보장(물리 불가능값 차단 여부)
- 구현 유지보수 비용(jsonb 검증 로직 추가 및 테스트 범위)
- 하위 시스템 영향도(Read Model 재투영 필요성 및 API 호환성)
- 사후 대응 속도(오염 행 격리 및 베이스라인 규칙 적용 용이성)

```sql
ALTER TABLE read_grip_result ADD CONSTRAINT chk_grip3d_pose_depth CHECK (grip_3d_pose IS NULL OR jsonb_path_exists(grip_3d_pose, '$.z1' ? (value::numeric >= 0.01 AND value::numeric <= 0.30)));
ALTER TABLE read_grip_result ADD CONSTRAINT chk_grip2d_pose_image CHECK (grip_2d_pose IS NULL OR jsonb_path_exists(grip_2d_pose, '$.xl' ? (value::numeric >= 0 AND value::numeric <= 1920)));
```

### 권장
- 프로젝터 checkIntegrity 구현 및 재투영
- 사유: 오염된 jsonb 값을 DB 레벨에서 즉시 차단하는 CHECK 제약은 동적 검증 오버헤드가 크고 마이그레이션 리스크가 높으며, 기존 Zod 기반 구조 검증과 충돌할 수 있다. 반면 checkIntegrity 메서드 구현은 기존 프로젝트터 인터페이스 패턴을 따르며, event_store 재투영으로 오염 데이터를 완전히 정제할 수 있어 데이터 정합성 보장과 구현 유지보수 비용 측면에서 최적이다.
- 수용하는 트레이드오프: 재투영으로 인한 파이프라인 일시 중단 및 처리 오버헤드 수용
- 기각한 대안:
  - 오염 행 즉시 격리(사후 대응 속도에서 떨어짐: 오염 데이터가 Read Model에 영구 잔존하여 하위 조회 시 추가 필터링 로직 필요)
  - 베이스라인 규칙을 Drizzle CHECK 제약으로 이관(구현 유지보수 비용에서 떨어짐: jsonb 동적 검증 쿼리 성능 저하 및 마이그레이션 리스크로 파이프라인 안정성 훼손)

### 버전 교체 코드 — `src/projection/projector/grip-result-v2.projector.ts` (addFile)

```typescript
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import { SensorValueMessage } from '@/projection/kafka/sensor-value.message';
import type { Projector, IntegrityViolation } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripResultV2 } from '@/shared/database/schema/service/read-grip-result-v2';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripResultV2Insert = InferInsertModel<typeof readGripResultV2>;

@Injectable()
export class GripResultProjectorV2 implements Projector<ReadGripResultV2Insert> {
  readonly name: string = "grip-result-v2-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripResultProjectorV2.name);
  }

  map(event: EventStoreEventRow): ReadGripResultV2Insert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    if (payload.objects.length === 0) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
        },
        "objects 비어 있음",
      );

      throw new Error(
        `grip-result-v2 map: empty objects in event ${event.eventId}`,
      );
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      objectName: payload.objects[0].class_name,
      gripSucceed: payload.grip_succeed,
      gripperType: "finger",
      occurredAt: event.occurredAt,
      grip2dPose: payload.grip_data.grip_2d_pose,
      grip3dPose: payload.grip_data.grip_3d_pose,
      robotTf: payload.robot_tf,
      humanAnnotationGrasp: payload.human_annotation_grasp,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
      validationStatus: "VALID",
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripResultV2Insert): Promise<void> {
    await tx
      .insert(readGripResultV2)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripResultV2.sceneKey, readGripResultV2.attemptNum],
        set: {
          objectName: row.objectName,
          gripSucceed: row.gripSucceed,
          gripperType: row.gripperType,
          occurredAt: row.occurredAt,
          grip2dPose: row.grip2dPose,
          grip3dPose: row.grip3dPose,
          robotTf: row.robotTf,
          humanAnnotationGrasp: row.humanAnnotationGrasp,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
          validationStatus: row.validationStatus,
        },
      });
  }

  toSensorValueMessages(rows: ReadGripResultV2Insert[]): SensorValueMessage[] {
    return rows.map((row) => ({
      sceneKey: row.sceneKey,
      attemptNumber: row.attemptNum,
      streamId: row.streamId,
      globalSequence: row.globalSeq,
      occurredAt: row.occurredAt.toISOString(),
      objectName: row.objectName,
      gripSucceed: row.gripSucceed,
      grip2dPose: row.grip2dPose,
      grip3dPose: row.grip3dPose,
      robotTf: row.robotTf,
      humanAnnotationGrasp: row.humanAnnotationGrasp,
    }));
  }

  checkIntegrity(row: ReadGripResultV2Insert, event: EventStoreEventRow): IntegrityViolation[] {
    const violations: IntegrityViolation[] = [];
    const depthMin = 0.01;
    const imageWidth = 1920;

    const grip3dPose = row.grip3dPose as Record<string, unknown> | null;
    if (grip3dPose) {
      const zKeys = ['z1', 'z2', 'z3', 'z4', 'z5', 'z6', 'z7', 'z8'] as const;
      for (const key of zKeys) {
        const val = grip3dPose[key];
        if (typeof val === 'number' && val < depthMin) {
          violations.push({
            readModelName: "read_grip_result_v2",
            sceneKey: row.sceneKey,
            attemptNum: row.attemptNum,
            streamId: event.streamId,
            globalSeq: event.globalSeq,
            ruleName: "depthNonNegative",
            affectedColumns: ["grip_3d_pose"],
            observedValue: String(val),
            expected: `>= ${depthMin}`,
            detail: `read_grip_result_v2 정합성 위반[depthNonNegative]: ${key}=${val} (깊이 ≤ 0 — 카메라 뒤/평면 위 물체는 불가능) [corr:${event.streamId}]`,
          });
        }
      }
    }

    const grip2dPose = row.grip2dPose as Record<string, unknown> | null;
    if (grip2dPose) {
      const xKeys = ['xl', 'xr'] as const;
      for (const key of xKeys) {
        const val = grip2dPose[key];
        if (typeof val === 'number' && (val < 0 || val > imageWidth)) {
          violations.push({
            readModelName: "read_grip_result_v2",
            sceneKey: row.sceneKey,
            attemptNum: row.attemptNum,
            streamId: event.streamId,
            globalSeq: event.globalSeq,
            ruleName: "pixelRangeViolation",
            affectedColumns: ["grip_2d_pose"],
            observedValue: String(val),
            expected: `[0, ${imageWidth}]`,
            detail: `read_grip_result_v2 정합성 위반[pixelRangeViolation]: ${key}=${val} (이미지 경계 [0, 1920]px 밖 — 화면 밖 픽셀 좌표는 불가능) [corr:${event.streamId}]`,
          });
        }
      }
    }

    row.validationStatus = violations.length > 0 ? "PHYSICAL_VIOLATION" : "VALID";
    return violations;
  }
}
```

```typescript
import { Injectable } from '@nestjs/common';
import { PinoLogger } from 'nestjs-pino';
import { InsertResult, InsertService } from '@/insert/insert.service';
import { GripResultProjector } from '@/projection/projector/grip-result.projector';
import { MultiModalProjector } from '@/projection/projector/multimodal.projector';
import { GripResultProjectorV2 } from '@/projection/projector/grip-result-v2.projector';
import { ProjectionResult } from '@/projection/projector/projector';

import { LogAction } from '@/shared/logger/logging-context';

export type CatchUpAllResult = {
  multimodal: ProjectionResult;
  gripResult: ProjectionResult;
};

export type InsertAndProjectionAllResult = {
  insert: InsertResult;
  projection: CatchUpAllResult;
};

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly gripResultV2: GripResultProjectorV2,
    private readonly insertService: InsertService,

  }

    return this.runner.run(this.multimodal);
  }

  catchUpGripResult(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResult);
  }

  catchUpGripResultV2(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResultV2);
  }

    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult };
  }

  async insertAllAndProjectAll(): Promise<InsertAndProjectionAllResult> {
    this.logger.info(
      { action: LogAction.PROJECTION_START },
      "전체 적재+투영 시작",
    );

    const insert: InsertResult = await this.insertService.insertToyData();
    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
}
```
