## 1. 권고 (Recommendation)

> read_grip_result의 robotTf 및 grip3dPose 컬럼에 물리적 범위 이탈 값이 오염 저장됨 — 파지 성공/실패 판정의 신뢰성을 근본적으로 훼손함

### 심각도 — critical

- scene 02008 attempt 1: robotTfTranslationZ=1.5m가 workspace [0.95,1.15]m 상한을 초과하여 gripSucceed=1과 물리적 모순 발생
- scene 02009 attempt 1: grip3dPoseZ(z1~z8) 전부가 [0.01,0.30]m depth 상한을 초과하여 파지 가능 깊이 밖에서 성공 판정 기록
- 두 사례 모두 구조 검증(Zod)은 통과했으나 의미적 정합성(gripSucceed_poseConsistency) 검증이 누락되어 오염값이 Read Model에 영구 저장됨

### 영향 범위

- grip-result-projector (무검증 매핑 및 저장)
- read_grip_result (robotTf, grip3dPose 컬럼 오염)

### 근본원인 — projectionOrPipelineFault

1. 관측 증상: gripSucceed=1인데 robotTfTranslationZ 및 grip3dPoseZ가 물리적 범위 밖으로 이탈한 채 read_grip_result에 저장됨
2. Why 1: 왜 범위를 벗어난 값이 DB에 저장되었는가? → GripResultProjector의 map() 메서드가 원본 페이로드를 검증 없이 직접 DB에 매핑했기 때문
3. Why 2: 왜 매핑 시 물리적 범위 검증이 수행되지 않았는가? → 현재 toyDataSchema는 타입/구조(Zod)만 검사하며, workspace/depth 범위나 gripSucceed와의 정합성은 검증하지 않기 때문
4. Why 3: 왜 정합성 검사가 누락되었는가? → GripResultProjector가 checkIntegrity() 인터페이스를 미구현하여 CatchUpRunner의 정합성 검사 라인을 우회했기 때문
5. Why 4: 왜 구조 검증만 의존하는 아키텍처가 채택되었는가? → 초기 파이프라인이 '값 이상 판정 부재' 상태였으며, zod만 존재하는 구조적 검증에 의존해 의미적 도메인 규칙을 Read Model 레벨에서 강제하지 않았기 때문

### 해결책 옵션 (contain → fix → harden)

#### [contain] 오염 행 즉시 격리 및 플래그
- 접근: read_grip_result 테이블에서 오염된 (scene_key, attempt_num) 조합을 조회하여 별도 플래그 컬럼 추가 또는 상태 변경으로 하위 읽기에서 제외
- 트레이드오프: 즉시 오염 차단 가능하나 원본 데이터 보존이 필요할 경우 별도 테이블 이동 또는 is_anomalous 플래그 관리 부담 발생
```sql
ALTER TABLE read_grip_result ADD COLUMN IF NOT EXISTS is_pose_consistent BOOLEAN DEFAULT TRUE;
UPDATE read_grip_result SET is_pose_consistent = FALSE WHERE (scene_key, attempt_num) IN (('반려동물용품_CR01_강아지공룡알장난감_02008', 1), ('반려동물용품_CR01_강아지공룡알장난감_02009', 1));
```

#### [fix] 프로젝터에 checkIntegrity 구현 및 재투영
- 접근: GripResultProjector에 checkIntegrity() 메서드 추가하여 gripSucceed=1일 때 robotTfTranslationZ 및 grip3dPoseZ 범위를 검증하고, 위반 시 IntegrityViolation을 반환하도록 수정 후 CatchUpRunner로 재투영
- 트레이드오프: 파이프라인 근본 해결 및 자동 격리 가능하나, 기존 오염 행을 덮어쓰거나 실패 처리하려면 upsert 로직 수정 필요
```sql
checkIntegrity(row: ReadGripResultInsert): IntegrityViolation[] {
  const violations: IntegrityViolation[] = [];
  if (row.gripSucceed === 1) {
    const tf = row.robotTf as { translation_3x1: number[] };
    const z = tf?.translation_3x1?.[2];
    if (z !== undefined && (z < 0.95 || z > 1.15)) {
      violations.push({ readModelName: 'read_grip_result', sceneKey: row.sceneKey, attemptNum: row.attemptNum, streamId: row.streamId, globalSeq: row.globalSeq, ruleName: 'gripSucceed_poseConsistency', affectedColumns: ['robotTf'], observedValue: `translation_3x1[2]=${z}`, expected: '[0.95, 1.15] m', detail: 'gripSucceed=1인데 robotTfTranslationZ가 workspace 범위를 벗어남.' });
    }
    const pose = row.grip3dPose as { z1: number; z2: number; z3: number; z4: number; z5: number; z6: number; z7: number; z8: number };
    const zs = [pose.z1, pose.z2, pose.z3, pose.z4, pose.z5, pose.z6, pose.z7, pose.z8];
    const maxZ = Math.max(...zs);
    if (maxZ > 0.30) {
      violations.push({ readModelName: 'read_grip_result', sceneKey: row.sceneKey, attemptNum: row.attemptNum, streamId: row.streamId, globalSeq: row.globalSeq, ruleName: 'gripSucceed_poseConsistency', affectedColumns: ['grip3dPose'], observedValue: `max(z1..z8)=${maxZ}`, expected: '[0.01, 0.30] m', detail: 'gripSucceed=1인데 grip3dPoseZ가 파지 가능 깊이를 벗어남.' });
    }
  }
  return violations;
}
```

#### [harden] 베이스라인 문서에 gripSucceed_poseConsistency 규칙 명시 및 모니터링 연동
- 접근: Sensor Value Baseline v1에 조건부 정합성 규칙을 공식 문서화하고, CatchUpRunner의 이상 로그를 모니터링 대시보드에 연동하여 재발 방지
- 트레이드오프: 운영 관점의 예방 체계 구축에 유리하나, 기존 오염 데이터는 별도 처리 필요
```sql
/* Sensor Value Baseline v1 추가 규칙 */
- rule: gripSucceed_poseConsistency
  expected: grip_succeed=1(성공) 이면 robotTfTranslationZ ∈ [0.95, 1.15] m, grip3dPoseZ(z1..z8) ∈ [0.01, 0.30] m
  note: 성공 판정과 물리값 간 모순 시 이상 확정. 실패(grip_succeed=0) 시 범위 이탈은 노이즈로 간주.
```

### 권장
- 프로젝터에 checkIntegrity 구현 및 재투영 (fix)
- 사유: 오염의 근본 원인이 프로젝트터의 정합성 검사 누락이므로, checkIntegrity() 구현을 통해 파이프라인 레벨에서 자동 차단 및 격리가 가능함. contain 단계의 수동 플래그 관리보다 장기적 운영 리스크가 낮음.
- 수용하는 트레이드오프: 기존 오염 행에 대한 upsert 로직 수정 및 재투영 시 짧은 지연 시간 수용
- 기각한 대안:
  - contain(오염 행 즉시 격리): 데이터 정합성 보장 수준에서 수동 관리로 확장성 부족 및 재투영 시 중복 처리 필요
  - harden(베이스라인 문서화): 하위 시스템 영향도 및 복구 속도 측면에서 기존 오염 데이터 복구에 직접 기여하지 못함

- Insight 카드 등록: §2의 카드 등록 SQL을 DDL과 함께 적용(카탈로그 동기화)

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import type { InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import type { ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector, IntegrityViolation } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripResultV2 } from '@/shared/database/schema/service/read-grip-result-v2';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

const WORKSPACE_Z_MIN = 0.95;
const WORKSPACE_Z_MAX = 1.15;
const DEPTH_Z_MIN = 0.01;
const DEPTH_Z_MAX = 0.30;

type ReadGripResultV2Insert = InferInsertModel<typeof readGripResultV2>;

@Injectable()
export class GripResultIntegrityProjector implements Projector<ReadGripResultV2Insert> {
  readonly name: string = "grip-result-integrity-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripResultIntegrityProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripResultV2Insert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    if (payload.objects.length === 0) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
        },
        "objects 비어 있음",
      );

      throw new Error(
        `grip-result-v2 map: empty objects in event ${event.eventId}`,
      );
    }

    const zTranslation = payload.robot_tf.translation_3x1[2];
    const zValues = [
      payload.grip_data.grip_3d_pose.z1,
      payload.grip_data.grip_3d_pose.z2,
      payload.grip_data.grip_3d_pose.z3,
      payload.grip_data.grip_3d_pose.z4,
      payload.grip_data.grip_3d_pose.z5,
      payload.grip_data.grip_3d_pose.z6,
      payload.grip_data.grip_3d_pose.z7,
      payload.grip_data.grip_3d_pose.z8,
    ];

    const zMin = Math.min(...zValues);
    const zMax = Math.max(...zValues);

    let outlierFlag = 0;
    if (payload.grip_succeed === 1) {
      const zOutOfRange = zTranslation < WORKSPACE_Z_MIN || zTranslation > WORKSPACE_Z_MAX;
      const depthOutOfRange = zMin < DEPTH_Z_MIN || zMax > DEPTH_Z_MAX;
      if (zOutOfRange || depthOutOfRange) {
        outlierFlag = 1;
      }
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      objectName: payload.objects[0].class_name,
      gripSucceed: payload.grip_succeed,
      robotTfTranslationZ: zTranslation,
      grip3dPoseZMin: zMin,
      grip3dPoseZMax: zMax,
      gripOutlierFlag: outlierFlag,
      occurredAt: event.occurredAt,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripResultV2Insert): Promise<void> {
    await tx
      .insert(readGripResultV2)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripResultV2.sceneKey, readGripResultV2.attemptNum],
        set: {
          objectName: row.objectName,
          gripSucceed: row.gripSucceed,
          robotTfTranslationZ: row.robotTfTranslationZ,
          grip3dPoseZMin: row.grip3dPoseZMin,
          grip3dPoseZMax: row.grip3dPoseZMax,
          gripOutlierFlag: row.gripOutlierFlag,
          occurredAt: row.occurredAt,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }

  checkIntegrity(row: ReadGripResultV2Insert): IntegrityViolation[] {
    const violations: IntegrityViolation[] = [];

    if (row.gripOutlierFlag === 1) {
      const zTrans = row.robotTfTranslationZ ?? 0;
      const zMax = row.grip3dPoseZMax ?? 0;

      if (zTrans < WORKSPACE_Z_MIN || zTrans > WORKSPACE_Z_MAX) {
        violations.push({
          readModelName: "read_grip_result_v2",
          sceneKey: row.sceneKey,
          attemptNum: row.attemptNum,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
          ruleName: "workspaceZRange",
          affectedColumns: ["robot_tf_translation_z"],
          observedValue: String(zTrans),
          expected: `[${WORKSPACE_Z_MIN}, ${WORKSPACE_Z_MAX}]`,
          detail: `read_grip_result_v2 정합성 위반[workspaceZRange]: gripSucceed=1인데 robotTfTranslationZ=${zTrans}이 작업범위를 벗어남. scene_key=${row.sceneKey}, attempt_num=${row.attemptNum}.`,
        });
      }

      if (zMax < DEPTH_Z_MIN || zMax > DEPTH_Z_MAX) {
        violations.push({
          readModelName: "read_grip_result_v2",
          sceneKey: row.sceneKey,
          attemptNum: row.attemptNum,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
          ruleName: "depthZRange",
          affectedColumns: ["grip_3d_pose_z_max"],
          observedValue: String(zMax),
          expected: `[${DEPTH_Z_MIN}, ${DEPTH_Z_MAX}]`,
          detail: `read_grip_result_v2 정합성 위반[depthZRange]: gripSucceed=1인데 grip3dPoseZMax=${zMax}이 파지 가능 깊이를 벗어남. scene_key=${row.sceneKey}, attempt_num=${row.attemptNum}.`,
        });
      }
    }

    return violations;
  }
}
```

        "이벤트 매핑(검증) 실패",

    this.logger.debug(

        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,

      .values(row)
      .onConflictDoUpdate({

    if (grip3dPose) {
      const zKeys = ["z1", "z2", "z3", "z4", "z5", "z6", "z7", "z8"];
      for (const key of zKeys) {
        const z = grip3dPose[key];
        if (z !== undefined && (z < DEPTH_Z_MIN || z > DEPTH_Z_MAX)) {
          violations.push({
            readModelName: "read_grip_result_v2",
            sceneKey: row.sceneKey,
            attemptNum: row.attemptNum,
            streamId: event.streamId,
            globalSeq: event.globalSeq,
            ruleName: "depthZRange",
            affectedColumns: ["grip_3d_pose"],
            observedValue: String(z),
            expected: `[${DEPTH_Z_MIN}, ${DEPTH_Z_MAX}]`,
            detail: `read_grip_result_v2 정합성 위반[depthZRange]: gripSucceed=1인데 grip3dPose${key}=${z}이 파지 가능 깊이 [${DEPTH_Z_MIN}, ${DEPTH_Z_MAX}]m 밖으로 이탈.`,
          });
        }
      }
    }

    return violations;
  }

  gripResult: ProjectionResult;

  gripResult: ProjectionResult;

  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,

    private readonly insertService: InsertService,

    return { gripResult };
  }
