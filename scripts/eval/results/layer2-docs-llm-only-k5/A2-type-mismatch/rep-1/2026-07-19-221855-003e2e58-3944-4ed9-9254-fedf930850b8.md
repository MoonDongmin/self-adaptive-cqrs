스키마 및 엔드포인트가 불변이므로 변경 없음. 기존 read_grip_result의 gripSucceed: smallint("grip_succeed").notNull() 컬럼과 read_multimodal의 image2dUri: null, videoUri: null 할당 로직이 그대로 유지되며, 투영 파이프라인만 복원됨.

## Guardrails (constraints)

- v1 자산(테이블/엔드포인트/프로젝터 name) 무손상
- PK (scene_key, attempt_num) 유지
- TypeScript any 금지
- 식별자 전체 단어
- DDL 실행·API 컷오버는 인간 승인 후에만 (human-in-the-loop)
- Read Model 테이블명은 read_ 접두 스네이크 케이스
