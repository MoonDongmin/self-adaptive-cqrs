#### 신규 결합 Read Model (read_grip_result_with_media) 도입
- 접근: 새로운 Drizzle 스키마와 Projector 생성. 기존 두 테이블은 유지하되, Insight Card 조회 전용으로 결합된 Read Model을 별도 관리.

- 트레이드오프: 초기 개발 비용과 유지보수 복잡도 증가. 하지만 기존 파지 전용/미디어 전용 Read Model의 도메인 경계를 해치지 않으며, 확장성 확보.
