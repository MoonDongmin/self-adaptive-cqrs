## 1. 권고 (Recommendation)

> read_grip_result의 grip3dPose Z축 값이 동일 장면 내 시퀀스 급변 규칙을 위반하여 데이터 품질이 심각하게 훼손됨.

### 심각도 — critical

오염 컬럼(grip3dPose)은 파지 제어 및 물리 분석의 핵심 입력값이며, 동일 sceneKey 내 2개 행(attempt 1, 2)이 시퀀스 정합성을 동시에 위반함. event_store에 원본 payload가 보존되어 재투영으로 완전 복구 가능하나, 현재 파이프라인의 정합성 게이트 부재로 인해 오염이 Read Model에 고착된 상태임.

### 기대-실측 델타 근거

- (반려동물용품_CR01_강아지공룡알장난감_02010#1, `grip3dPose` / grip3dPose) 관측 `"z1":0.06621591822239369,"z2":0.06738581037293279,"z3":0.07110208907802962,"z4":0.0699321969274905,"z5":0.04889791092197039,"z6":0.05006780307250949,"z7":0.053784081777606324,"z8":0.05261418962706721` vs 기준 `grip3dPoseZ_depth` [0.01, 0.30] m → 델타 평균 0.061m (범위 내) · 시퀀스 시작점 기준 정상 깊이 분포

### 관찰

- 동일 sceneKey 내 attempt 1→2 간 grip3dPose Z축 평균이 0.061m에서 0.170m로 급변(Δ=0.109m)하여 suddenJump_withinScene 규칙을 위반함.
- 개별 Z좌표는 베이스라인 grip3dPoseZ_depth 범위([0.01, 0.30]m) 내에 있으나, 시퀀스 내 물리적 연속성/정합성이 깨짐.
- 프로젝터 GripResultProjector의 checkIntegrity 미구현으로 인해 구조 검증(zod) 통과 후 의미적 값 오류가 Read Model에 그대로 투영됨.

### 근본원인 — projectionOrPipelineFault

1. 왜 attempt 2의 Z값이 attempt 1 대비 0.109m 급변했는가? → 동일 장면 내 물체/마운트 상태가 변하지 않았는데 depth 센서 출력값이 불연속적으로 상승했기 때문이다.
2. 왜 이 급변이 시스템에서 즉시 차단되지 않고 Read Model에 기록되었는가? → GripResultProjector의 checkIntegrity 메서드가 구현되지 않아 시퀀스 정합성 검사가 생략되었기 때문이다.
3. 왜 시퀀스 정합성 검사가 프로젝트 설계 단계에서 누락되었는가? → 기존 검증 로직이 zod 기반 구조 스키마 매칭에 집중되어, jsonb 내 물리적 값의 의미적 타당성(범위/연속성) 검증은 관찰자(LLM) 의존 구조로 남겨졌기 때문이다.
4. 왜 의미적 타당성 검증이 런타임 파이프라인에 통합되지 않았는가? → 투영 단계의 정합성 검사(checkIntegrity)가 선택적 옵셔널 인터페이스로 설계되어, 핵심 Read Model에도 기본 적용되지 않았기 때문이다.
5. 왜 구조적 검증만 존재하는가? → 초기 개발 시 데이터 품질 관리를 사후 관찰과 수기 베이스라인 비교에 위임하여, 파이프라인 내 자동화된 물리적 정합성 게이트가 부재한 구조적 갭이 고착되었기 때문이다.

#### [fix] 프로젝터 정합성 검사 구현
- 접근: GripResultProjector에 checkIntegrity 메서드를 구현하여 동일 sceneKey 내 직전 레코드 대비 grip3dPoseZ 평균 Δ를 검증하고 임계 초과 시 IntegrityViolation 반환
- 트레이드오프: 파이프라인 내 조기 차단으로 재투영 비용 발생하나 장기적 품질 보장
```sql
// src/projection/projector/grip-result.projector.ts 내 checkIntegrity 구현 예시
checkIntegrity(row: ReadGripResultInsert, event: EventStoreEventRow): IntegrityViolation[] {
  const violations: IntegrityViolation[] = [];
  // 직전 레코드 조회 로직(캐시 또는 DB)을 통해 prevZAvg 계산
  const currentZAvg = this.calculateGrip3dPoseZAverage(row.grip3dPose);
  const prevZAvg = this.getPreviousAttemptZAverage(row.sceneKey, row.attemptNum);
  if (prevZAvg !== null) {
    const delta = Math.abs(currentZAvg - prevZAvg);
    if (delta > 0.10) {
      violations.push({
        readModelName: "read_grip_result",
        sceneKey: row.sceneKey,
        attemptNum: row.attemptNum,
        streamId: event.streamId,
        globalSeq: event.globalSeq,
        ruleName: "suddenJump_withinScene",
        affectedColumns: ["grip_3d_pose"],
        observedValue: `z_avg=${currentZAvg.toFixed(4)}, prev_z_avg=${prevZAvg.toFixed(4)}`,
        expected: "Δ <= 0.10 m",
        detail: `suddenJump_withinScene 위반: scene_key=${row.sceneKey} attempt ${row.attemptNum}의 Z축 평균이 직전 대비 ${delta.toFixed(3)}m 급변.`
      });
    }
  }
  return violations;
}
```

```sql
    await this.queueReprojection(violation.sceneKey, violation.attemptNum);
  }
}
```

### 권장
- 프로젝터 정합성 검사 구현 (fix)
- 사유: 근본원인이 파이프라인 내 정합성 게이트 부재이므로, 투영 단계에서 즉시 차단하는 것이 오염 확산을 원천적으로 방지하고 하위 시스템 신뢰도를 높임.
- 수용하는 트레이드오프: 기존 오염 데이터에 대한 재투영 작업 비용과 프로젝트 수정 기간을 수용하여 장기적 파이프라인 안정성을 확보함.
- 기각한 대안:
  - contain(오염 행 플래그 격리)는 decisionCriteria '데이터 정합성 보장 수준'에서 근본 원인 해결이 불가하여 거부됨.
  - harden(베이스라인 문서화)는 decisionCriteria '파이프라인 통합 비용'과 '하위 시스템 영향도'에서 실시간 차단 지연으로 인해 거부됨.

- 사유: 기존 v1 Read Model은 grip3dPose(jsonb)를 구조만 검증하고 z1..z8의 물리적 평균을 계산하거나 범위 검증을 수행하지 않아, 같은 scene 내 attempt 간 z-평균이 0.1m 이상 급변하는 suddenJump_withinScene 규칙 위반이 조용히 통과됨 [corr:grip-attempt:반려동물용품_CR01_강아지공룡알장난감_02010]. v2는 grip_3d_pose_z_avg 컬럼을 추가해 평균값을 영구 저장하고, checkIntegrity에서 물리적 파지 깊이 범위(0.01~0.5m)를 검증해 이상값을 즉시 차단하며, 기존 v1 데이터는 동시 보존됨.
- 트리거 근거: > 사유: [윈도우 1] R6 suddenJump_withinScene: 같은 scene 연속 attempt 간 z평균 0.060 → 0.170, Δ=0.110 > 0.10 m / [2차 지목] R6 suddenJump_withinScene: 같은 scene 연속 attempt 간 z평균 0.069 → 0.179, Δ=0.110 > 0.10 m

v1 GripResultProjector.map()은 payload.grip_data.grip_3d_pose를 jsonb로 그대로 저장할 뿐 z1..z8의 평균을 계산하거나 물리적 범위(0.01~0.5m)를 검증하지 않아 이상값이 조용히 통과함 [corr:grip-attempt:반려동물용품_CR01_강아지공룡알장난감_02010].

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripResultV2 } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripResultV2Insert = InferInsertModel<typeof readGripResultV2>;

@Injectable()
export class GripResultV2Projector implements Projector<ReadGripResultV2Insert> {
  readonly name: string = "grip-result-v2-projector";

  private readonly prevZMeanByScene: Map<string, number> = new Map();
  private readonly Z_JUMP_THRESHOLD = 0.10;

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripResultV2Projector.name);
  }

  map(event: EventStoreEventRow): ReadGripResultV2Insert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    const sceneKey = event.streamId.replace(/^grip-attempt:/, "");
    const zValues = [
      payload.grip_data.grip_3d_pose.z1,
      payload.grip_data.grip_3d_pose.z2,
      payload.grip_data.grip_3d_pose.z3,
      payload.grip_data.grip_3d_pose.z4,
      payload.grip_data.grip_3d_pose.z5,
      payload.grip_data.grip_3d_pose.z6,
      payload.grip_data.grip_3d_pose.z7,
      payload.grip_data.grip_3d_pose.z8,
    ];

    const zDepthMean = zValues.reduce((sum, val) => sum + val, 0) / zValues.length;

    const prevMean = this.prevZMeanByScene.get(sceneKey);
    let gripOutlierFlag = 0;

    if (prevMean !== undefined) {
      const diff = Math.abs(zDepthMean - prevMean);
      if (diff > this.Z_JUMP_THRESHOLD) {
        gripOutlierFlag = 1;
      }
    }

    this.prevZMeanByScene.set(sceneKey, zDepthMean);

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: sceneKey,
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey,
      attemptNum: event.attemptNum,
      objectName: payload.objects[0].class_name,
      gripSucceed: payload.grip_succeed,
      gripperType: "finger",
      occurredAt: event.occurredAt,
      zDepthMean: String(zDepthMean),
      gripOutlierFlag,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripResultV2Insert): Promise<void> {
    await tx
      .insert(readGripResultV2)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripResultV2.sceneKey, readGripResultV2.attemptNum],
        set: {
          objectName: row.objectName,
          gripSucceed: row.gripSucceed,
          gripperType: row.gripperType,
          occurredAt: row.occurredAt,
          zDepthMean: row.zDepthMean,
          gripOutlierFlag: row.gripOutlierFlag,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```

```typescript
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import type { ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import { SensorValueMessage } from '@/projection/kafka/sensor-value.message';
import type { Projector, IntegrityViolation } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripResultV2 } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripResultV2Insert = InferInsertModel<typeof readGripResultV2>;

function extractZAvg(grip3dPose: unknown): number | null {
  if (typeof grip3dPose !== 'object' || grip3dPose === null) return null;
  const pose = grip3dPose as Record<string, unknown>;
  const zKeys: Array<keyof typeof pose> = ['z1','z2','z3','z4','z5','z6','z7','z8'];
  const values: number[] = [];
  for (const k of zKeys) {
    const v = pose[k];
    if (typeof v === 'number') values.push(v);
  }
  if (values.length === 0) return null;
  const sum = values.reduce((acc, cur) => acc + cur, 0);
  return sum / values.length;
}

@Injectable()
export class GripResultV2Projector implements Projector<ReadGripResultV2Insert> {
  readonly name: string = "grip-result-v2-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripResultV2Projector.name);
  }

  map(event: EventStoreEventRow): ReadGripResultV2Insert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        { action: LogAction.MAP_FAILED, error, [LogContext.EVENT_ID]: event.eventId, [LogContext.STREAM_ID]: event.streamId, [LogContext.ATTEMPT_NUM]: event.attemptNum, [LogContext.GLOBAL_SEQ]: event.globalSeq },
        "이벤트 매핑(검증) 실패",
      );
      throw error;
    }

    if (payload.objects.length === 0) {
      this.logger.error(
        { action: LogAction.MAP_FAILED, [LogContext.EVENT_ID]: event.eventId, [LogContext.STREAM_ID]: event.streamId },
        "objects 비어 있음",
      );
      throw new Error(`grip-result-v2 map: empty objects in event ${event.eventId}`);
    }

    const zAvg = extractZAvg(payload.grip_data.grip_3d_pose);

    this.logger.debug(
      { action: LogAction.EVENT_MAPPED, [LogContext.PROJECTOR_NAME]: this.name, [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""), [LogContext.ATTEMPT_NUM]: event.attemptNum, [LogContext.GLOBAL_SEQ]: event.globalSeq },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      objectName: payload.objects[0].class_name,
      gripSucceed: payload.grip_succeed,
      gripperType: "finger",
      occurredAt: event.occurredAt,
      grip2dPose: payload.grip_data.grip_2d_pose,
      grip3dPose: payload.grip_data.grip_3d_pose,
      robotTf: payload.robot_tf,
      humanAnnotationGrasp: payload.human_annotation_grasp,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
      grip3dPoseZAvg: zAvg ?? 0.0,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripResultV2Insert): Promise<void> {
    await tx.insert(readGripResultV2).values(row).onConflictDoUpdate({
      target: [readGripResultV2.sceneKey, readGripResultV2.attemptNum],
      set: {
        objectName: row.objectName,
        gripSucceed: row.gripSucceed,
        gripperType: row.gripperType,
        occurredAt: row.occurredAt,
        grip2dPose: row.grip2dPose,
        grip3dPose: row.grip3dPose,
        robotTf: row.robotTf,
        humanAnnotationGrasp: row.humanAnnotationGrasp,
        streamId: row.streamId,
        globalSeq: row.globalSeq,
        grip3dPoseZAvg: row.grip3dPoseZAvg,
      },
    });
  }

  checkIntegrity(row: ReadGripResultV2Insert, _event: EventStoreEventRow): IntegrityViolation[] {
    const violations: IntegrityViolation[] = [];
    const zAvg = row.grip3dPoseZAvg;

    if (zAvg < 0.01) {
      violations.push({
        readModelName: "read_grip_result_v2",
        sceneKey: row.sceneKey,
        attemptNum: row.attemptNum,
        streamId: row.streamId,
        globalSeq: row.globalSeq,
        ruleName: "grip3dPoseZPhysicalRange",
        affectedColumns: ["grip_3d_pose_z_avg"],
        observedValue: String(zAvg),
        expected: "0.01 ~ 0.5 (m)",
        detail: `read_grip_result_v2 정합성 위반[grip3dPoseZPhysicalRange]: z-평균(${zAvg}m)이 물리적 파지 깊이 하한(0.01m) 미만. scene=${row.sceneKey}, attempt=${row.attemptNum}.`,
      });
    } else if (zAvg > 0.5) {
      violations.push({
        readModelName: "read_grip_result_v2",
        sceneKey: row.sceneKey,
        attemptNum: row.attemptNum,
        streamId: row.streamId,
        globalSeq: row.globalSeq,
        ruleName: "grip3dPoseZPhysicalRange",
        affectedColumns: ["grip_3d_pose_z_avg"],
        observedValue: String(zAvg),
        expected: "0.01 ~ 0.5 (m)",
        detail: `read_grip_result_v2 정합성 위반[grip3dPoseZPhysicalRange]: z-평균(${zAvg}m)이 물리적 파지 깊이 상한(0.5m) 초과. scene=${row.sceneKey}, attempt=${row.attemptNum}.`,
      });
    }

    return violations;
  }

  toSensorValueMessages(rows: ReadGripResultV2Insert[]): SensorValueMessage[] {
    return rows.map((row) => ({
      sceneKey: row.sceneKey,
      attemptNumber: row.attemptNum,
      streamId: row.streamId,

      grip3dPose: row.grip3dPose,
      robotTf: row.robotTf,
      humanAnnotationGrasp: row.humanAnnotationGrasp,
    }));
  }
}
```

```typescript
import { Injectable } from '@nestjs/common';
import { PinoLogger } from 'nestjs-pino';
import { InsertResult, InsertService } from '@/insert/insert.service';
import { GripResultProjector } from '@/projection/projector/grip-result.projector';
import { GripResultV2Projector } from '@/projection/projector/grip-result-v2.projector';
import { MultiModalProjector } from '@/projection/projector/multimodal.projector';
import { ProjectionResult } from '@/projection/projector/projector';
import { CatchUpRunner } from '@/projection/runner/catch-up.runner';
import { LogAction } from '@/shared/logger/logging-context';

export type CatchUpAllResult = {
  multimodal: ProjectionResult;
  gripResult: ProjectionResult;
  gripResultV2: ProjectionResult;
};

export type InsertAndProjectionAllResult = {
  insert: InsertResult;
  projection: CatchUpAllResult;
};

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly gripResultV2: GripResultV2Projector,
    private readonly insertService: InsertService,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  catchUpMultimodal(): Promise<ProjectionResult> {
    return this.runner.run(this.multimodal);
  }

  catchUpGripResult(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResult);
  }

  catchUpGripResultV2(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResultV2);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();
    const gripResultV2: ProjectionResult = await this.catchUpGripResultV2();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult, gripResultV2 };
  }

  async insertAllAndProjectAll(): Promise<InsertAndProjectionAllResult> {
    this.logger.info(
      { action: LogAction.PROJECTION_START },
      "전체 적재+투영 시작",
    );

    const insert: InsertResult = await this.insertService.insertToyData();
    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
}
```
