## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 40, `payload.schema.drift`) payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) ← 트립 앵커 → Zod 검증 실패로 conveyor_speed와 gripper_temperature 키가 적재(deserialization) 단계에서 유실되어 Read Model 영구 저장이 불가능. [corr:19573d9b-cce1-44bf-b7d4-4e423afcce45]
- GripAttemptRecorded 이벤트 스키마에 미정의된 conveyor_speed, gripper_temperature 키 유입 감지 [corr:19573d9b-cce1-44bf-b7d4-4e423afcce45].
- 기존 Read Model read_grip_result 및 read_multimodal Insight 카드에 동해 해당 필드 컬럼 부재,로 인해 투영 매핑 실패 [corr:19573d9b-cce1-44bf-b7d4-4e423afcce45].
- src/insert/dto/toy-data.dto.ts 의 toyDataSchema 정의가 Zod strict 모드로 미예상 키 거절,로 인해 GripResultProjector.map() 에서 payload = toyDataSchema.parse(event.payload) 실패 경로 진입 [corr:19573d9b-cce1-44bf-b7d4-4e423afcce45].
- 기존 구현 src/projection/projector/grip-result.projector.ts 의 map() 메서드는 Zod 파싱 실패 시 throw err 로 투영 파이프라인 중단,로 인해 무해화 격리 수단이 필요 [corr:19573d9b-cce1-44bf-b7d4-4e423afcce45].

### Decision Drivers
- Schema drift decoupling from core business logic
- Zod strictness validation failure handling & poison event safety
- API contract stability vs evolution necessity
- Read Model queryability for new sensor data without schema coupling

### Considered Options
#### 기존 DTO/Projector 보강 (기각 대안)
- 접근: src/insert/dto/toy-data.dto.ts 의 toyDataSchema 확장 및 GripResultProjector.map() 수정으로 Zod .passthrough() 적용, 기존 read_grip_result 테이블에 컬럼 추가.
- 제안 필드: conveyor_speed, gripper_temperature
- 트레이드오프: Driver 1(의존성 결합)에서 실패 — 핵심 비즈니스 로직과 센서 드리프트가 일체화되어 향후 스키마 변경 시 파이프라인 재투영 비용 증가. Zod strict 모드로 거절된 값이 아닌 passthrough 허용으로 정합성 검사 약화.
```typescript

```

#### 신독 분리(newReadModel) — read_grip_drift_fields_v1

신독 분리(newReadModel) — read_grip_drift_fields_v1

- (+) 핵심 grip_result 스키마·정합성 규칙 무변 유지로 하위 호환성 보장

- (−) API 엔드포인트 버전 로프트(v2)로 하위 호환성 테스트 병력 필요

### Non-Goals
- 기존 read_grip_result 테이블에 컬럼 확장
- Zod z.coerce/defaults 치환으로 정상값 위장
- event_store append rollback

```ts
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripDriftFields } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';
import { toyDataSchema } from '@/insert/dto/toy-data.dto';

type ReadGripDriftInsert = InferInsertModel<typeof readGripDriftFields>;

@Injectable()
export class GripDriftProjector implements Projector<ReadGripDriftInsert> {
  readonly name: string = "grip-drift-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripDriftProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripDriftInsert {
    let payload: Record<string, unknown>;
    try {
      payload = toyDataSchema.extend({
        conveyor_speed: z.number().optional(),
        gripper_temperature: z.number().optional(),
      }).parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      conveyorSpeed: typeof payload.conveyor_speed === "number" ? String(payload.conveyor_speed) : null,
      gripperTemperature: typeof payload.gripper_temperature === "number" ? String(payload.gripper_temperature) : null,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripDriftInsert): Promise<void> {
    await tx
      .insert(readGripDriftFields)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripDriftFields.sceneKey, readGripDriftFields.attemptNum],
        set: {
          sceneKey: row.sceneKey,
          attemptNum: row.attemptNum,
          conveyorSpeed: row.conveyorSpeed,
          gripperTemperature: row.gripperTemperature,
        },
      });
  }
}
```

### 버전 교체 코드 — `src/projection/projection.service.ts` (modifyFile)

```typescript
import { Injectable } from '@nestjs/common';
import { PinoLogger } from 'nestjs-pino';
import { InsertResult, InsertService } from '@/insert/insert.service';
import { GripResultProjector } from '@/projection/projector/grip-result.projector';
import { MultiModalProjector } from '@/projection/projector/multimodal.projector';
import { ProjectionResult } from '@/projection/projector/projector';
import { CatchUpRunner } from '@/projection/runner/catch-up.runner';
import { GripDriftFieldsV2Projector } from '@/projection/projector/grip-drift-fields-v2.projector';
import { LogAction } from '@/shared/logger/logging-context';

export type CatchUpAllResult = {
  multimodal: ProjectionResult;
  gripResult: ProjectionResult;
};

export type InsertAndProjectionAllResult = {
  insert: InsertResult;
  projection: CatchUpAllResult;
};

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly insertService: InsertService,
    private readonly gripDriftFieldsV2: GripDriftFieldsV2Projector,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  catchUpMultimodal(): Promise<ProjectionResult> {
    return this.runner.run(this.multimodal);
  }

  catchUpGripResult(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResult);
  }

  catchUpGripDriftFieldsV2(): Promise<ProjectionResult> {
    return this.runner.run(this.gripDriftFieldsV2);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult };
  }

  async insertAllAndProjectAll(): Promise<InsertAndProjectionAllResult> {
    this.logger.info(
      { action: LogAction.PROJECTION_START },
      "전체 적재+투영 시작",
    );

    const insert: InsertResult = await this.insertService.insertToyData();
    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
}
```
