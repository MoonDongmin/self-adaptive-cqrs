## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 40, `payload.schema.drift`) payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) ← 트립 앵커 → Zod 검증에서 미등록 키(conveyor_speed, gripper_temperature) 감지, 현 Read Model 투영 시 필드 유실 경고 발생 [corr:ca92824d-ccc0-4004-80ac-c8867d380582]
- (level 30, `insert.batch.done`) toy-data 적재 완료 → Batch 적재가 성공으로 ES에 append되었으나 payload 구조 mismatch로 기존 projector 매핑 실패 가능성 [corr:ca92824d-ccc0-4004-80ac-c8867d380582]
- src/insert/dto/toy-data.dto.ts 의 toyDataSchema 정의에는 conveyor_speed, gripper_temperature 키가 미존재. Zod .parse() 실행 시 해당 필드는 객체에서 제거(strip)되거나 검증 실패로 이어짐, 이로 인해 Read Model 에 유입되지 [corr:ca92824d-ccc0-4004-80ac-c8867d380582].
- read_grip_result Insight 카드 의 object_name, grip_succeed 등 기존 컬럼에는 신규 키 매핑이 미구현. GripResultProjector.map() (src/projection/projector/grip-result.projector.ts) 만 payload.objects[0].class_name 등 기존 필드만 반환 [corr:ca92824d-ccc0-4004-80ac-c8867d380582].
- read_multimodal Insight 카드 의 image_2d_uri, video_uri 는 현재 projector 가 null 로 둠. 신규 키 반영 시 media URI 매핑과 동반될 수 있으나 본 권고 에 초점은 drift 대응 [corr:ca92824d-ccc0-4004-80ac-c8867d380582].
- 확정된 read_grip_drift 설계 의 conveyor_speed numeric, gripper_temperature numeric 컬럼 이 정적 타입 매칭 필요 [corr:ca92824d-ccc0-4004-80ac-c8867d380582].

### Decision Drivers
- Schema drift detection at payload validation
- Data preservation requirement for sensor metrics
- Single-responsibility principle for Read Models
- API contract stability

### Considered Options
#### 기존 Read Model 보강 (기각 대안)
- 접근: read_grip_result Drizzle 스키마 추가 컬럼(conveyor_speed, gripper_temperature) 및 GripResultProjector.map() 수정.
- 제안 필드: read_grip_result.conveyor_speed, read_grip_result.gripper_temperature
- 트레이드오프: 단일 테이블 유지하나 grip result 와 sensor drift 가 혼, single-responsibility 위반, migration risk 높음.
```typescript
export const readGripResult = pgTable("read_grip_result", { ... conveyorSpeed: numeric("conveyor_speed"), gripperTemperature: numeric("gripper_temperature") }); // map return 추가 필드
```

#### 신규 Read Model 생성 (권장)
- 접근: read_grip_drift Drizzle 스키마/프로젝터(DriftProjector) 신규 구현, ProjectionService 등록.
- 제안 필드: read_grip_drift.scene_key, read_grip_drift.attempt_num, read_grip_drift.conveyor_speed, read_grip_drift.gripper_temperature
- 트레이드오프: 관심 분리 완벽, 기존 테이블 무변, projection overhead 미미 증가, API version 변경 필.
```typescript
export class DriftProjector implements Projector<ReadGripDriftInsert> { map(event) { const payload = toyDataSchema.parse(event.payload); return { sceneKey: event.streamId.replace(/^grip-attempt:/, ""), attemptNum: event.attemptNum, conveyorSpeed: Number(payload.conveyor_speed), gripperTemperature: Number(payload.gripper_temperature), occurredAt: event.occurredAt, streamId: event.streamId, globalSeq: event.globalSeq }; } }
```

### Decision Outcome
신규 Read Model 생성 (권장)

### Consequences
- (+) Sensor drift data preserved
- (+) Clean architecture separation
- (+) Existing read_grip_result schema untouched
- (−) Projection latency increases slightly due to new projector execution
- (−) API version bump required for public contract evolution

### Non-Goals
- Modifying existing read_grip_result schema
- Fixing upstream data generation pipeline
- Handling non-drift defects (e.g., file corruption)

import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';

type ReadGripDriftInsert = InferInsertModel<typeof readGripDrift>;

@Injectable()
export class GripDriftProjector implements Projector<ReadGripDriftInsert> {
  readonly name: string = "grip-drift-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripDriftProjector.name);

  map(event: EventStoreEventRow): ReadGripDriftInsert {
    let payload: ToyDataDto;
    try {

        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      conveyorSpeed: payload.conveyor_speed ?? null,
      gripperTemperature: payload.gripper_temperature ?? null,
      occurredAt: event.occurredAt,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripDriftInsert): Promise<void> {
    await tx
      .insert(readGripDrift)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripDrift.sceneKey, readGripDrift.attemptNum],
        set: {
          conveyorSpeed: row.conveyorSpeed,
          gripperTemperature: row.gripperTemperature,
          occurredAt: row.occurredAt,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
