- src/projection/projector/grip-result.projector.ts 의 map() 메서드 반환 객체(ReadGripResultInsert) 는 Drizzle 스키마(read-grip-result.ts) 에 매칭된 정형 구조이므로 신규 키가 누락됨. [corr:697be73c-194e-4397-8ebb-b76e94621466]

### Decision Drivers
- 정성 격처 유지 (환경 데이터 vs 파지 결과)
- 스키마 진전 호환성
- 이벤트 store I/O 중복 관리
- API 버전 변경 수용

### Considered Options
#### 기존 read_grip_result 보강 (Column Extension)
- 접근: src/shared/database/schema/service/read-grip-result.ts 에 conveyor_speed, gripper_temperature numeric 컬럼 추가, GripResultProjector.map() 에 payload 키 매핑 추가.
- 제안 필드: read_grip_result.conveyor_speed, read_grip_result.gripper_temperature
- 트레이드오프: 기존 테이블 스키마 진전으로 하위 호환성 검증 필요, 조인/확장 로직이 기존 grip result 모델에 결합됨.

### Decision Outcome
신규 read_grip_environment_v1 분리 (New ReadModel) - 환경 메타데이터가 핵심 파지 결과 로직에 결합되지 않도록 격처 유지하며 스키마 드리프트 대응이 명확함.

### Consequences
- (+) 기존 grip result 모델의 정성 규칙/조인 로직 무변
- (+) 신규 키 유입 시 Read Model 투영 실패(poison event) 방지
- (+) 환경 데이터 조회 경로 독립화
- (−) 버전 switch 및 migration SQL 관리 추가
- (−) 초기 client API 연동 경로 분화 필요
- (−) 이벤트 store 읽기 I/O 중복 증가(동일 stream_id 다중 투영)

### Non-Goals
- payload schema Zod 검증 수정 (소스 코드 변경 금지)
- 기존 read_multimodal/image_uri 매핑 로직 개선
- sensor value message kafka 발행 로직 변경

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripEnvironment } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripEnvironmentInsert = InferInsertModel<typeof readGripEnvironment>;

@Injectable()
export class GripEnvironmentProjector implements Projector<ReadGripEnvironmentInsert> {
  readonly name: string = "grip-environment-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripEnvironmentProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripEnvironmentInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      conveyorSpeed: payload.conveyor_speed ?? null,
      gripperTemperature: payload.gripper_temperature ?? null,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripEnvironmentInsert): Promise<void> {
    await tx
      .insert(readGripEnvironment)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripEnvironment.sceneKey, readGripEnvironment.attemptNum],
        set: {
          conveyorSpeed: row.conveyorSpeed,
          gripperTemperature: row.gripperTemperature,
        },
      });
  }
}
```
