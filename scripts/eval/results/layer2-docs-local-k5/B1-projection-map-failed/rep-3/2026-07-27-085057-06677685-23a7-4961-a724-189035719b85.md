## 1. 권고 (Recommendation)

### Status

### Context (근거)
- (level 50, `projection.map.failed`) objects 비어 있음 ← 트립 앵커 → 투영 로직에서 빈 objects 배열 예외 발생 → 배치 롤백. [corr:06677685-23a7-4961-a724-189035719b85]
- (level 50, `db.error`) 투영 트랜잭션 실패 → 단일 예외 전파로 전체 커서/트랜잭션 상태 손실. [corr:06677685-23a7-4961-a724-189035719b85]
- `GripResultProjector.map()` 메서드에서 `payload.objects.length === 0` 조건 시 `throw new Error(...)` 실행 [corr:06677685-23a7-4961-a724-189035719b85].
- `read_grip_result` 스키마의 `object_name`은 `payload.objects[0].class_name` 기준, 빈 배열 시 원천 데이터 유입이 불가함.
- 현재 `CatchUpRunner`/`ProjectionService` 패턴은 예외 전파로 `db.error` 발생 [corr:06677685-23a7-4961-a724-189035719b85], 커서 정지/롤백.
- 코드는 `src/projection/projector/grip-result.projector.ts` 38~44 라인에서 throw 발생.

### Decision Drivers
- 배치 트랜잭션 정합성 (Rollback vs Skip)
- 원천 데이터 품질 검증 (Reject/Verify)
- 코드 변경 최소화 (Existing Projector)

### Considered Options
#### map() 예외 포착 및 null 반환 (Skip & Log)
- 접근: `GripResultProjector.map()` 빈 objects 조건 시 throw 제거, dead-letter 로그 방출 및 null 반환. Batch executor 전 upsert에서 null 필터링 적용.
- 제안 필드: LogAction.MAP_FAILED, event.eventId
- 트레이드오프: 배치 롤백 차단, 원천 데이터 검증은 외부 요청 위임.
```typescript
if (payload.objects.length === 0) { this.logger.error({ action: LogAction.MAP_FAILED, [LogContext.EVENT_ID]: event.eventId }, "objects 비어 ← dead-letter"); return null; }
```

#### controlled SkipError 전파 (Cursor Advance)
- 접근: `GripResultProjector.map()` 빈 objects 시 `throw new SkipProjectionEventError(event.eventId)` 발생. `CatchUpRunner` 내 `run()` 메서드 catch `SkipProjectionEventError`, 커서 전진(`last_event_seq += 1`) 및 dead-letter 로그 방출, 롤백 차단.
- 제안 필드: SkipProjectionEventError
- 트레이드오프: runner 확용 필요, but minimal projector change.
```typescript
throw new SkipProjectionEventError(event.eventId); // CatchUpRunner.run() catch block advance cursor & log
```

### Decision Outcome
map() 예외 포착 및 null 반환 (Skip & Log)

### Consequences
- (+) 배치 트랜잭션 롤백 차단으로 정상 이벤트 투영 유지.
- (+) dead-letter 로그 방출로 결함 추적 가시성 확보.
- (+) 원천 데이터 검증은 외부 요청 위임으로 정합성 원칙 준수.
- (−) 빈 objects 이벤트가 event_store에 누적되어 추후 재투영 시 동일 dead-letter 발생.
- (−) runner 커서 전진 로직이 별도 필터링 적용 필요로 batch executor 확용 미미 증가.

### Non-Goals
- zod coerce/기본값 치환으로 정상값 위화 (검열 원칙 준수).
- 신규 Read Model 테이블/스키마 생성 (신규 테이블/스키마 변경 금지).
