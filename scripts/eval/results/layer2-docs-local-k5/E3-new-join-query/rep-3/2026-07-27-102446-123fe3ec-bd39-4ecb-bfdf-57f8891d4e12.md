### Decision Outcome
신외 조인 Read Model (`read_grip_result_multimodal`) - 단일 화면 동조회 의도 직접 충족과 N+1 리스크 제로화.

### Consequences
- (+) 클라이언트 단건 조회(`SELECT ... FROM read_grip_result_multimodal WHERE scene_key=? AND attempt_num=?`)로 한 화면 제공
- (+) 조인 로직 DBMS 위양, client-side join overhead 제거
- (−) `event_store` 읽기 2회 동동 투영 시 latency 미미 증가
- (−) storage footprint 확만

### Non-Goals
- `image_2d_uri`, `video_uri` null 매핑 보강 (deferred to URI resolver lane)
- Zod coerce/기본값 치환으로 거절 값 무해화 (principle violation)
- 파일명 regex parsing 최적화 (`MODAL_FILE_NAME_RE`)

### 투영 매핑 명세 (이벤트 → 컬럼)

> upsert 키: scene_key,attempt_num · 리플레이: projection_cursor 초기화 시 주의: catch-up 전체 재투영 시 동일 키(scene_key, attempt_num)에 대해 멱id(upsert) 전제 조건을 반드시 적용하여 기존 행 덮어쓰기 또는 스킵 처리해야 일관성 유지.

| 원천 이벤트 | payload 필드 | 컬럼 | 변환 |
| --- | --- | --- | --- |
| GripAttemptRecorded | objects[].class_name | object_name | take first element verbatim |
| GripAttemptRecorded | grip_succeed | grip_succeed | verbatim |
| GripAttemptRecorded | grip_data.grip_2d_pose | grip_2d_pose | verbatim |
| GripAttemptRecorded | grip_data.grip_3d_pose | grip_3d_pose | verbatim |
| GripAttemptRecorded | human_annotation_grasp[] | human_annotation_grasp | verbatim array |
| GripAttemptRecorded | 2D_image_file_name | image_2d_file_name | verbatim |
| GripAttemptRecorded | video_file_name | video_file_name | verbatim |

파생 컬럼(이벤트 payload 아님):
- `scene_key` ← stream_id.replace(/^grip-attempt:/, '')
- `attempt_num` ← extract attempt number from stream_id/data_key filename pattern (e.g., _00018_01_)
- `gripper_type` ← fixed to 'finger' per system constraint
- `occurred_at` ← extract YYYYMMDD from 2D_image_file_name, convert to ISO timestamp
- `robot_tf` ← merge robot_tf.rotation_3x3 and robot_tf.translation_3x1 into single JSON object
- `stream_id` ← passed through from event stream ID context
- `global_seq` ← passed through from event global sequence context

## 3. API Versioning

> 실행 게이트: 아래 변경은 인간 승인 후에만 적용한다 (human-in-the-loop).

### Unreleased (v1 → v2)

#### Added
- 신규 Read Model 테이블 read_grip_result_multimodal 및 Projector GripResultMultimodalProjectorV2. 단일 조회 뷰로 파지 결과와 멀티모달 미디어 동동 매핑.

- ProjectionController 라우트 /grip-result-multimodal 엔드포인트 등록.

### 마이그레이션 절차

- 하위호환 변경: 기존 read_grip_result, read_multimodal 테이블/프로젝터/라우트는 무손상 유지. v2 확장은 additive-only.; 신규 테이블 키 (scene_key, attempt_num) 는 v1 키 호환과 동일 규칙 적용. 클라이언트 기존 join 로직은 v2 라우트로 대체 가능.
- 파괴적 변경: 없음
- 컷오버 전 테스트: 1. projection.batch 완료 로그(level 30) 확인으로 v1 투영 정상성 검증.
2. catchUpGripResultMultimodalV2 실행 시 global_seq 범위와 row count 가 sum(read_grip_result rows, read_multimodal rows) 일치하는지 SQL 검증.
3. insight.card.request → /grip-result-multimodal 라우트 호출 후 card payload image_2d_file_name/video_file_name 동동 존재하는지 E2E assertion.
- 롤백 창/조건: DDL table read_grip_result_multimodal 및 DI/라우트 제거. v1 decoupled projection fallback 유지. 롤백 조건: v2 투영 latency regression > 50ms or client join dependency conflict.
- Insight 카드 등록: §2의 카드 등록 SQL을 DDL과 함께 적용(카탈로그 동기화)

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripResultMultimodal } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripResultMultimodalInsert = InferInsertModel<typeof readGripResultMultimodal>;

@Injectable()
export class GripResultMultimodalProjector implements Projector<ReadGripResultMultimodalInsert> {
  readonly name: string = "grip-result-multimodal-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripResultMultimodalProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripResultMultimodalInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    if (payload.objects.length === 0) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
        },
        "objects 비어 있음",
      );

      throw new Error(`grip-result-multimodal map: empty objects in event ${event.eventId}`);
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      objectName: payload.objects[0].class_name,
      gripSucceed: payload.grip_succeed,
      gripperType: "finger",
      occurredAt: event.occurredAt,
      grip2dPose: payload.grip_data.grip_2d_pose,
      grip3dPose: payload.grip_data.grip_3d_pose,
      robotTf: payload.robot_tf,
      humanAnnotationGrasp: payload.human_annotation_grasp,
      image2dFileName: payload["2D_image_file_name"],
      videoFileName: payload.video_file_name,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripResultMultimodalInsert): Promise<void> {
    await tx
      .insert(readGripResultMultimodal)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripResultMultimodal.sceneKey, readGripResultMultimodal.attemptNum],
        set: {
          objectName: row.objectName,
          gripSucceed: row.gripSucceed,
          gripperType: row.gripperType,
          occurredAt: row.occurredAt,
          grip2dPose: row.grip2dPose,
          grip3dPose: row.grip3dPose,
          robotTf: row.robotTf,
          humanAnnotationGrasp: row.humanAnnotationGrasp,
          image2dFileName: row.image2dFileName,
          videoFileName: row.videoFileName,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
