파생 컬럼(이벤트 payload 아님):
- `scene_key` ← Remove 'grip-attempt:' prefix from stream_id
- `attempt_num` ← Extract attempt index `_NN_` segment from image_2d_file_name

- `gripper_type` ← Fixed 'finger' per design spec (suction reserved)
- `stream_id` ← Event stream ID metadata
- `global_seq` ← Event global sequence number metadata

### Unreleased (v1 → v2)

#### Added
- 신규 Read Model 테이블 read_grip_multimodal 및 v2 Projector/GripMultimodalProjectorV2
- 신규 라우트 /grip-multimodal 및 서비스 메서드 catchUpGripMultimodalV2

### 마이그레이션 절차

- 하위호환 변경: 기존 v1 테이블·프로젝터·라우트는 무손상 유지. 신규 v2 테이블은 additive only.
- 파괴적 변경: 없음
- 컷오버 전 테스트: 기존 projection pipeline(INSERT_ALL, MULTIModal, GRIP_RESULT) 정상 완료 검증 후, /grip-multimodal 라우트 호출 시 read_grip_multimodal 테이블 row count 및 payload.objects[0].class_name 일치 확인.
- 롤백 창/조건: v2 라우트 DI 제거 및 /grip-multimodal 엔드포인트 주정화. v1 Read Model 조회 로인 재적재.
- Insight 카드 등록: §2의 카드 등록 SQL을 DDL과 함께 적용(카탈로그 동기화)

### 사유·호환성

- 사유: 기존 Insight 카드 카탈로그 미존재로 '파지 결과와 시도의 이미지·영상 경로를 한 화면에서 함께 보고 싶다' 요청 실패. v1 Read Model(`read_grip_result`, `read_multimodal`)은 각각 파지 데이터와 미디어 링크만 저장해, 사용자에게 필요한 결합 시트(테이블)를 직접 조회할 수 없음. 신규 `read_grip_multimodal` 테이블을 추가하여 양자 데이터를 동시 보존하며 단일 키 `(scene_key, attempt_num)`로 매핑, 기존 v1 구조는 무손상 유지.
- 트리거 근거: 03:03:41.272 | 40 | insight.card.miss | 9e67a9b3-5f0b-4b23-a0d9-22b754c99234 | - | - | - | insight 카드 없음: 파지 결과와 해당 시도의 이미지·영상 경로를 한 화면에서 함께 보고 싶다. ← 트립 앵커 [corr:9e67a9b3-5f0b-4b23-a0d9-22b754c99234] v1 GripResultProjector.map() 줄 `objectName: payload.objects[0].class_name` 만 추출해 미디어 링크를 미적재, 단일 조회 실패.
- v1 호환성: 기존 테이블·엔드포인트·프로젝터 클래스/name은 수정·삭제 금지. 새 테이블(`read_grip_multimodal`), 새 프로젝터(`GripMultimodalProjectorV2`, name 끝에 -v2), 새 라우트(`/grip-multimodal`), 새 서비스 메서드(`catchUpGripMultimodalV2`)만 추가. v1 projection pipeline 및 Insight 조회 로인은 기존 동작 무변.

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripMultimodal } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripMultimodalInsert = InferInsertModel<typeof readGripMultimodal>;

@Injectable()
export class GripMultimodalProjector implements Projector<ReadGripMultimodalInsert> {
  readonly name: string = "grip-multimodal-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripMultimodalProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripMultimodalInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    if (payload.objects.length === 0) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
        },
        "objects 비어 있음",
      );

      throw new Error(
        `grip-multimodal map: empty objects in event ${event.eventId}`,
      );
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      objectName: payload.objects[0].class_name,
      gripSucceed: payload.grip_succeed,
      gripperType: "finger",
      occurredAt: event.occurredAt,
      grip2dPose: payload.grip_data.grip_2d_pose,
      grip3dPose: payload.grip_data.grip_3d_pose,
      robotTf: payload.robot_tf,
      humanAnnotationGrasp: payload.human_annotation_grasp,
      image2dFileName: payload["2D_image_file_name"],
      videoFileName: payload.video_file_name,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripMultimodalInsert): Promise<void> {
    await tx
      .insert(readGripMultimodal)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripMultimodal.sceneKey, readGripMultimodal.attemptNum],
        set: {
          objectName: row.objectName,
          gripSucceed: row.gripSucceed,
          gripperType: row.gripperType,
          occurredAt: row.occurredAt,
          grip2dPose: row.grip2dPose,
          grip3dPose: row.grip3dPose,
          robotTf: row.robotTf,
          humanAnnotationGrasp: row.humanAnnotationGrasp,
          image2dFileName: row.image2dFileName,
          videoFileName: row.videoFileName,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```
