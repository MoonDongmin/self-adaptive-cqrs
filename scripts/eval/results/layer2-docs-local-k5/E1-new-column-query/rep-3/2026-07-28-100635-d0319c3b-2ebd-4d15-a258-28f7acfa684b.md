### Decision Drivers
- Schema Stability (기존 Read Model 스키ma 드리프트 방지)
- Time-Series Query Requirement (occurred_at 기준 시계열 집게 필요)
- Isolation Principle (sensor drift domain 과 grip result domain 분리)
- Versioning Control (API/Model 버전 관리 추적)

### Considered Options
#### newReadModel
- 접근: 신규 Projector(SensorDriftProjector) 생성, read_grip_sensor_drift_v2 테이블 매핑
- 제안 필드: scene_key, attempt_num, occurred_at, gripper_temperature, conveyor_speed, stream_id, global_seq
- 트레이드오프: 기존 Read Model 스키ma 무변, 신규 키 격리·무해화 용이, 투영 비용 증감(신규 커서/테이블)
```typescript
return { sceneKey: event.streamId.replace(/^grip-attempt:/, ""), attemptNum: event.attemptNum, occurredAt: event.occurredAt, gripperTemperature: payload.gripper_temperature, conveyorSpeed: payload.conveyor_speed, streamId: event.streamId, globalSeq: event.globalSeq };
```

#### existingColumnExtension
- 접근: read_grip_result Drizzle 스키ma 추가 컬럼, GripResultProjector.map() 수정
- 제안 필드: gripper_temperature, conveyor_speed
- 트레이드오프: 기존 Read Model 스키ma 드리프트 발생, grip result domain 과 sensor drift domain 결합으로 책임 위반, 버전 관리 복잡성
```typescript
return { ...row, gripperTemperature: payload.gripper_temperature, conveyorSpeed: payload.conveyor_speed };
```

### Decision Outcome
newReadModel adoption. 사유: 기존 Read Model 스키ma 드리프트 방지, sensor drift domain 격리, 시계열 조회 요구사항 충족.

### Consequences
- (+) Existing tables/schema 무변, client 호환성 유지
- (+) Sensor data lookup isolation, Zod 미정의 필드 유실 대응 용이
- (+) Time-series 조회(occurred_at 기준) 직접 매핑 가능
- (−) 신규 Projector/테이블 관리 오버헤드, catch-up 커서 추가 관리 필요
- (−) API 엔드포인트 확장(versionSwitch) 동반 필요, 버전 추적 복잡성 증감

### Non-Goals
- 기존 read_grip_result 스키ma 수정, payload.schema.drift 로그 제거
- Zod schema 강제 수정으로 default 값 치환 권고 (검열·격리 유지 원칙 준수)

CREATE TABLE read_grip_sensor_drift_v2 (

  attempt_num smallint NOT NULL,
  occurred_at timestamptz,
  gripper_temperature varchar,
  conveyor_speed varchar,

### 투영 매핑 명세 (이벤트 → 컬럼)

> upsert 키: scene_key, attempt_num · 리플레이: projection_cursor 초기화 시 latest global_seq 기준 설정. catch-up 재투영은 upsert 전제이므로 scene_key+attempt_num 키 중복 시 최신 payload.schema.drift 값으로 덮어쓰되, insert.file.ok 기반 stream_id/global_seq는 원천 이벤트 순서 유지.

| 원천 이벤트 | payload 필드 | 컬럼 | 변환 |
| --- | --- | --- | --- |
| insert.file.ok | stream_id | stream_id | verbatim |
| insert.file.ok | global_seq | global_seq | verbatim |

파생 컬럼(이벤트 payload 아님):
- `scene_key` ← stream_id prefix 'grip-attempt:' 제거
- `attempt_num` ← stream_id 내 `_NN_` 패턴 추출 (시도 번호)
- `occurred_at` ← YYYYMMDD 날짜 추출 → ISO timestamp 변환

### 사유·호환성

- 사유: 신규 payload 키(gripper_temperature, conveyor_speed) 유입 감지([corr:d0319c3b-2ebd-4d15-a258-28f7acfa684b])로 인해 기존 Insight Card 카탈로그(read_grip_result, read_multimodal)에는 미등록된 신규 모델/카드 부재([corr:c3c1a1a2-0015-4fd9-839e-f24ea6696a1b]). v1 기존 프로젝터는 toyDataSchema 검증만 수행하고 신규 키를 무시하는 구조이므로 시간대별 조회 요청을 충족할 수 없음. 새 Read Model(read_grip_sensor_drift_v2)과 전용 프로젝터를 배선하여 동시 운영(coexistence)으로 이전 시퀀스 데이터가 v2에 누락될 수 있으나, 이는 backwardCompatibleChanges 로 명시된 '신규 필드 유입'이므로 컷오버 전 검증 절차로 보전한다.
- 트리거 근거: | 01:06:35.631 | 40 | payload.schema.drift | d0319c3b-2ebd-4d15-a258-28f7acfa684b | - | - | - | payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) ← 트립 앵커 | newKeys={"conveyor_speed": "1.2", "gripper_temperature": "36.5"} |
이 행에서 감지된 신규 키는 v1 toyDataSchema 검증 로logic(src/insert/dto/toy-data.dto.ts)과 GripResultProjector.map() payload.objects[0].class_name 등 이가 신규 필드를 스키마에 미등록하여 매핑 시 유실됨. 기존 Insight Card 카탈로그에는 미등록된 신규 모델 부재([corr:c3c1a1a2-0015-4fd9-839e-f24ea6696a1b]).
- v1 호환성: 기존 read_grip_result와 read_multimodal 테이블/프로젝터는 100% 무손상 유지. 신규 v2 Read Model은 동시 운영(coexistence)으로 이전 시퀀스 데이터가 v2에 누락될 수 있으나, 이는 backwardCompatibleChanges 로 명시된 '신규 필드 유입'이므로 컷오버 전 검증 절차로 보전한다.

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDriftDto, toyDataDriftSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripSensorDrift } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripSensorDriftInsert = InferInsertModel<typeof readGripSensorDrift>;

@Injectable()
export class GripSensorDriftProjector implements Projector<ReadGripSensorDriftInsert> {
  readonly name: string = "grip-sensor-drift-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripSensorDriftProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripSensorDriftInsert {
    let payload: ToyDataDriftDto;
    try {
      payload = toyDataDriftSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      occurredAt: event.occurredAt,
      gripperTemperature: payload.gripper_temperature ?? null,
      conveyorSpeed: payload.conveyor_speed ?? null,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripSensorDriftInsert): Promise<void> {
    await tx
      .insert(readGripSensorDrift)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripSensorDrift.sceneKey, readGripSensorDrift.attemptNum],
        set: {
          occurredAt: row.occurredAt,
          gripperTemperature: row.gripperTemperature,
          conveyorSpeed: row.conveyorSpeed,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```
