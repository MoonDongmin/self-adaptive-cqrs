## 1. 권고 (Recommendation)

> 감시 판정: 물리적 센서 치우침(z≤0, xl>1920)이 실패 시도 데이터에 비정상 적재되어 Read Model 오염을 확정.

### 심각도 — critical

오염 컬럼(grip3dPose/grip2dPose)이 물리적 한계 초과/미만으로 Read Model 정합성 위배. 영향 행수(2건)가 소수이나 event_store 원천 보존 가용하여 재투영 복구가 가능하나, 현재 pipeline의 Zod 검증 부재로 오염이 영구 고착될 위험.

### 기대-실측 델타 근거

- (반려동물용품_CR01_강아지공룡알장난감_02006#1, `grip3dPose` / grip3dPose) 관측 `-0.05` vs 기준 `grip3dPoseZ_depth` [0.01, 0.30] m → 델타 -0.06 (미만 최소 0.01) · 물리적 깊이 음수(카메라 뒤)로 불가능한 측정치
- (반려동물용품_CR01_강아지공룡알장난감_02007#1, `grip2dPose` / grip2dPose) 관측 `2500` vs 기준 `grip2dPose_withinImage` x in [0, 1920], y in [0, 1110] → 델타 580 (초월 최대 1920) · 이미지 너비(1920px) 초과로 화면 밖 픽셀 좌표

### 관찰

- R2 depthNegative: grip3dPose.z1 ≤ 0 위반
- R3 pixelRangeViolation: grip2dPose.xl > 1920px 위반

### 영향 범위

- event_store → grip-result-projector → read_grip_result(grip_2d_pose/grip_3d_pose) → catch-up.runner.ts → projection.controller.ts(/grip-result) → API v1

### 근본원인 — projectionOrPipelineFault

1. 왜 이상 발생? → 실패(gripSucceed=0) 데이터의 물리적 치우침(z≤0, xl>1920)이 허용됨.
2. 왜 허용? → GripResultProjector.map() 만 Zod 구조 검증만 수행, 의미적 값 오류 필터링 부재.
3. 왜 부재? → Read Model 스키마에 depthNegative/pixelRangeViolation 검 규칙 미구현.
4. 왜 미구신? → 기존 구현 소스(GripResultProjector)에 checkIntegrity() 미구현 및 physical validity 로직 누락.
5. 왜 누락? → 시스템적 판정 부재 — 구조적 zod만 존재, 물리적 baseline 검증 파이프라인 결결.

### 의사결정 기준

- 1. 데이터 보존(event_store 원천 유지 vs 삭제)
- 2. downstream 영향(read_grip_result 정합성 vs API 안정성)
- 3. 구현 부담(프로젝터 수정 vs DB 격리 SQL)

### 해결책 옵션 (contain → fix → harden)

## 3. API Versioning

> 실행 게이트: 아래 변경은 인간 승인 후에만 적용한다 (human-in-the-loop).

### Unreleased (v1 → v2)

#### Added
- 신규 Read Model read_grip_result_v2 테이블과 Drizzle 스키마, GripResultProjectorV2 프로젝터 구현
- 라우트 /grip-result-v2 및 ProjectionService.catchUpGripResultV2 배선
#### Fixed
- sensor_baseline_deviation 이상 감지: z1≤0 및 xl>1920 물리적 이탈을 explicit 플래그 매핑으로 분리

### 마이그레이션 절차

- 하위호환 변경: 기존 read_grip_result 테이블과 GripResultProjector 클래스/이름은 수정·삭제 금지. 신규 v2는 addFile로 생성.; DI와 라우트만 한 줄 추가(modifyFile)로 배선. v1은 legacy aggregation 호환, v2는 이상 플래그 기반 정합성 검증을 동시 수행.
- 파괴적 변경: 없음
- 컷오버 전 테스트: GS 26(z1=-0.05)와 GS 27(xl=2500) 원시 레코드 재검인: v2 depth_negative_flag=1, pixel_range_violation_flag=1 매칭 확인. v1 grip3dPose/grip2dPose raw value 보존 확인. downstream aggregation query가 v2 플래그 filter를 적용할 수 있는지 E2E 검증.
- 롤백 창/조건: v2 투영 성능 저하 또는 downstream 호환성 깨짐 시, 컷오버 전 revert to v1 projection route. 이상 감지는 query layer에서 z1≤0/xl>1920 filter로 대체. migrationSql DROP read_grip_result_v2.
- Insight 카드 등록: §2의 카드 등록 SQL을 DDL과 함께 적용(카탈로그 동기화)

### 사유·호환성

- 사유: v1 GripResultProjector.map()은 payload.grip_data.grip_3d_pose.z1과 payload.grip_data.grip_2d_pose.xl 값을 무조건 적재할 수 있는 JSONB 컬럼에 매핑한다. 물리적 깊이 음수(z1 ≤ 0)와 이미지 경계 초과(xl > 1920px)가 발생 시, v1은 silently invalid data를 저장하고 downstream aggregations이 왜곡된다[corr:GS26][corr:GS27]. 신규 Read Model read_grip_result_v2는 이 두 이탈을 explicit 플래그(depth_negative_flag, pixel_range_violation_flag)로 분리해 투영 시 즉시 이상 감지할 수 있도록 설계한다.
- 트리거 근거: window GS 26 anchor row: {"sceneKey":"반려동물용품_CR01_강아지공룡알장난감_02006","attemptNumber":1,"globalSequence":26,"gripSucceed":0,"grip3dPose":{"z1":-0.05}} → z1=-0.05 ≤ 0 위반[corr:GS26]. v1 code line `return { ... grip3dPose: payload.grip_data.grip_3d_pose, ... }` loads raw value without bounds check.
window GS 27 anchor row: {"sceneKey":"반려동물용품_CR01_강아지공룡알장난감_02007","attemptNumber":1,"globalSequence":27,"gripSucceed":0,"grip2dPose":{"xl":2500}} → xl=2500 > 1920 위반[corr:GS27]. v1 code line `return { ... grip2dPose: payload.grip_data.grip_2d_pose, ... }` loads raw value without bounds check.
- v1 호환성: 기존 read_grip_result 테이블과 GripResultProjector 클래스/이름은 수정·삭제 금지. 신규 read_grip_result_v2 테이블과 GripResultProjectorV2 클래스는 addFile로 생성. DI와 라우트만 한 줄 추가(modifyFile)로 배선. v1은 legacy aggregation 호환, v2는 이상 플래그 기반 정합성 검증을 동시 수행.

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripResultV2 } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripResultV2Insert = InferInsertModel<typeof readGripResultV2>;

@Injectable()
export class GripResultV2Projector implements Projector<ReadGripResultV2Insert> {
  readonly name: string = "grip-result-v2-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripResultV2Projector.name);
  }

  map(event: EventStoreEventRow): ReadGripResultV2Insert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    if (payload.objects.length === 0) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
        },
        "objects 비어 있음",
      );

      throw new Error(`grip-result-v2 map: empty objects in event ${event.eventId}`);
    }

    const depthNegativeFlag = payload.grip_data.grip_3d_pose.z1 <= 0 ? 1 : 0;
    const pixelRangeViolationFlag = payload.grip_data.grip_2d_pose.xl > 1920 ? 1 : 0;

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      objectName: payload.objects[0].class_name,
      gripSucceed: payload.grip_succeed,
      occurredAt: event.occurredAt,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
      depthNegativeFlag,
      pixelRangeViolationFlag,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripResultV2Insert): Promise<void> {
    await tx
      .insert(readGripResultV2)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripResultV2.sceneKey, readGripResultV2.attemptNum],
        set: {
          objectName: row.objectName,
          gripSucceed: row.gripSucceed,
          occurredAt: row.occurredAt,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
          depthNegativeFlag: row.depthNegativeFlag,
          pixelRangeViolationFlag: row.pixelRangeViolationFlag,
        },
      });
  }
}
```

### 버전 교체 코드 — `src/projection/projection.service.ts` (modifyFile)

```typescript
import { Injectable } from '@nestjs/common';
import { PinoLogger } from 'nestjs-pino';
import { InsertResult, InsertService } from '@/insert/insert.service';
import { GripResultProjector } from '@/projection/projector/grip-result.projector';
import { MultiModalProjector } from '@/projection/projector/multimodal.projector';
import { GripResultProjectorV2 } from '@/projection/projector/grip-result-v2.projector';
import { ProjectionResult } from '@/projection/projector/projector';
import { CatchUpRunner } from '@/projection/runner/catch-up.runner';
import { LogAction } from '@/shared/logger/logging-context';

export type CatchUpAllResult = {
  multimodal: ProjectionResult;
  gripResult: ProjectionResult;
  gripResultV2: ProjectionResult;
};

export type InsertAndProjectionAllResult = {
  insert: InsertResult;
  projection: CatchUpAllResult;
};

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly gripResultV2: GripResultProjectorV2,
    private readonly insertService: InsertService,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  catchUpMultimodal(): Promise<ProjectionResult> {
    return this.runner.run(this.multimodal);
  }

  catchUpGripResult(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResult);
  }

  catchUpGripResultV2(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResultV2);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();
    const gripResultV2: ProjectionResult = await this.catchUpGripResultV2();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult, gripResultV2 };
  }

  async insertAllAndProjectAll(): Promise<InsertAndProjectionAllResult> {
    this.logger.info(
      { action: LogAction.PROJECTION_START },
      "전체 적재+투영 시작",
    );

    const insert: InsertResult = await this.insertService.insertToyData();
    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
}
```
