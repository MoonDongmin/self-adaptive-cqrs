## 1. 권고 (Recommendation)

> 데이터 품질 판정: 두 레코드(`..._02006#1`, `..._02007#1`)의 깊이와 2D 좌표가 물리적/이미지 경계 규칙을 명백히 위반하여 즉시 격리 권고 (critical).

### 심각도 — critical

오염 컬럼(`grip3dPose`, `grip2dPose`) 은 하류 컨트롤러 및 API 응답 에 직접 노출 될 수 있으며, 영향 행수는 2 건 으로 국한 되 나 event_store 원천 데이터 가 보존 되어 재투영(fix) 이 가능 한 다 현 Read Model(`read_grip_result`) 에 는 무방 조건(jsonb) 을 허용 해 정적 검실패 로 인한 오염 유입 이 확정 됨.

### 기대-실측 델타 근거

- (반려동물용품_CR01_강아지공룡알장난감_02006#1, `grip3dPose` / grip3dPose) 관측 `-0.05` vs 기준 `grip3dPoseZ_depth` [0.01, 0.30] m → 델타 -0.06 m below lower bound · 깊이 위반: 카메라 프레임 에서 물체 거리 가 음수 일 수 없음.
- (반려동물용품_CR01_강아지공룡알장난감_02007#1, `grip2dPose` / grip2dPose) 관측 `2500` vs 기준 `grip2dPose_withinImage` x in [0, 1920], y in [0, 1110] → 델타 +580 px above upper bound · 이미지 너비 1920px 초과된 좌표 는 물리적 불가능 한 투영.

### 관찰

- record ..._02006#1 grip3dPoseZ(z1)=-0.05 violates depth>0 rule
- record ..._02007#1 grip2dPose(xl)=2500 exceeds width=1920 rule

### 영향 범위

- event_store → grip-result-projector.map() → read_grip_result(grip_2d_pose, grip_3d_pose) → ProjectionController(/projection/grip-result) → API 응답(InsertAndProjectionAllResult)

### 근본원인 — projectionOrPipelineFault

1. 원천 센서(카메라/Depth) 출력 에 음수 깊이 와 초과된 픽셀 을 포함 함.
2. 왜 DB 에 그 값 을 적재 했 는가? GripResultProjector.map() 이 Zod 구조 검증(toyDataSchema) 만 통과 하고 의미적 값 범위 검실패 가 누락 됨.
3. 왜 검실패 가 누락 되었 는가? Read Model 스키마(read_grip_result) 가 jsonb 타입 으로 유연 한 객체 저 장 을 설계 해 정 적 열 거/범 위 제 감 이 배제 됨.
4. 왜 정 적 제 감 을 배제 했 는가? 초기 Read Model 설계 가 원천 payload 의 무조건 투 영 만 우선 화 하고 이상 감 지 로직 을 하 류 관찰자(LLM) 위 양 으로 미루 음.
5. 왜 미루 음? 구조 적 Zod 검증 만 존재 하여 값 이상 판 정 부 재 — 구조 적 zod 만 존재' 가 시스템 의 고 질 관 행.

### 의사결정 기준

- 데이터 정성 유지(event_store 원천 보존 vs Read Model 오염 격리)
- 하 류 API/컨트롤러 영향 차단(즉 시 격 리 vs 재 투 영)
- 운영 비용 및 복잡 도(SQL/TS 수정 vs 신규 테이블 설계)
- 규 율 영 구 화 필 요 성(베이스 라인 문서 추가 vs 일 회 성 격 리)

| GripAttemptRecorded | streamId | stream_id | verbatim |
| GripAttemptRecorded | attemptNumber | attempt_num | verbatim |
| GripAttemptRecorded | objects[].class_name | object_name | payload.objects[0].class_name |
| GripAttemptRecorded | grip_succeed | grip_succeed | verbatim |
| GripAttemptRecorded | occurredAt | occurred_at | verbatim |
| GripAttemptRecorded | globalSequence | global_seq | verbatim |

파생 컬럼(이벤트 payload 아님):
- `scene_key` ← streamId prefix 'grip-attempt:' 제거
- `grip_outlier_flag` ← 1 if MIN(z1..z8)<0 OR MAX(xl,xr)>1920 else 0
- `min_depth_observed` ← MIN(grip3dPose.z1, ..., grip3dPose.z8)
- `max_pixel_xl_observed` ← MAX(grip2dPose.xl, grip2dPose.xr)

## 3. API Versioning

> 실행 게이트: 아래 변경은 인간 승인 후에만 적용한다 (human-in-the-loop).

### Unreleased (v1 → v2)

#### Added
- read_grip_result_v2 테이블·GripResultProjectorV2 프로젝터·/grip-result-v2 라우트 배어. 물리적 depth≤0/pixel>1920 위반 플래그화 및 검지 로직 도입.
- schema/index.ts v2 스키마 export 추가.

### 마이그레이션 절차

- 하위호환 변경: -
- 파괴적 변경: read_grip_result_v2 introduces grip_outlier_flag, min_depth_observed, max_pixel_xl_observed columns. 기존 v1 read_grip_result 테이블은 무손상 유지이나 컷오버 이후 신규 클라이언트/대시보드 연queries는 v2 스키마 기준 적용.
- 컷오버 전 테스트: 1. CatchUpRunner 실행으로 v1·v2 동시 투영 수행.
2. JOIN scene_key, attempt_num 기준으로 v1 gripSucceed vs v2 gripOutlierFlag 일치 검증(모든 row에서 v1 outlier_flag=0, v2 flag=0).
3. 만약 v2 flag=1 이면서 v1 적재된 row 존재 → 컷오버 금지, 이상 로그 방출.
4. 모든 row 일치 시 컷오버 승인.
- 롤백 창/조건: 컷오버 실패 또는 v2 outlier_flag=1 row 발견 시: 1) /grip-result-v2 라우트 차단, 2) 기존 /projection/grip-result(v1) 라우트 재개시, 3) read_grip_result_v2 테이블 DROP 및 GripResultProjectorV2 DI 제거. rollback 창: 컷오버 승인 commit 전까지.
- Insight 카드 등록: §2의 카드 등록 SQL을 DDL과 함께 적용(카탈로그 동기화)

### 사유·호환성

- 사유: 기존 v1 GripResultProjector.map() 메서드에서 payload.objects[0].class_name 만 추출하고 pose/robot_tf 원값을 그대로 적재하는 구조(zod) 검증만 통과한 채로 물리적 범위 검사를 건너뛴다. 이로 인해 Record 02006#1 grip3dPoseZ(z1)=-0.05m(깊이 ≤ 0)와 Record 02007#1 grip2dPose(xl)=2500px(이미지 경계 1920px 초과)가 DB에 적재되며 downstream 관찰자/분석 파이프라인에서 기준선 편만 현으로 이어진다 [corr:1] [corr:2]. v2 Read Model(read_grip_result_v2)은 min_depth_observed, max_pixel_xl_observed, grip_outlier_flag 컬럼을 도입하고 checkIntegrity() 검사를 배어 물리적 불가능한 관측값을 플래그화하여 DB 오염을 차단.
- 트리거 근거: [Seq 26] sceneKey=반려동물용품_CR01_강아지공룡알장난감_02006, attemptNum=1, globalSeq=26 | payload.grip3dPose.z1=-0.05 (깊이 ≤ 0 — 카메라 뒤/평면 위 물체는 불가능) [corr:1]
[Seq 27] sceneKey=반려동물용품_CR01_강아지공룡알장난감_02007, attemptNum=1, globalSeq=27 | payload.grip2dPose.xl=2500 (이미지 경계 [0, 1920]px 밖 — 화면 밖 픽셀 좌표는 불가능) [corr:2]
v1 코드의 map() 메서드 줄: return { ..., grip3dPose: payload.grip_data.grip_3d_pose, ... }; 에서 z1~z8 최소/최값 계산 및 outlier_flag 세팅이 누락됨.
- v1 호환성: 기존 read_grip_result 테이블·GripResultProjector 클래스·라우트 엔드포인트를 수정·삭제 금지. v2(read_grip_result_v2, GripResultProjectorV2)는 신규 파일/엔드포인트(/grip-result-v2)로 배어 동시 존재 가능. 컷오버 전 testBeforeCutover 검증으로 v1/v2 outlier_flag 일치 시 v1 적재 중단, 이후 v2 전용 라우트 전환.

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripResultV2 } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripResultV2Insert = InferInsertModel<typeof readGripResultV2>;

const IMAGE_WIDTH_LIMIT: number = 1920;
const DEPTH_LOWER_BOUND: number = 0;

@Injectable()
export class GripResultV2Projector implements Projector<ReadGripResultV2Insert> {
  readonly name: string = "grip-result-v2-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripResultV2Projector.name);
  }

  map(event: EventStoreEventRow): ReadGripResultV2Insert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    const sceneKey: string = event.streamId.replace(/^grip-attempt:/, "");
    const attemptNum: number = event.attemptNum;
    const objectName: string = payload.objects[0].class_name;
    const gripSucceed: number = payload.grip_succeed;
    const occurredAt: Date = event.occurredAt;

    const pose3d = payload.grip_data.grip_3d_pose;
    const pose2d = payload.grip_data.grip_2d_pose;

    const minZ: number = Math.min(pose3d.z1, pose3d.z2, pose3d.z3, pose3d.z4, pose3d.z5, pose3d.z6, pose3d.z7, pose3d.z8);
    const maxXL: number = Math.max(pose2d.xl, pose2d.xr);

    let outlierFlag: number = 0;
    if (minZ <= DEPTH_LOWER_BOUND || maxXL > IMAGE_WIDTH_LIMIT) {
      outlierFlag = 1;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: sceneKey,
        [LogContext.ATTEMPT_NUM]: attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey,
      attemptNum,
      objectName,
      gripSucceed,
      occurredAt,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
      gripOutlierFlag: outlierFlag,
      minDepthObserved: minZ,
      maxPixelXlObserved: maxXL,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripResultV2Insert): Promise<void> {
    await tx
      .insert(readGripResultV2)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripResultV2.sceneKey, readGripResultV2.attemptNum],
        set: {
          objectName: row.objectName,
          gripSucceed: row.gripSucceed,
          occurredAt: row.occurredAt,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
          gripOutlierFlag: row.gripOutlierFlag,
          minDepthObserved: row.minDepthObserved,
          maxPixelXlObserved: row.maxPixelXlObserved,
        },
      });
  }
}
```
