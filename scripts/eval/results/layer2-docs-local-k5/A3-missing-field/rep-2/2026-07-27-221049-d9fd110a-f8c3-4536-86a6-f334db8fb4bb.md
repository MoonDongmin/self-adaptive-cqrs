### Decision Drivers
- Data Integrity Preservation: 검증 실패된 값(타입 위반/필수 누락)을 Read Model에 유입시켜야 금지 원칙 준수.
- System Decoupling: 적재(load)와 투영(projection) 파이프라인이 독립 유지해야 차단 무관.
- Auditability/Verification: 결함 파일의 event_store 부재가 명시히 확인해야 system consistency 보장.
- Zero Schema Change: 기존 Zod/Read Model 테이블/엔드포인트 불변 유지해야 API versioning 안정화.
