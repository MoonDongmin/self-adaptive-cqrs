사용자가 최근 적재 데이터에 포함된 `gripper_temperature` 필드를 시간대별로 조회할 수 있는 Read Model 을 요청했으나, 기존 `read_grip_result` 및 `read_multimodal` 테이블에는 해당 필드가 정의되어 있지 않아 조회가 불가능합니다. 이는 `payload.schema.drift` 로그에서 `newKeys={"conveyor_speed": "1.2", "gripper_temperature": "36.5"}`로 신규 키 유입이 감지되었음에도 불구하고, 기존 Insight Card 카탈로그에 미등재된 Read Model 이 부재했기 때문입니다. 결과적으로 `insight.card.miss` 로그가 3 회 반복 발생하며, 사용자의 시간대별 조회 intent 가 실패했습니다.
