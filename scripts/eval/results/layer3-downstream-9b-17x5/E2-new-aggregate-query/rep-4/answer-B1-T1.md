사용자가 객체별 파지 성공률 (시도 수, 성공 수, 성공률) 을 한 번에 조회하는 요청을 보냈으나, 기존 Read Model 은 이를 지원하지 못합니다. 로그에서 `insight.card.request` 와 `insight.card.miss` 액션이 빈번히 발생하고, `detail` 필드에 "객체 (object_name) 별 파지 성공률을 한 번에 조회하고 싶다"는 오류 메시지가 포함되어 있어, 해당 기능이 현재 구현되지 않았음을 알 수 있습니다. Read Model 의 `read_grip_result` 테이블은 `(scene_key, attempt_num)` 을 주 키로 하여 개별 시도별 파지 결과를 저장하고 있으며, `object_name` 을 기준으로 집계된 통계 데이터가 존재하지 않습니다. 따라서 `object_name` 을 그룹화하여 시도 수와 성공 수를 계산하고, 이를 바탕으로 성공률을 도출하는 SQL 쿼리가 작성되어야 합니다.
