사용자가 `POST /object-success-rate` 엔드포인트를 호출하여 객체별 파지 성공률 (시도 수, 성공 수, 성공률) 을 조회했으나, 기존 Read Model (`read_grip_result`) 은 장면과 시도 단위의 원자적 행 (row-level) 데이터만 보유하고 있어 집계된 결과를 직접 제공하지 못해 요청이 실패했습니다. 로그 분석 결과 `insight.card.request`가 3 회 발생했으나, `insight.card.miss`가 3 회 기록되어 해당 인사이트 카드가 미등록되어 있음을 확인했습니다. 이는 `GripResultProjector` 가 `object_name` 과 `grip_succeed` 를 장면/시도 단위로만 매핑하고 누적 집계 로직을 수행하지 않아, `object_name` 을 주 키로 하는 `read_object_success_rate_v1` 테이블이 부재했기 때문입니다. 따라서 `object_name` 단위의 `total_attempts`, `success_count`, `success_rate` 필드를 가진 신규 Read Model 을 생성해야 사용자의 조회 요구사항을 충족할 수 있습니다.
