사용자가 `POST /object-success-rate` 엔드포인트를 호출하여 객체별 파지 성공률 (시도 수, 성공 수, 성공률) 을 조회했으나, `insight.card.miss` 로그가 발생하여 요청이 실패했습니다. 이는 `insight.card.request` 로직이 `read_object_success_rate_v1`이라는 집계 (Aggregation) Read Model 테이블을 카탈로그에 등록하지 않아, 해당 엔티티를 DB 에서 조회할 수 없기 때문입니다. 기존 `read_grip_result` 테이블은 `scene_key` 와 `attempt_num` 을 PK 로 하는 이벤트 단위 (Row-level) 데이터로만 구성되어 있어, `object_name` 기준으로 집계된 필드 (total_attempts, success_count, success_rate) 가 부재하여 사용자의 요구사항을 충족하지 못했습니다.
