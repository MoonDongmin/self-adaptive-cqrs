사용자가 '일자별 파지 성공률 추이'를 포함한 집계 조회를 요청했으나, 기존 Read Model 은 장면별 시도 단위 (scene_key, attempt_num) 의 원자적 데이터만 저장하고 있어 시간별 집계 쿼리가 불가능합니다. 로그에서 `insight.card.miss` 레벨 40 에 해당 요청이 기록된 것으로 보아, 시스템은 해당 집계 뷰가 존재하지 않음을 인지하고 있습니다. Read Model 의 `read_grip_result` 테이블은 `occurred_at` 필드가 존재하지만, 이를 기준으로 `attempt_num` 과 `scene_key` 를 그룹화하여 성공률 (grip_succeed) 을 계산할 수 있는 인덱스나 뷰가 정의되어 있지 않습니다. 따라서 사용자의 요청은 현재 아키텍처의 Read Model 구조상 지원되지 않는 조회 패턴입니다.
