사용자가 '일자별 파지 성공률 추이'를 포함한 집계 조회를 요청했으나, 제공된 Read Model 은 `(scene_key, attempt_num)` 을 기본 키로 하는 개별 파지 결과만 저장하고 있어, 날짜별 시도 수나 성공 수와 같은 집계된 통계 값을 직접 조회할 수 없습니다.

구체적으로 `read_grip_result` 테이블의 `occurred_at` 필드는 개별 데이터의 촬영 일자만 포함하며, `attempt_num` 필드는 같은 장면 내의 시도 번호를 의미하므로, 이를 기준으로 날짜와 시도 횟수를 그룹화하여 성공률을 계산하는 SQL 쿼리를 작성할 수 없습니다.

또한 로그 분석 결과, `insight.card.request` 와 `insight.card.miss` 로그가 반복적으로 발생하고 있으며, `detail` 필드에 "일자별 파지 성공률 추이를 보고 싶다. ... 현재 Read Model 로 가능한가?"라는 텍스트가 포함되어 있어, 사용자가 기존 Read Model 을 통해 원하는 데이터를 얻을 수 없음을 확인했습니다.

따라서 요청된 '일자별 파지 성공률 추이'는 현재 Read Model 의 구조상 불가능하며, 별도의 집계 쿼리나 새로운 Read Model 생성이 필요하거나, 원본 이벤트 스트림을 직접 조회하여 처리해야 합니다.
