사용자가 '일자별 파지 성공률 추이 (날짜별 시도 수, 성공 수, 성공률)'를 요청했으나, 기존 Read Model(`read_grip_result`) 은 장면별·시도별 (scene_key, attempt_num) 행 단위 데이터만 보유하고 있어 날짜별 집계 (GROUP BY) 로직이 구현되지 않아 조회가 실패했습니다. 로그 분석 결과 `insight.card.miss`가 3 회 발생하며, 이는 `read_grip_result` 테이블에 `total_attempts`나 `success_count`와 같은 일일 누적 필드가 존재하지 않고, `GripResultProjector` 에서도 `occurredAt` 기반의 일일 집계 로직이 미적재되었음을 보여줍니다. 따라서 사용자 의도를 충족시키기 위해 `read_daily_grip_stats_v2`라는 새로운 집계 전용 Read Model 테이블을 생성해야 합니다.
