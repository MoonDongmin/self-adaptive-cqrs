사용자가 '일자별 파지 성공률 추이'를 포함한 시계열 집계 조회를 요청했으나, 기존 Read Model 은 `read_grip_result` 와 `read_multimodal` 테이블이 `(scene_key, attempt_num)` 조합을 기본 키로 하여 개별 파지 시도 단위의 원자 데이터만 저장하고 있어, 날짜 (`occurred_at`) 를 기준으로 그룹화한 집계 결과를 직접 조회할 수 없습니다.

로그 분석 결과, `insight.card.request` 액션이 발생했으나 `insight.card.miss` 응답이 반환된 것으로 보아, 요청된 '일자별 파지 성공률 추이'라는 인사이트 카드 ID 가 현재 데이터베이스에 존재하지 않거나 매핑되지 않았음을 알 수 있습니다.

이러한 원인은 Read Model 의 스키마 정의에서 `occurred_at` 필드가 존재하지만, 이를 기준으로 `attempt_num` 과 `scene_key` 를 그룹화하여 `count`, `sum`, `avg` 와 같은 집계 연산을 수행하는 뷰나 별도 테이블이 정의되어 있지 않기 때문입니다.

따라서 사용자가 원하는 '시간 순'으로 정렬된 '시도 수', '성공 수', '성공률'이라는 3 차원 시계열 데이터는 현재 `read_grip_result` 테이블의 원본 데이터를 직접 쿼리하여 애플리케이션 레벨에서 집계 처리해야만 얻을 수 있습니다.
