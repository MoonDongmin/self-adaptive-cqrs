사용자가 '일자별 파지 성공률 추이'를 포함한 시계열 집계 데이터를 요청했으나, `insight.card.miss` 로그 (예: `7f638470-b913-438a-a200-1c6b20779b34`) 에서 3 회 연속으로 해당 요청이 매칭되지 않아 시스템이 기능을 제공하지 못했습니다. 이는 기존 Read Model (`read_grip_result`, `read_multimodal`) 이 `occurred_date` 기반의 일일 누적 필드 (`attempt_count`, `success_count`, `success_rate`) 를 보유하지 않아, row-level 데이터만으로는 시간 순으로 그룹화된 추이를 조회할 수 없기 때문입니다. 따라서 `read_daily_grip_success_rate_v1`이라는 새로운 집계 전용 Read Model 테이블을 생성하고, `GripAttemptRecorded` 이벤트를 투영하여 일일 단위의 성공률과 시도 수를 계산하는 로직을 구현해야 합니다.
