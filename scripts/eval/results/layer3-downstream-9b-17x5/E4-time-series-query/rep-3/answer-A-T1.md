사용자가 '일자별 파지 성공률 추이' (날짜별 시도 수, 성공 수, 성공률) 를 시간 순으로 조회하는 요청을 보냈으나, 시스템은 `insight.card.miss` 로 매칭 실패를 반환하고 있습니다. 이는 기존 Read Model(`read_grip_result`) 이 원천 시도 기록 (1 건 단위) 만 저장하고 있어, `occurred_at` 기준으로 `GROUP BY` 를 통한 집계 조회를 직접 수행할 수 없기 때문입니다. 로그 분석 결과, `insight.card.miss` 레벨 40 에서 3 회 반복된 실패가 기록되었으며, 이는 `read_grip_result` 의 키 구조가 `(scene_key, attempt_num)` 이므로 날짜 단위 집계가 불가능함을 증명합니다. 따라서 사용자 요청을 충족시키기 위해 `read_grip_daily_success_rate` 라는 새로운 Read Model 생성이 필요하며, 기존 v1 자산은 무손상 유지해야 합니다.
