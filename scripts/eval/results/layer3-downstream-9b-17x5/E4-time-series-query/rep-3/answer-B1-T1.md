사용자가 '일자별 파지 성공률 추이'를 포함한 집계 조회를 요청했으나, 기존 Read Model 은 장면별 시도별 상세 결과만 저장하고 있어 시간별 집계 쿼리가 불가능합니다. 로그에서 `insight.card.miss`로 기록된 상세 조회 실패 원인은, 사용자가 요청한 '일자별 파지 성공률 추이'라는 집계형 키워드가 `read_grip_result` 테이블의 `object_name` 필드와 같은 단건 조회용 키로 오해되어 발생했습니다. 따라서 현재 Read Model 은 `occurred_at` 필드를 기준으로 날짜별 시도 수와 성공 수를 그룹화하는 집계 연산이 지원되지 않습니다.
