사용자가 `POST /grip-result-with-media` 엔드포인트를 호출하여 파지 결과와 해당 시도의 이미지·영상 경로를 한 화면에서 함께 보고자 요청했으나, 시스템은 `insight.card.miss` 로그를 발생시켜 해당 기능을 지원하지 않는 것으로 진단됩니다. 이는 `read_grip_result`와 `read_multimodal`로 분리된 두 개의 Read Model 테이블이 존재하며, `GripResultProjector`와 `MultiModalProjector`가 서로 다른 테이블로 데이터를 독립적으로 투영(upsert)하고 있어 통합된 뷰가 결여되었기 때문입니다. 결과적으로 `insight.card.request`가 들어와도 `insight.card.miss`가 반환되며, `payload` 내의 `2D_image_file_name`과 `video_file_name` 필드가 기존 Read Model 에 포함되지 않아 동시 조회가 불가능한 상태입니다.
