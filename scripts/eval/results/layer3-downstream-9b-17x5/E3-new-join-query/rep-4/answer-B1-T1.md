사용자가 파지 결과와 해당 시도의 이미지·영상 경로를 한 화면에 함께 보고는 싶으나, `insight.card.request` 로그에 `insight.card.miss`가 발생하여 요청이 실패했습니다. 이는 `read_grip_result`와 `read_multimodal`이라는 두 개의 별도 Read Model 테이블이 존재하여, 두 테이블의 데이터를 JOIN 하지 않고는 단일 조회로 동시 제공이 불가능하기 때문입니다. `read_grip_result`는 파지 성공 여부 및 포즈 정보를, `read_multimodal`은 이미지/영상 URI 정보를 저장하고 있으나, 현재 스키마에는 두 모델 간의 직접적인 연결 필드가 명시되어 있지 않습니다. 따라서 사용자가 원하던 '한 화면에 통합 조회' 기능은 현재 아키텍처로는 구현되지 않았으며, 별도의 JOIN 쿼리나 통합 뷰 생성이 선행되어야 합니다.
