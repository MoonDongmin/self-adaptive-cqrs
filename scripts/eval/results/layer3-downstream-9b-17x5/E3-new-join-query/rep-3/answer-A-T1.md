사용자가 `POST /grip-with-media` 엔드포인트를 통해 파지 결과와 해당 시도의 이미지·영상 경로를 한 화면에서 동시에 조회하려 요청했으나, 기존 아키텍처에서는 이를 충족할 수 없는 문제가 발생했습니다. 그 원인은 `read_grip_result`와 `read_multimodal`이라는 두 개의 별도 Read Model 테이블에 데이터가 분산되어 저장되어 있어, 단일 Insight 카드 조회로 결합된 뷰를 제공하지 못하기 때문입니다. 로그 분석 결과, `insight.card.request`가 3 회 반복되었음에도 불구하고 `insight.card.miss`가 발생하며, 이는 `read_grip_with_media` 테이블이 존재하지 않아 결합된 데이터 조회가 불가능했음을 보여줍니다. 구체적으로 `insight.card.miss` 로그의 `detail` 필드에 "파지 결과와 해당 시도의 이미지·영상 경로를 한 화면에서 함께 보고 싶다"는 메시지가 포함되어 있어, 사용자가 결합된 뷰를 원한다는 의도가 명확히 드러납니다.
