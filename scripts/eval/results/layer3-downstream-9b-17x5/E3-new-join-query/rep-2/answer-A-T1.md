사용자가 `POST /insight-card` 엔드포인트를 호출하여 파지 결과와 해당 시도의 이미지·영상 경로를 한 화면에서 함께 보고자 요청했으나, 시스템은 `insight.card.miss` 로 응답하고 있다. 이는 자료에 명시된 `insight_read_db` 에서 `read_insight_card_v1` 테이블이 존재하지 않고, 기존 `read_grip_result` 와 `read_multimodal` 테이블만 분리되어 저장되어 있어 통합 뷰를 제공할 수 없기 때문이다. 로그 기록에 따르면 `insight.card.request` 가 3 회 발생했으나 모두 `insight.card.miss` 로 처리되었으며, 이는 `read_insight_card_v1` Read Model 이 부재하여 통합된 데이터를 조회할 수 없음을 의미한다.
