현재 운영 중인 센서 관찰기가 `read_grip_result` 테이블에 물리적 제약 (깊이 z1 ≤ 0) 과 이미지 경계 (xl > 1920px) 를 위배하는 2 개의 이상 데이터 (seq:26, seq:27) 를 투영하여 저장했습니다. 이는 `GripResultProjector` 의 매핑 로직이 원본 이벤트의 raw JSONB 포즈 값을 검증 없이 직접 DB 에 적재했기 때문이며, 구체적으로 `grip3dPose.z1` 값이 -0.05 m 로 음수이고 `grip2dPose.xl` 값이 2500 px 로 이미지 너비 한도를 초과했습니다. 이러한 구조적 검증 부재로 인해 DB 에는 물리적으로 불가능한 데이터가 포함되었으나, 이벤트 소스 (event_store) 에는 원본 payload 가 그대로 보존되어 있습니다. 따라서 즉시 `read_grip_result` 테이블에서 해당 키 (scene_key, attempt_num) 를 가진 행을 삭제하여 격리하고, 향후에는 `GripOutlierProjector` 를 추가하여 물리적 무결성 규칙을 강제해야 합니다.
