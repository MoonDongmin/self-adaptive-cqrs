사용자가 '파지 실패가 가장 많은 객체 상위 목록'을 조회했으나, 기존 Read Model 은 파지 성공 여부만 저장하고 있어 객체별 실패 수와 실패율을 계산할 수 없는 문제가 발생했습니다. 이는 `read_grip_result` 테이블에 `object_name` 과 `grip_succeed` 필드가 존재하지만, `object_name` 을 기준으로 집계하는 `object_failure_count` 나 `object_failure_rate` 필드가 정의되어 있지 않기 때문입니다. 또한, 로그 분석 결과 `insight.card.miss` 레벨 40 로그가 '파지 실패가 가장 많은 객체 상위 목록'이라는 사용자 요청을 포함하고 있으나, 해당 요청은 Insight 서비스 내부에서 처리된 것으로 보아 백엔드 Read Model 에 반영되지 않은 상태임을 알 수 있습니다. 따라서 사용자의 요청을 충족시키기 위해서는 `object_name` 에 따라 `grip_succeed=0`인 행을 필터링하고 그룹화하여 카운트하는 새로운 집계 로직이 필요하며, 이를 위해 기존 Read Model 에 해당 필드를 추가하거나 별도 집계 테이블을 생성해야 합니다.
