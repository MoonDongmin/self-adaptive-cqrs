## 1. 권고 (Recommendation)

> 데이터 품질 판정: critical 이상 감지 — 물리적 깊이 음수 및 화면 밖 2D 좌표가 Read Model에 무검증 투영됨.

### 심각도 — critical

오염 열(grip2dPose/grip3dPose)이 하류 컨트롤러 및 API 응답에 직접 노출되며, 2개 행(globalSequence 26~27)이 영장성으로 오염된 값이 삽입됨. event_store 원천 기록은 보존되어 재투영(fix)으로 복원 가능하나, 현재 Read Model 스키마에는 정합성 검증 로직 부재로 즉시 격리/수정 조치가 필함.

### 기대-실측 델타 근거

- (반려동물용품_CR01_강아지공룡알장난감_02006#1, `grip3dPose` / grip3dPose) 관측 `"z1":-0.05` vs 기준 `grip3dPoseZ_depth` [0.01, 0.30] m → 델타 -0.06 m (미만 하한) · 카메라 프레임 기준 깊이(z)가 0 이하로 물리적 불가능한 음수 값 기록됨.
- (반려동물용품_CR01_강아지공룡알장난감_02007#1, `grip2dPose` / grip2dPose) 관측 `"xl":2500` vs 기준 `grip2dPose_withinImage` x in [0, 1920], y in [0, 1110] → 델타 +580 px (초과 상한) · 2D 좌표 xl이 이미지 너비(1920px)를 넘어선 화면 밖 픽셀 값 기록됨.

### 관찰

- Record 02006#1 grip3dPose z1 = -0.05 m violates physical depth constraint (≤ 0).
- Record 02007#1 grip2dPose xl = 2500 px exceeds image width bound (> 1920).

### 영향 범위

- event_store → grip-result-projector → read_grip_result(grip_2d_pose/grip_3d_pose jsonb)
- read_grip_result → catch-up.runner.ts
- catch-up.runner.ts → projection.controller.ts(/grip-result) → API response

### 근본원인 — projectionOrPipelineFault

1. 왜 음수 깊이와 화면 밖 좌표가 발생? 센서 원천 payload를 물리적 범위 검증 없이 그대로 jsonb 열에 매핑됨.
2. 왜 검증이 생략? Read Model 스키마(jsonb)가 구조만 허용하고 의미적 값 반례를 차단하지.
3. 왜 구조만 허용? DTO Zod 검증은 타입/길이 검사만 수행, semantic range check 미구현.
4. why semantic check 미구현? 베이스라인 규칙 존재하지만 projection 삽지 시 point에서 강제 적용이 누락됨.
5. why 누락? Projector map()과 upsert() 메서드에 checkIntegrity 구현이 결결되어 Zod parse만 의존.

### 의사결정 기준

- 원천 데이터(event_store) 보존 vs 즉시 격리
- Read Model 스키마 수정(신뢰성) vs 기존 테이블 유지(호환성)
- 재투영(fix) vs 플래그/격리(contain)
- 검증 로직 삽입(harden) vs 별도 이상 테이블 설계

### 해결책 옵션 (contain → fix → harden)

#### [contain] 오염 행 격리(DELETE — 원본은 event_store 에 보존, 재투영으로 복원)
- 접근: event_store 원천 기록은 영장성 보존하며, 즉시 read_grip_result 테이블에서 오염된 (scene_key, attempt_num) 키를 DELETE로 제거. 하류 API 응답의 영장성 오류 차단.
- 트레이드오프: 기존 Read Model 스키마 유지로 호환성 보장 대신, 재투영(fix) 로직 추가 지연.
```sql

-- 원본 이벤트는 event_store 에 보존되므로 v2 재투영(무결성 플래그 포함)으로 복원 가능하다.

```

#### [fix] 타깃 패치/재투영 (검증 로직 삽지)
- 접근: GripResultProjector.checkIntegrity 메서드 구현 추가. Zod parse 통과 시 jsonb 필드 접근으로 depth≥0.01 및 xl≤1920 검증, 실패 시 IntegrityViolation 반환 → CatchUpRunner에서 격리/수정.
- 트레이드오프: 프로젝터 로직 확확으로 유지성 확보 대신, 기존 upsert 흐름 변경과 테스트 커버리지 증감.
```typescript
checkIntegrity(row: ReadGripResultInsert): IntegrityViolation[] {
  const violations: IntegrityViolation[] = [];
  const z1Raw = (row.grip3dPose as Record<string, unknown>)['z1'] as number | undefined;
  const xlRaw = (row.grip2dPose as Record<string, unknown>)['xl'] as number | undefined;

  if (z1Raw !== undefined && z1Raw < 0.01) {
    violations.push({
      readModelName: 'read_grip_result', sceneKey: row.sceneKey, attemptNum: row.attemptNum,
      streamId: row.streamId, globalSeq: row.globalSeq, ruleName: 'grip3dPoseZ_depth',
      affectedColumns: ['grip_3d_pose'], observedValue: String(z1Raw), expected: '[0.01, 0.30] m',
      detail: `depth 음수/미만 위반: z1=${z1Raw}m`
    });
  }
  if (xlRaw !== undefined && xlRaw > 1920) {
    violations.push({
      readModelName: 'read_grip_result', sceneKey: row.sceneKey, attemptNum: row.attemptNum,
      streamId: row.streamId, globalSeq: row.globalSeq, ruleName: 'grip2dPose_withinImage',
      affectedColumns: ['grip_2d_pose'], observedValue: String(xlRaw), expected: 'x in [0, 1920]',
      detail: `xl 화면 밖 초과: xl=${xlRaw}px`
    });
  }
  return violations;
}
```

#### [harden] 베이스라인 규칙 추가 (DDL CHECK)
- 접근: read_grip_result 테이블에 jsonb 필드 접근 CHECK CONSTRAINT 추가. Postgres native syntax로 z1≥0.01 및 xl≤1920 강제 적용.
- 트레이드오프: DB 레벨 신뢰성 확보 대신, jsonb CHECK 연성 오버헤드 및 마이그레이션 비용 발생.

### 권장
- contain(오염 행 격리) + harden(베이스라인 규칙 추가) + v2 설계 채택
- 사유: event_store 원천 보존을 전제로 오염된 jsonb 열의 즉시 삭제를 수행하며, 하류 API 응답의 영장성 오류를 차단. harden DDL CHECK는 하류 삽지 시 물리적 반례 자동 거절. 확정 설계(read_grip_outlier_v2) 채택으로 별도 이상 플래그 테이블을 구축하여 원치 측정값과 위반 플래그 이력 관리.
- 수용하는 트레이드오프: 기존 Read Model 스키마 유지로 호환성 보장 대신, fix(재투영) 로직 추가 지연 및 v2 테이블 운영 오버헤드.
- 기각한 대안:
  - fix(재투영): 검증 로직 미구현 시 무의미, decisionCriteria 4에서 harden 우선.
  - DDL 수정: §2/§3 설계 확정(read_grip_outlier_v2)과 충돌, decisionCriteria 2에서 기존 테이블 유지.

| GripAttemptRecorded | sceneKey | scene_key | verbatim |
| GripAttemptRecorded | attemptNumber | attempt_num | verbatim |

| GripAttemptRecorded | occurredAt | occurred_at | verbatim |

- `depth_negative_flag` ← (z1_raw <= 0) ? 1 : 0
- `pixel_xl_out_of_bounds_flag` ← (xl_raw > 1920) ? 1 : 0

3. `CatchUpRunner` 필터링(`null` return) 시 processed count 일치 검증

- Insight 카드 등록: §2의 카드 등록 SQL을 DDL과 함께 적용(카탈로그 동기화)

### 사유·호환성

- 사유: 기존 v1 Read Model(`read_grip_result`)는 Zod 구조 검증만 통과하고, 의미적 물리적 제약(깊이 ≤ 0, 2D 픽셀 경계 초과)을 허용해 이상 데이터가 영유 DB에 적재됨[corr:26][corr:27]. 신규 `read_grip_outlier_v2` 테이블과 `GripOutlierV2Projector`를 추가하여 z1_raw ≤ 0 또는 xl_raw > 1920 위반 플래그를 전수 검지하고 이상 로그만 영유 DB에 적재, 기존 v1 파이프라인은 무손상 유지[corr:26][corr:27].
- 트리거 근거: [Seq 26] {"sceneKey":"반려동물용품_CR01_강아지공룡알장난감_02006","attemptNumber":1,"globalSequence":26,..."grip3dPose":{"z1":-0.05,...}} ⚠ physical [..._02006#1] grip3dPoseZ(z1)=-0.05 (깊이 ≤ 0 — 카메라 뒤/평면 위 물체는 불가능)
[Seq 27] {"sceneKey":"반려동물용품_CR01_강아지공룡알장난감_02007","attemptNumber":1,"globalSequence":27,..."grip2dPose":{"xl":2500,...}} ⚠ physical [..._02007#1] grip2dPose(xl)=2500 (이미지 경계 [0, 1920]px 밖 — 화면 밖 픽셀 좌표는 불가능)
- v1 호환성: 기존 `read_grip_result` 테이블·프로젝터·라우트·서비스 DI 는 일체 건드리지 않고 보존. 신규 `GripOutlierV2Projector` 만 추가 DI 배선, `/grip-outlier-v2` 라우트 추가, `schema/index.ts` export 확만 추가[corr:26][corr:27].

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripOutlierV2 } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type GripOutlierV2ProjectorInsert = InferInsertModel<typeof readGripOutlierV2>;

function toNumberOrNull(value: unknown): number | null {
  if (value === undefined || value === null) {
    return null;
  }
  const parsed = Number(value);
  return Number.isNaN(parsed) ? null : parsed;
}

function toStringOrNull(value: unknown): string | null {
  return value === undefined || value === null ? null : String(value);
}

function toDateOrNull(value: unknown): Date | null {
  if (typeof value !== "string" && typeof value !== "number") {
    return null;
  }
  const parsed = new Date(value);
  return Number.isNaN(parsed.getTime()) ? null : parsed;
}

@Injectable()
export class GripOutlierV2Projector implements Projector<GripOutlierV2ProjectorInsert> {
  readonly name: string = "grip-outlier-v2-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripOutlierV2Projector.name);
  }

  map(event: EventStoreEventRow): GripOutlierV2ProjectorInsert {
    // 결정론 합성 프로젝터 — payload 경로가 자명하지 않은 컬럼은 §2 투영 매핑 명세와 대조해 보정하라.
    const payload = event.payload as Record<string, unknown>;

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      objectName: toStringOrNull(payload["object_name"]),
      gripSucceed: toNumberOrNull(payload["grip_succeed"]),
      occurredAt: event.occurredAt,
      z1Raw: toNumberOrNull(payload["z1_raw"]),
      xlRaw: toNumberOrNull(payload["xl_raw"]),
      depthNegativeFlag: toNumberOrNull(payload["depth_negative_flag"]),
      pixelXlOutOfBoundsFlag: toNumberOrNull(payload["pixel_xl_out_of_bounds_flag"]),
    };
  }

  async upsert(tx: DrizzleTx, row: GripOutlierV2ProjectorInsert): Promise<void> {
    await tx
      .insert(readGripOutlierV2)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripOutlierV2.sceneKey, readGripOutlierV2.attemptNum],
        set: {
          objectName: row.objectName,
          gripSucceed: row.gripSucceed,
          occurredAt: row.occurredAt,
          z1Raw: row.z1Raw,
          xlRaw: row.xlRaw,
          depthNegativeFlag: row.depthNegativeFlag,
          pixelXlOutOfBoundsFlag: row.pixelXlOutOfBoundsFlag,
        },
      });
  }
}
```

### 버전 교체 코드 — `src/projection/projection.service.ts` (modifyFile)

```typescript
import { Injectable } from '@nestjs/common';
import { PinoLogger } from 'nestjs-pino';
import { InsertResult, InsertService } from '@/insert/insert.service';
import { GripResultProjector } from '@/projection/projector/grip-result.projector';
import { MultiModalProjector } from '@/projection/projector/multimodal.projector';
import { GripOutlierV2Projector } from '@/projection/projector/grip-outlier-v2.projector';
import { ProjectionResult } from '@/projection/projector/projector';
import { CatchUpRunner } from '@/projection/runner/catch-up.runner';
import { LogAction } from '@/shared/logger/logging-context';

export type CatchUpAllResult = {
  multimodal: ProjectionResult;
  gripResult: ProjectionResult;
  outlierV2: ProjectionResult;
};

export type InsertAndProjectionAllResult = {
  insert: InsertResult;
  projection: CatchUpAllResult;
};

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly outlierV2: GripOutlierV2Projector,
    private readonly insertService: InsertService,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  catchUpMultimodal(): Promise<ProjectionResult> {
    return this.runner.run(this.multimodal);
  }

  catchUpGripResult(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResult);
  }

  catchUpOutlierV2(): Promise<ProjectionResult> {
    return this.runner.run(this.outlierV2);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();
    const outlierV2: ProjectionResult = await this.catchUpOutlierV2();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult, outlierV2 };
  }

  async insertAllAndProjectAll(): Promise<InsertAndProjectionAllResult> {
    this.logger.info(
      { action: LogAction.PROJECTION_START },
      "전체 적재+투영 시작",
    );

    const insert: InsertResult = await this.insertService.insertToyData();
    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
}
```
