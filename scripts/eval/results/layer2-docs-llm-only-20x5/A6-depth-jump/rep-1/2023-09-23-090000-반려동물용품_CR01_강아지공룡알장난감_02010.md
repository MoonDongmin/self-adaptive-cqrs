| GripAttemptRecorded | attemptNumber | attempt_num | verbatim |

| GripAttemptRecorded | occurredAt | occurred_at | verbatim |

### 사유·호환성

- 사유: 기존 Read Model read_grip_result의 grip_3d_pose 컬럼이 jsonb 타입만 할당하여 Zod 구조적 검증은 통과하나 실제 Z좌표 값(심호/급변)에 대한 물리적 정합성 판정이 누락 [corr:1]. 이로 인해 scene 내 연속 시도 간 Z평균 Δ=0.110m > 0.10m 임계 위배가 미감지되어 downstream 이상 탐지 파이프라인이 정상 데이터로 유입됨. 신규 read_grip_z_avg_v2 Read Model은 payload.grip_data.grip_3d_pose.z1..z8를 직접 평균화하여 z_avg_m 컬럼에 영적 저장, enabling physical consistency validation without raw JSON parsing or fragile value extraction.
- 트리거 근거: [윈도우 1] R6 suddenJump_withinScene: 같은 scene 연속 attempt 간 z평균 0.060 → 0.170, Δ=0.110 > 0.10 m / [2차 지목] R6 suddenJump_withinScene: 같은 scene 연속 attempt 간 z평균 0.069 → 0.179, Δ=0.110 > 0.10 m
v1 코드의 read_grip_result 스키마(grip_3d_pose: jsonb) 및 GripResultProjector.map() 메서드(payload.grip_data.grip_3d_pose 할당만)는 값 이상 판정을 누락하여 위 급상승을 미감지.
- v1 호환성: 기존 read_grip_result 테이블·엔드포인트·프로젝터 클래스/name은 무손단. 신규 Read Model은 동시 저장/독 조회 패턴으로 v1 데이터와 독립 운영, backward compatible.

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import type { InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripZAvgV2 } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripZAvgV2Insert = InferInsertModel<typeof readGripZAvgV2>;

@Injectable()
export class GripZAvgProjector implements Projector<ReadGripZAvgV2Insert> {
  readonly name: string = "grip-z-avg-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripZAvgProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripZAvgV2Insert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    const pose = payload.grip_data.grip_3d_pose;
    const zSum: number = pose.z1 + pose.z2 + pose.z3 + pose.z4 + pose.z5 + pose.z6 + pose.z7 + pose.z8;
    const zAvg: number = zSum / 8.0;

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      objectName: payload.objects[0].class_name,
      zAvgM: zAvg,
      occurredAt: event.occurredAt,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripZAvgV2Insert): Promise<void> {
    await tx
      .insert(readGripZAvgV2)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripZAvgV2.sceneKey, readGripZAvgV2.attemptNum],
        set: {
          objectName: row.objectName,
          zAvgM: row.zAvgM,
          occurredAt: row.occurredAt,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```
