### Decision Drivers
- 배치 트랜잭션 안전성 보장 (roll-back 차단)
- 결함 데이터 격리·무해화 정책 유지 (원천 수정 요청)
- Read Model 스키마·엔드포인트 불변 요구

### Considered Options
#### SkipEventHandling
- 접근: GripResultProjector.map() 수정으로 특정 에러 클래스 정의, CatchUpRunner 가 해당 에러를 catch 시 skip 처리.
- 제안 필드: SkipProjectionError, runner loop adjustment
- 트레이드오프: Zero schema change, preserves batch integrity, requires minor CatchUpRunner scope but zero external impact.
```typescript
export class SkipProjectionError extends Error { constructor(eventId: string) { super(`skip:${eventId}`); this.name = "SkipProjectionError"; } }
// in map(): if (payload.objects.length === 0) { this.logger.warn({ action: LogAction.MAP_FAILED, [LogContext.EVENT_ID]: event.eventId }, "objects 비어 있음 → skip"); throw new SkipProjectionError(event.eventId); }
```

#### DeadLetterLogging
- 접근: GripResultProjector.map() 수정으로 로그 기록 및 null 반환, CatchUpRunner 가 null 필터링.
- 제안 필드: null return path, runner filter logic
- 트레이드오프: Explicit isolation log, zero transaction impact, but runner modification scope wider and type safety 하강.
```typescript
// in map(): if (payload.objects.length === 0) { this.logger.warn({ action: LogAction.MAP_FAILED, [LogContext.EVENT_ID]: event.eventId }, "objects 비어 있음 → dead-letter"); return null as unknown as ReadGripResultInsert; }
```

### Decision Outcome

### Consequences
- (+) 정상 이벤트(global_seq 1~25) 유실 방지
- (+) 결함 이벤트 식별 로그 남김
- (+) 스키마·엔드포인트 무변
