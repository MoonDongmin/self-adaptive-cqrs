### Decision Drivers
- Batch Rollback Mitigation (db.error 차단 및 정상 이벤트 투영 보장)
- Defect Value Preservation (검거된 값의 무해화/치환 금지, 격리+원천 수정 요청 원칙 준수)
- Operational Overhead (기존 스키마·엔드포인트 유지, 최소 코드 변경)

### Considered Options
#### projectorSkipEmptyObjects
- 접근: GripResultProjector.map() 의 빈 objects 체크 로직 변경. throw 대신 null 반환, 격리 로그 방출. Runner 에서 null 필터링 적용.
