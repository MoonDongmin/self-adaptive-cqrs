- `read_grip_result` 스키마의 Primary Key `(scene_key, attempt_num)`은 행 단위(row-level) 구조로, `total_attempts`, `failure_count`, `success_count` 집계 필드가 부재하여 GROUP BY 산출값 및 정렬 요구를 충족할 수 없음. [corr:bf385709-2ed3-4bf0-8208-4b86b3778535]
- `GripResultProjector.map()` 구현(`src/projection/projector/grip-result.projector.ts`)은 1:1 이벤트→행 매핑만 수행, 집계 로직이 존재하지 않아 object별 실패 수/실패율 추출이 불가능. [corr:cc1bc1f8-4478-4a16-a7ef-e1b0118d8653]
- 요청 의도('순위대로')는 row-level 테이블만으로는 query-layer aggregation overhead를 발생하며, 영구 상태 유지와 O(1) 조회가 요구하는 신규 집계 테이블 구조가 필연함. [corr:b06ec7f3-c996-492d-bda8-194bdb17923a]

### Decision Drivers
- Aggregation requirement (object-level stats vs row-level)
- Sorting requirement (rank by failure count/rate)
- Existing schema limitations (no GROUP BY support in current Read Models)
- Defect value handling principle (isolation over coercion)

### Considered Options
#### 신규 집계 테이블 생성 (read_object_failure_report)
- 접근: newReadModel
- 제안 필드: object_name, total_attempts, failure_count, success_count
- 트레이드오프: initial projection build overhead 발생, storage overhead 증가. 하지만 query-layer aggregation overhead 제거 및 native sorting 지원 보장.
```typescript
return { objectName: payload.objects[0].class_name, totalAttempts: 1, failureCount: payload.grip_succeed === 0 ? 1 : 0, successCount: payload.grip_succeed === 1 ? 1 : 0 };
```

#### 기존 Read Model 기반 뷰/쿼리 레이어 집계
- 접근: existingReinforcement
- 제안 필드: -
- 트레이드오프: dataset 규모 증가 시 query performance degradation 발생. driver '정렬 요구'에서 졌음.
```typescript
SELECT object_name, COUNT(*) as total_attempts FROM read_grip_result GROUP BY object_name ORDER BY SUM(CASE WHEN grip_succeed = 0 THEN 1 ELSE 0 END) DESC;
```

### Decision Outcome
신규 집계 테이블 생성 (read_object_failure_report) | 요청의 '순위대로' 및 '실패 수/실패율' 요구사항은 row-level 구조만으로는 충족할 수 없으며, 신규 집계 테이블이 영구 상태 유지와 O(1) 조회를 보장.

### Consequences
- (+) object별 실패 통계 조회 latency 감소 (O(1) vs O(N))
- (+) native sorting 지원으로 ranking query 단순화
- (+) defect value 격리 원칙 준수 (거절·격리 유지 + 원천 데이터 수정 요청)
- (−) initial projection build overhead 발생
- (−) storage footprint 증가 (aggregation table 추가)
- (−) catch-up runner pipeline extension 필요

### Non-Goals
- row-level `read_grip_result`/`read_multimodal` 스키마 변경 금지
- z.coerce·기본값 치환으로 결함 값 무해화 금지
- query-layer aggregation reliance 금지

- 트리거 근거: | 03:15:01.373 | 40 | insight.card.miss | bf385709-2ed3-4bf0-8208-4b86b3778535 | - | - | - | insight 카드 없음: 파지 실패가 가장 많은 객체 상위 목록을 조회하고 싶다. 객체별 실패 수와 실패율을 순위대로 보고 싶다. ← 트립 앵커 [corr:bf385709-2ed3-4bf0-8208-4b86b3778535]
- v1 호환성: v1 `GripResultProjector`는 1:1 매핑(`payload.objects[0].class_name`)에 치우쳐 집계 보고서를 제공하지. 신규 v2 테이블·프로젝터는 독립 DI 배선으로 v1 무손상 원칙을 따르며, 컷오버 전 기존 insight 카드 미스 로그를 v2 조회로 대체할 수 있다.

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readObjectFailureReport } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

// Drizzle sql 태그는 'drizzle-orm' 에서 import 하라 — 'drizzle-orm/pg-core' 에는 sql 이 없다.
import { sql } from 'drizzle-orm';

type ReadObjectFailureReportInsert = InferInsertModel<typeof readObjectFailureReport>;

@Injectable()
export class ObjectFailureReportProjector implements Projector<ReadObjectFailureReportInsert> {
  readonly name: string = "object-failure-report-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(ObjectFailureReportProjector.name);
  }

  map(event: EventStoreEventRow): ReadObjectFailureReportInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    if (payload.objects.length === 0) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
        },
        "objects 비어 있음",
      );

      throw new Error(
        `object-failure-report map: empty objects in event ${event.eventId}`,
      );
    }

    const objectName = payload.objects[0].class_name;
    const isFailure = payload.grip_succeed === 0;

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      objectName,
      totalAttempts: 1,
      failureCount: isFailure ? 1 : 0,
      successCount: isFailure ? 0 : 1,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadObjectFailureReportInsert): Promise<void> {
    await tx
      .insert(readObjectFailureReport)
      .values(row)
      .onConflictDoUpdate({
        target: [readObjectFailureReport.objectName],
        set: {
          totalAttempts: sql`${readObjectFailureReport.totalAttempts} + excluded.totalAttempts`,
          failureCount: sql`${readObjectFailureReport.failureCount} + excluded.failureCount`,
          successCount: sql`${readObjectFailureReport.successCount} + excluded.successCount`,
        },
      });
  }
}
```
