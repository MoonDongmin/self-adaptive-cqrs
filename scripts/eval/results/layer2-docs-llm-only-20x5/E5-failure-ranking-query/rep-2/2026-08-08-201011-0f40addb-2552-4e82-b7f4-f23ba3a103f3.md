- GripResultProjector.map() 및 upsert() 구현(src/projection/projector/grip-result.projector.ts)은 onConflictDoUpdate로 단일 시도 행을 overwrite/update만 수행, 객별 누적 갱신 로직이 미구현
- 요청 의도('순위별 실패 수/실패율')는 GROUP BY object_name과 산출 연산이 필연히 필요하나 현존 Read Model 테이블 구조로는 직접 충족 불가능

### Decision Drivers
- Query intent requires object-level aggregation and failure rate calculation
- Existing schema lacks aggregate columns forcing application-layer computation or model redesign
- Row-level projector's onConflictDoUpdate pattern cannot natively accumulate across multiple attempts per object without complex state management
- API versioning compatibility vs new endpoint overhead for analytics decoupling

### Considered Options
#### 기전 보강
- 접근: GripResultProjector.upsert 수정하여 object_name 기준 누적 갱신 로직 추가.
- 제안 필드: total_attempts, success_count, failure_count
- 트레이드오프: 스키마 확장에 따른 upsert 복잡성 증가, 동경시도 overwrite 시 집계 일관성 유지 필요, 기존 엔드포인트 호환 가능.
```typescript
await tx.insert(readGripResult).values(row).onConflictDoUpdate({ target: [readGripResult.sceneKey, readGripResult.attemptNum], set: { ...row, totalAttempts: row.totalAttempts + 1, successCount: row.gripSucceed === 1 ? row.successCount + 1 : row.successCount } });
```

#### 신규 분리(newReadModel)
- 접근: read_object_failure_stats 테이블 신규 투영(Projector) 구현, 기존 GripResultProjector는 row-level 유지, 집계 전용 프로젝터 별도 운영.
- 제안 필드: object_name, total_attempts, success_count, failure_count
- 트레이드오프: API 버전 변경 및 새 엔드포인트 필요, 초기 catch-up 마이그레이션 비용 발생, 관심 분리(CoC) 준수, rank query 성능 우위.
```typescript
// read_object_failure_stats.projector.ts map(event): { objectName: payload.objects[0].class_name, totalAttempts: 1, successCount: payload.grip_succeed, failureCount: 1 - payload.grip_succeed }; upsert(tx, row): await tx.insert(readObjectFailureStats).values(row).onConflictDoUpdate({ target: [readObjectFailureStats.objectName], set: { totalAttempts: readObjectFailureStats.totalAttempts + row.totalAttempts, successCount: readObjectFailureStats.successCount + row.successCount } });
```

#### 버전 교체(versionSwitch)
- 접근: 기존 엔드포인트 /projection/grip-result 확장으로 rank query 지원.
- 제안 필드: total_attempts, success_count, failure_count
- 트레이드오프: API 호환성 유지 but application-layer aggregation overhead 발생, Read Model 원칙 위배 가능성.
```typescript

```

### Decision Outcome
신규 분리(newReadModel) - 사유: 관심 분리 준수, 기존 onConflictDoUpdate overwrite 패턴과의 집계 충돌 해결, rank query 성능 우위, 확정 설계 매칭.

### Consequences
- (+) rank query 수행 시 O(1) 조회 가능
- (+) 기존 row-level projector 로직 무수한 수정 방지
- (+) 집게/실패율 산출 로직 격리
- (−) API 버전 변경(versionSwitch) 동반 필요
- (−) 초기 catch-up 재투영 비용 발생
- (−) 신규 엔드포인트 추가 작업

### Non-Goals
- zod 검증 실패 값 정상화(coerce/defaults)
- 2D/video URI 매핑 구현
- event payload schema 수정

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readObjectFailureStats } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';
import { sql } from 'drizzle-orm';

type ReadObjectFailureStatsInsert = InferInsertModel<typeof readObjectFailureStats>;

@Injectable()
export class ObjectFailureStatsProjector implements Projector<ReadObjectFailureStatsInsert> {
  readonly name: string = "object-failure-stats-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(ObjectFailureStatsProjector.name);
  }

  map(event: EventStoreEventRow): ReadObjectFailureStatsInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    if (payload.objects.length === 0) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
        },
        "objects 비어 있음",
      );

      throw new Error(`object-failure-stats map: empty objects in event ${event.eventId}`);
    }

    const objectName = payload.objects[0].class_name;
    const gripSucceed = payload.grip_succeed;

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.OBJECT_NAME]: objectName,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      objectName,
      totalAttempts: 1,
      successCount: gripSucceed,
      failureCount: 1 - gripSucceed,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadObjectFailureStatsInsert): Promise<void> {
    await tx
      .insert(readObjectFailureStats)
      .values(row)
      .onConflictDoUpdate({
        target: [readObjectFailureStats.objectName],
        set: {
          totalAttempts: sql`${readObjectFailureStats.totalAttempts} + ${row.totalAttempts}`,
          successCount: sql`${readObjectFailureStats.successCount} + ${row.successCount}`,
          failureCount: sql`${readObjectFailureStats.failureCount} + ${row.failureCount}`,
        },
      });
  }
}
```
