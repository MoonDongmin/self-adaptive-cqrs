## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 40, `payload.schema.drift`) payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) ← 트립 앵커 → Zod/스키마 검증 실패로 conveyor_speed, gripper_temperature 신규 키가 event_store append 시 누락됨, 기존 Read Model 스키마에 이 컬럼 부재. [corr:6433d45e-3a14-407c-abff-9517954daff8]
- src/insert/dto/toy-data.dto.ts 의 toyDataSchema 는 conveyor_speed, gripper_temperature 필드를 미정의. Zod .parse() 호출 시 unknown key 거절로 이벤트 매핑 실패, ES append 차단.
- read_grip_result 의 object_name, grip_succeed 등 기존 컬럼과 read_multimodal 의 image_2d_uri, video_uri 에 센서 드리프트 필드 부재.
- GripResultProjector.map() 과 MultiModalProjector.map() 의 toyDataSchema.parse(event.payload) 의존성으로, Zod 실패 시 downstream projection 이 sensor context 를 누락.

### Decision Drivers
- ES 데이터 무해화 원칙 (Zod strictness 유지 + 미등록 키 거절)
- Read Model 스키마 고립성 (신규 센서 드리프트 격리)
- API 버전 관리 및 호환성 (기각 대안 vs 신규 모델)
- 투영 파이프라인 정지/확장 비용

### Considered Options
#### 기존 read_grip_result 컬럼 추가 (확장)
- 접근: src/shared/database/schema/service/read-grip-result.ts 에 conveyorSpeed, gripperTemperature varchar/numeric 추가, GripResultProjector.map() 에 payload 추출 로직 반영.
- 제안 필드: read_grip_result.conveyor_speed, read_grip_result.gripper_temperature
- 트레이드오프: API 버전 변경 필수, 기존 Read Model 스키마 확으로 인한 호환성 리스크, ES 데이터 순도 저하(unknown key 허용 시).

신규 read_grip_sensor_context 테이블 생성 (고정) — Zod strictness 유지로 ES 데이터 순도 보장, 기존 Read Model 무변파 및 API 호환성 확보.

## 2. Read Model 생성 SQL (Read Model DDL)

> 실행 게이트: 아래 변경은 인간 승인 후에만 적용한다 (human-in-the-loop).

- 대상: `read_grip_sensor_context` · 키: scene_key, attempt_num · 원천 이벤트: GripAttemptRecorded

```sql
CREATE TABLE read_grip_sensor_context (
    scene_key VARCHAR NOT NULL,
    attempt_num SMALLINT NOT NULL,
    occurred_at TIMESTAMPTZ NOT NULL,
    conveyor_speed DOUBLE PRECISION,
    gripper_temperature DOUBLE PRECISION,
    PRIMARY KEY (scene_key, attempt_num)
);
```

### 필드

```mschema
# Table: read_grip_sensor_context
[
(scene_key:varchar, 장면 식별 키 (stream_id에서 'grip-attempt:' 제거), Primary Key),

(occurred_at:timestamptz, 데이터 촬영 일자 (event.occurredAt)),
(conveyor_speed:double precision, Conveyor belt speed 센서 드리프트 유입 키),
(gripper_temperature:double precision, Gripper temperature 센서 드리프트 유입 키)
]
```

### 투영 매핑 명세 (이벤트 → 컬럼)

> upsert 키: scene_key,attempt_num · 리플레이: projection_cursor 초기화 시 반드시 0 또는 null 설정. catch-up 전 재투영 시 upsert는 멱يد성(update-if-exists) 전제이므로 scene_key+attempt_num 키 충돌 시 기존 값 유지(overwrite=false) 또는 명시적 overwrite 정책 적용.

| 원천 이벤트 | payload 필드 | 컬럼 | 변환 |
| --- | --- | --- | --- |
| GripAttemptRecorded | conveyor_speed | conveyor_speed | verbatim |
| GripAttemptRecorded | gripper_temperature | gripper_temperature | verbatim |

파생 컬럼(이벤트 payload 아님):
- `scene_key` ← stream_id에서 'grip-attempt:' prefix 제거, '_attempt_num_' 및 '_YYYYMMDD' suffix 잘라내어 scene_key 추출
- `attempt_num` ← stream_id 내 '_attempt_num_' 자리(예: '_01_') 추출, 정수 캐스팅
- `occurred_at` ← stream_id 내 '_YYYYMMDD' 자리(예: '_20230923') 추출, ISO timestamp 포맷 변환

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { z } from 'zod';
import { toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripSensorContext } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

const sensorContextPayloadSchema = toyDataSchema.extend({
  conveyor_speed: z.coerce.number().optional(),
  gripper_temperature: z.coerce.number().optional(),
});

type ReadGripSensorContextInsert = InferInsertModel<typeof readGripSensorContext>;

@Injectable()
export class GripSensorContextProjector implements Projector<ReadGripSensorContextInsert> {
  readonly name: string = "grip-sensor-context-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripSensorContextProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripSensorContextInsert {
    let payload: z.infer<typeof sensorContextPayloadSchema>;
    try {
      payload = sensorContextPayloadSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      occurredAt: event.occurredAt,
      conveyorSpeed: payload.conveyor_speed ?? null,
      gripperTemperature: payload.gripper_temperature ?? null,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripSensorContextInsert): Promise<void> {
    await tx
      .insert(readGripSensorContext)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripSensorContext.sceneKey, readGripSensorContext.attemptNum],
        set: {
          occurredAt: row.occurredAt,
          conveyorSpeed: row.conveyorSpeed,
          gripperTemperature: row.gripperTemperature,
        },
      });
  }
}
```

### 버전 교체 코드 — `src/projection/projection.service.ts` (modifyFile)

```typescript
import { Injectable } from '@nestjs/common';
import { PinoLogger } from 'nestjs-pino';
import { InsertResult, InsertService } from '@/insert/insert.service';
import { GripResultProjector } from '@/projection/projector/grip-result.projector';
import { MultiModalProjector } from '@/projection/projector/multimodal.projector';
import { GripSensorContextProjector } from '@/projection/projector/grip-sensor-context.projector';
import { ProjectionResult } from '@/projection/projector/projector';
import { CatchUpRunner } from '@/projection/runner/catch-up.runner';
import { LogAction } from '@/shared/logger/logging-context';

export type CatchUpAllResult = {
  multimodal: ProjectionResult;
  gripResult: ProjectionResult;
  sensorContext: ProjectionResult;
};

export type InsertAndProjectionAllResult = {
  insert: InsertResult;
  projection: CatchUpAllResult;
};

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly sensorContext: GripSensorContextProjector,
    private readonly insertService: InsertService,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  catchUpMultimodal(): Promise<ProjectionResult> {
    return this.runner.run(this.multimodal);
  }

  catchUpGripResult(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResult);
  }

  catchUpSensorContext(): Promise<ProjectionResult> {
    return this.runner.run(this.sensorContext);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();
    const sensorContext: ProjectionResult = await this.catchUpSensorContext();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult, sensorContext };
  }

  async insertAllAndProjectAll(): Promise<InsertAndProjectionAllResult> {
    this.logger.info(
      { action: LogAction.PROJECTION_START },
      "전체 적재+투영 시작",
    );

    const insert: InsertResult = await this.insertService.insertToyData();
    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
}
```
