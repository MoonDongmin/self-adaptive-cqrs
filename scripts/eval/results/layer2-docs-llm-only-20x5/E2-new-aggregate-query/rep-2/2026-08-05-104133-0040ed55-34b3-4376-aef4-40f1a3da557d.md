### Decision Drivers
- Query Intent: Group By object_name with cumulative metrics (attempts/success/rate).
- Existing Schema Limitation: read_grip_result is row-level, lacks aggregation columns.
- Projector Architecture: Current projectors map 1 event -> 1 row. No stateful accumulator exists for object-level stats.
- API Versioning: New Read Model requires schema evolution and version switch.

### Considered Options
#### 기존 보강 (기각 대안)
- 접근: read_grip_result 스키마에 total_attempts, success_count, success_rate 추가, GripResultProjector.upsert() 의 onConflictDoUpdate 로 집계 갱신 적용.
- 제안 필드: total_attempts, success_count, success_rate
- 트레이드오프: 키 (scene_key, attempt_num) 기준 aggregation 은 행 단위 일관성 위배. 동일 scene/attempt 의 중복 업데이트 시 rate 계산 모순. 리스크: Read Model 정합성 규칙 위반 및 client-side join 필요 재개.
```typescript
await tx.insert(readGripResult).values(row).onConflictDoUpdate({ target: [readGripResult.sceneKey, readGripResult.attemptNum], set: { totalAttempts: row.totalAttempts + 1, successCount: row.gripSucceed === 1 ? row.successCount + 1 : row.successCount, successRate: row.successCount / row.totalAttempts } });
```

#### 신규 분리 (권고)
- 접근: 확정 설계(read_grip_result_aggregate) 적용. GripResultProjector 또는 별도 AggregateProjector 의 upsert() 메서드에서 object_name 기준 onConflictDoUpdate 로 total_attempts, success_count, success_rate 누적 갱신.

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripResultAggregate } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type GripResultAggregateProjectorInsert = InferInsertModel<typeof readGripResultAggregate>;

function toNumberOrNull(value: unknown): number | null {
  if (value === undefined || value === null) {
    return null;
  }
  const parsed = Number(value);
  return Number.isNaN(parsed) ? null : parsed;
}

function toStringOrNull(value: unknown): string | null {
  return value === undefined || value === null ? null : String(value);
}

function toDateOrNull(value: unknown): Date | null {
  if (typeof value !== "string" && typeof value !== "number") {
    return null;
  }
  const parsed = new Date(value);
  return Number.isNaN(parsed.getTime()) ? null : parsed;
}

@Injectable()
export class GripResultAggregateProjector implements Projector<GripResultAggregateProjectorInsert> {
  readonly name: string = "grip-result-aggregate-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripResultAggregateProjector.name);
  }

  map(event: EventStoreEventRow): GripResultAggregateProjectorInsert {
    // 결정론 합성 프로젝터 — payload 경로가 자명하지 않은 컬럼은 §2 투영 매핑 명세와 대조해 보정하라.
    const payload = event.payload as Record<string, unknown>;

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      objectName: String(payload["object_name"] ?? ""),
      totalAttempts: toNumberOrNull(payload["total_attempts"]),
      successCount: toNumberOrNull(payload["success_count"]),
      successRate: toNumberOrNull(payload["success_rate"]),
    };
  }

  async upsert(tx: DrizzleTx, row: GripResultAggregateProjectorInsert): Promise<void> {
    await tx
      .insert(readGripResultAggregate)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripResultAggregate.objectName],
        set: {
          totalAttempts: row.totalAttempts,
          successCount: row.successCount,
          successRate: row.successRate,
        },
      });
  }
}
```
