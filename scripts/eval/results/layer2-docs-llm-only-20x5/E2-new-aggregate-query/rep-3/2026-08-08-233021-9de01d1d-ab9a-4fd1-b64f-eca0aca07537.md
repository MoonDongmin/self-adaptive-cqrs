## 2. Read Model 생성 SQL (Read Model DDL)

> 실행 게이트: 아래 변경은 인간 승인 후에만 적용한다 (human-in-the-loop).

- 대상: `read_grip_aggregate` · 키: object_name · 원천 이벤트: GripAttemptRecorded

```sql
CREATE TABLE read_grip_aggregate (
  object_name varchar NOT NULL,
  total_attempts bigint,
  success_count bigint,
  success_rate doublePrecision,
  PRIMARY KEY (object_name)
);
```

### 필드

```mschema
# Table: read_grip_aggregate
[
(object_name:varchar, 파지 대상 객체명 (payload.objects[0].class_name). Primary Key., Primary Key),
(total_attempts:bigint, 해당 object_name의 누적 시도 수. upsert 시 excluded.total_attempts + row.total_attempts 로 갱신.),
(success_count:bigint, 해당 object_name의 누적 성공 수. upsert 시 excluded.success_count + row.success_count 로 갱신.),
(success_rate:doublePrecision, 누적 성공률 (success_count / total_attempts). upsert 시 재계산.)
]
```

### 투영 매핑 명세 (이벤트 → 컬럼)

> upsert 키: object_name · 리플레이: projection_cursor 초기화 시 aggregated state seed 적용해야 하며, catch-up 전체 재투영은 upsert 전제(excluded+row) 로직이 멱덴성으로 보장되도록 0 제로 오류 처리를 검증해야 한다.

| 원천 이벤트 | payload 필드 | 컬럼 | 변환 |
| --- | --- | --- | --- |
| GripAttemptRecorded | objects[].class_name | object_name | verbatim |
| GripAttemptRecorded | grip_succeed | success_count | cast to bigint |
| GripAttemptRecorded | - | total_attempts | 1 |

파생 컬럼(이벤트 payload 아님):
- `success_rate` ← success_count / NULLIF(total_attempts, 0)

import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripAggregate } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type GripAggregateProjectorInsert = InferInsertModel<typeof readGripAggregate>;

function toNumberOrNull(value: unknown): number | null {
  if (value === undefined || value === null) {
    return null;
  }
  const parsed = Number(value);
  return Number.isNaN(parsed) ? null : parsed;
}

function toStringOrNull(value: unknown): string | null {
  return value === undefined || value === null ? null : String(value);
}

function toDateOrNull(value: unknown): Date | null {
  if (typeof value !== "string" && typeof value !== "number") {
    return null;
  }
  const parsed = new Date(value);
  return Number.isNaN(parsed.getTime()) ? null : parsed;
}

@Injectable()
export class GripAggregateProjector implements Projector<GripAggregateProjectorInsert> {
  readonly name: string = "grip-aggregate-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripAggregateProjector.name);
  }

  map(event: EventStoreEventRow): GripAggregateProjectorInsert {
    // 결정론 합성 프로젝터 — payload 경로가 자명하지 않은 컬럼은 §2 투영 매핑 명세와 대조해 보정하라.
    const payload = event.payload as Record<string, unknown>;

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      objectName: String(payload["object_name"] ?? ""),
      totalAttempts: toNumberOrNull(payload["total_attempts"]),
      successCount: toNumberOrNull(payload["success_count"]),
      successRate: toNumberOrNull(payload["success_rate"]),
    };
  }

  async upsert(tx: DrizzleTx, row: GripAggregateProjectorInsert): Promise<void> {
    await tx
      .insert(readGripAggregate)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripAggregate.objectName],
        set: {
          totalAttempts: row.totalAttempts,
          successCount: row.successCount,
          successRate: row.successRate,
        },
      });
  }
}
