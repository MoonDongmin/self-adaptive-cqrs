### Considered Options
#### sourceDataFixRequest
- 접근: 유지 현 toy-data.dto.ts Zod strict int 검증. 실패 파일(_02022_01_20230923.json, _02023_01_20230923.json)의 원천 JSON 수정 요청(필드 id, num_keypoints 강제 int 타입 변환)으로 재적재 유도.
