## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 40, `payload.schema.drift`) payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) ← 트립 앵커 → Zod DTO 검증 통과로 ES 저장이 정상이나 신규 키(gripper_temperature, conveyor_speed) 가 매핑 로직 미존재로 Read Model 투영이 누락. [corr:15c55464-3d9a-4134-8037-1412490c205e]
- (level 40, `insight.card.miss`) insight 카드 없음: 최근 적재 데이터에 gripper_temperature 필드가 들어오기 시작했다. 이 값을 시간대별로 조회하고 싶다. 현재 Read Model로 가능한가? 안 되면 어떻게 해야 하나? → 사용자 의도(시간대별 조회) 가 기존 Read Model 의 scene/attempt 단위 구조로는 매핑할 수 있는 컬럼 부재로 조회 실패. [corr:6b541099-476d-4f52-b09c-35663af28085]
- src/insert/dto/toy-data.dto.ts 의 toyDataSchema 정의에 gripper_temperature, conveyor_speed 가 미존재하여 Zod parse 시 해당 키가 silently dropped, ES 적재는 정상이나 Read Model 후보 매핑이 누락 [corr:15c55464-3d9a-4134-8037-1412490c205e].
- src/shared/database/schema/service/read-grip-result.ts 의 readGripResult Drizzle 테이블 정의에 온도/속도 컬럼이 미존재, GripResultProjector.map() 반환 객체 또한 신규 키 매핑이 미구현 [corr:15c55464-3d9a-4134-8037-1412490c205e].
- 사용자 요청 insight.card.miss 로그는 scene_key/attempt_num 단위 행 구조로는 시간대별 집계(aggregation) 의도 충족이 불가능, 기존 Read Model(read_grip_result, read_multimodal) 만으로는 신규 sensor drift 매핑이 부재 [corr:6b541099-476d-4f52-b09c-35663af28085].

### Decision Drivers
- 시간대별(sensor drift) 집계 의도 충족 vs scene/attempt 단위 정밀성 유지
- 신규 payload 키 유입(schema drift) 격리 및 Read Model 확장에 따른 API 카탈로그 동기화
- 기존 Read Model(read_grip_result) 의 구조적 변경 최소화(Granularity separation)

### Considered Options
#### 기존ReadModelColumnExtension
- 접근: GripResultProjector.map() 및 Drizzle 스키마 추가 수정으로 gripper_temperature_avg, conveyor_speed_avg 열 확장.

- 트레이드오프: scene/attempt 단위 정밀성 규칙 위배, 시간대별 집계 의도 충족 실패(행 단위 매핑만 가능), migration 비용 과다.

#### newReadModelSensorDrift
- 접근: 신규 SensorDriftProjector 구현으로 read_grip_sensor_drift_v2 테이블 투영.
- 제안 필드: read_grip_sensor_drift_v2.occurred_at_hour, read_grip_sensor_drift_v2.gripper_temperature_avg, read_grip_sensor_drift_v2.conveyor_speed_avg, read_grip_sensor_drift_v2.event_count
- 트레이드오프: 신규 프로젝터 등록 및 API 카탈로그 sync 필요, 기존 Read Model 무해화.

### Consequences
- (+) 사용자 의도(시간대별 조회) 충족
- (+) 기존 Read Model 구조 무해화
- (+) schema drift 신규 키 매핑 격리
- (−) API 카탈로그 sync 작업 동반 필요
- (−) 신규 테이블 migration 및 projector 등록 overhead 발생

### Non-Goals
- read_grip_result 의 scene/attempt 정밀성 규칙 변경
- Zod DTO 스키마 강제 수정(원천 데이터 요청)
- poison event rollback 커서 점프

CREATE TABLE read_grip_sensor_drift_v2 (
  occurred_at_hour timestamptz NOT NULL,

  conveyor_speed_avg double precision,

### 필드

### 투영 매핑 명세 (이벤트 → 컬럼)

> upsert 키: occurred_at_hour · 리플레이: projection_cursor must initialize at -1 for full replay. Catch-up replay requires idempotent upsert logic: overwrite or correctly accumulate values when reprocessing events.

| 원천 이벤트 | payload 필드 | 컬럼 | 변환 |
| --- | --- | --- | --- |
| GripAttemptRecorded | gripper_temperature | gripper_temperature_avg | verbatim |
| GripAttemptRecorded | conveyor_speed | conveyor_speed_avg | verbatim |

파생 컬럼(이벤트 payload 아님):
- `occurred_at_hour` ← extract YYYY-MM-DD from filename, truncate to hour boundary
- `event_count` ← counter incremented per event within same occurred_at_hour bucket

import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripSensorDriftV2 } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type GripSensorDriftV2ProjectorInsert = InferInsertModel<typeof readGripSensorDriftV2>;

function toNumberOrNull(value: unknown): number | null {
  if (value === undefined || value === null) {
    return null;
  }
  const parsed = Number(value);
  return Number.isNaN(parsed) ? null : parsed;
}

function toStringOrNull(value: unknown): string | null {
  return value === undefined || value === null ? null : String(value);
}

function toDateOrNull(value: unknown): Date | null {
  if (typeof value !== "string" && typeof value !== "number") {
    return null;
  }
  const parsed = new Date(value);
  return Number.isNaN(parsed.getTime()) ? null : parsed;
}

@Injectable()
export class GripSensorDriftV2Projector implements Projector<GripSensorDriftV2ProjectorInsert> {
  readonly name: string = "grip-sensor-drift-v2-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripSensorDriftV2Projector.name);
  }

  map(event: EventStoreEventRow): GripSensorDriftV2ProjectorInsert {
    // 결정론 합성 프로젝터 — payload 경로가 자명하지 않은 컬럼은 §2 투영 매핑 명세와 대조해 보정하라.
    const payload = event.payload as Record<string, unknown>;

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      occurredAtHour: Number(payload["occurred_at_hour"] ?? 0),
      gripperTemperatureAvg: toNumberOrNull(payload["gripper_temperature_avg"]),
      conveyorSpeedAvg: toNumberOrNull(payload["conveyor_speed_avg"]),
      eventCount: toNumberOrNull(payload["event_count"]),
    };
  }

  async upsert(tx: DrizzleTx, row: GripSensorDriftV2ProjectorInsert): Promise<void> {
    await tx
      .insert(readGripSensorDriftV2)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripSensorDriftV2.occurredAtHour],
        set: {
          gripperTemperatureAvg: row.gripperTemperatureAvg,
          conveyorSpeedAvg: row.conveyorSpeedAvg,
          eventCount: row.eventCount,
        },
      });
  }
}
