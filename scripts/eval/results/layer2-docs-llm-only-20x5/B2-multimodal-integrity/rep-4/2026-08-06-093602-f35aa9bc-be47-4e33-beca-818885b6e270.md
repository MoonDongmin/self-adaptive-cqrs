### Considered Options
#### map() 정합성 차단 (Prevent Insertion)
- 접근: MultiModalProjector.map() 내 toyDataSchema.parse() 성공 시, checkIntegrity(row) 호출을 추가하여 위반이 감지 시 throw new Error(...) 처리. 이로해 CatchUpRunner의 catch block에서 이벤트 스킵/로트백 처리가 자연스럽게 유도됨.
- 제안 필드: map(), checkIntegrity() 연계
- 트레이드오프: 배치 연속성 단절 가능성, but 데이터 품질 보장.
```typescript
try { payload = toyDataSchema.parse(event.payload); } catch (err) { throw err; } const row = this.buildRow(payload, event); const violations = this.checkIntegrity(row); if (violations.length > 0) { throw new Error(`integrity violation: ${violations[0].detail}`); } return row;
```

#### read_multimodal 정리 SQL 격리 (Post-Cleanup)
- 접근: 기존 투영 흐름 유지, 대신 projection.done 이후 별도 정리 스텝에서 containmentSql 실행으로 PK 매칭된 오염 행 DELETE.
- 제안 필드: cleanup.sql, runner.postProcess()
- 트레이드오프: DB I/O 추가 비용, 원천 payload 수정 요청 병추.
