### Decision Drivers
- 데이터 무해화 원칙 준수(poison event 차단)
- 적재/투영 boundary isolation(적재 실패 시 투영 정상 진행)
- operational overhead minimization
- upstream feedback loop clarity

### Considered Options

- 접근: src/insert/dto/toy-data.dto.ts 의 Zod 검증(grip_succeed) 은 그대로 유지. 실패 로그(insert.file.failed) 를 upstream 모니터링/alert 보강으로 원천 파일 수정 요청을 유도.

- 트레이드오프: 재투영 비용 0, 데이터 무해화 보장, 단 외부 파지 수정 절차 필요.
