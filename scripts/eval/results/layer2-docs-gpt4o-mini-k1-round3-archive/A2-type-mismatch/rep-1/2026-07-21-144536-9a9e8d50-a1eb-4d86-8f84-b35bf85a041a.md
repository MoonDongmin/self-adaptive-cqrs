- zod 검증을 통해 원천 데이터의 유효성을 강화할 수 있음.

### Considered Options
#### 원천 데이터 수정 요청 + zod 검증 강화
- 접근: src/insert/dto/toy-data.dto.ts에서 grip_succeed 필드의 타입을 z.number().int().min(0).max(1)로 유지하고, 원천 데이터에서 이 필드의 타입을 검증하여 string 타입의 값을 거부하도록 수정.
- 제안 필드: grip_succeed
- 트레이드오프: 원천 데이터의 타입 오류를 수정하여 Read Model의 적재를 정상화할 수 있음.
```typescript

```

#### 무유입 검증 절차 추가
- 접근: 원천 데이터의 유효성을 검증하는 절차를 추가하여 잘못된 데이터가 적재되지 않도록 함.
- 제안 필드: grip_succeed
- 트레이드오프: 원천 데이터의 유효성을 강화할 수 있으나, 추가적인 검증 로직이 필요함.
