### Decision Drivers
- Read Model의 데이터 품질 보장
- 원천 데이터의 유효성 검사 강화

### Considered Options
#### 유효성 검사 추가
- 접근: GripResultProjector의 map() 메서드에서 grip_data와 robot_tf의 유효성 검사를 추가하여 필드가 존재하지 않을 경우 오류를 발생시키도록 수정.
- 제안 필드: grip_data, robot_tf
- 트레이드오프: 이 방법은 원천 데이터의 유효성을 보장하므로 Read Model의 데이터 품질을 높일 수 있지만, 원천 데이터가 수정되지 않는 한 여전히 실패할 수 있음.
```typescript
if (!payload.grip_data) { throw new Error("grip_data 필드가 누락되었습니다."); } if (!payload.robot_tf) { throw new Error("robot_tf 필드가 누락되었습니다."); }
```

### Decision Outcome
유효성 검사 추가

### Consequences
- (+) Read Model의 데이터 품질 향상
- (+) 원천 데이터의 유효성 검사 강화
- (−) 원천 데이터가 수정되지 않으면 여전히 오류 발생 가능성

### Non-Goals
- Read Model 구조 변경
- 기존 데이터 수정
