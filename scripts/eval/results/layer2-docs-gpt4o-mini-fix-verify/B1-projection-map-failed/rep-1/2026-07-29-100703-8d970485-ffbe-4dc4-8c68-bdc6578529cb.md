## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 50, `projection.map.failed`) objects 비어 있음 ← 트립 앵커 → grip-result Read Model에서 objects 배열이 비어 있어 매핑 실패를 초래함 [corr:8d970485-ffbe-4dc4-8c68-bdc6578529cb]
- Insight 카드의 objects[].class_name은 파지 대상 객체명으로, 현재 payload에서 비어 있는 상태입니다.
- GripResultProjector의 map 메서드에서 if (payload.objects.length === 0) 조건문이 실행되어 오류 로그를 남기고 있습니다. [src/projection/projector/grip-result.projector.ts]
- read_grip_result 테이블의 object_name 컬럼은 payload.objects[0].class_name에서 값을 가져오는데, 현재 objects가 비어 있어 null로 설정됩니다.

### Decision Drivers
- 요청 충족 가능성
- 데이터 무결성 유지
- 오류 처리 정책

### Considered Options
#### 기본값 설정을 통한 오류 처리
- 접근: GripResultProjector의 map 메서드에서 payload.objects가 비어 있을 경우, 기본값을 설정하거나 오류를 처리하는 로직을 추가합니다.
- 제안 필드: object_name, grip_succeed, gripper_type
- 트레이드오프: 기본값을 설정할 경우, 실제 데이터와의 불일치가 발생할 수 있으며, 오류를 처리할 경우 요청이 실패할 수 있습니다.
