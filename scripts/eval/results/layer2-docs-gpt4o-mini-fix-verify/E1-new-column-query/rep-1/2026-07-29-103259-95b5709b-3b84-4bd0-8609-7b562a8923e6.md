## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 40, `payload.schema.drift`) payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) ← 트립 앵커 → Read Model에 gripper_temperature 필드가 부족함을 드러냄. [corr:95b5709b-3b84-4bd0-8609-7b562a8923e6]
- (level 40, `insight.card.miss`) insight 카드 없음: 최근 적재 데이터에 gripper_temperature 필드가 들어오기 시작했다. 이 값을 시간대별로 조회하고 싶다. 현재 Read Model로 가능한가? 안 되면 어떻게 해야 하나? → gripper_temperature 필드가 Read Model에 존재하지 않아 조회 요청이 실패함을 드러냄. [corr:db08146c-967c-46f0-990c-ecf682324bd1]
- Insight 카드의 현재 컬럼명: read_grip_result.object_name (파지 대상 객체명) 및 read_grip_result.grip_succeed (파지 성공 여부)와 같은 필드가 존재하지만, gripper_temperature 필드는 현재 null임.
- src/projection/projector/grip-result.projector.ts에서 map() 메서드가 gripper_temperature를 처리하지 않음.
- src/shared/database/schema/service/read-grip-result.ts에서 gripper_temperature 필드가 정의되어 있지 않음.

### Decision Drivers
- 사용자의 gripper_temperature 필드 조회 요청 충족
- 기존 Read Model의 구조적 부족 해결
- 데이터 중복 최소화

### Considered Options
#### 신규 Read Model 생성
- 접근: 신규 Read Model read_gripper_temperature를 생성하여 gripper_temperature 필드를 포함하도록 함.
- 제안 필드: read_gripper_temperature.object_name, read_gripper_temperature.gripper_temperature, read_gripper_temperature.grip_succeed, read_gripper_temperature.occurred_at, read_gripper_temperature.scene_key, read_gripper_temperature.attempt_num, read_gripper_temperature.stream_id, read_gripper_temperature.global_seq
- 트레이드오프: 신규 Read Model 생성으로 인한 데이터 중복 가능성, 관리 복잡성 증가.
```typescript
return {
  object_name: payload.objects[0].class_name,
  gripper_temperature: payload.gripper_temperature, // 신규 필드 추가
  grip_succeed: payload.grip_succeed,
  occurred_at: event.occurredAt,
  scene_key: event.streamId.replace(/^grip-attempt:/, ""),
  attempt_num: event.attemptNum,
  stream_id: event.streamId,
  global_seq: event.globalSeq,
};
```

### Decision Outcome
신규 Read Model read_gripper_temperature 생성 — 사용자의 gripper_temperature 조회 요청을 충족하기 위해 필수적임.

### Consequences
- (+) 사용자가 gripper_temperature 필드를 시간대별로 조회할 수 있게 됨.
- (+) 데이터 구조의 일관성 유지.
- (−) 신규 Read Model로 인한 데이터 중복 가능성.
- (−) 관리 복잡성 증가.

### Non-Goals
- 기존 Read Model의 구조 변경.
- 기존 데이터의 수정.

```ts
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripperTemperature } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripperTemperatureInsert = InferInsertModel<typeof readGripperTemperature>;

@Injectable()
export class GripperTemperatureProjector implements Projector<ReadGripperTemperatureInsert> {
  readonly name: string = "gripper-temperature-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripperTemperatureProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripperTemperatureInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (err) {
      this.logger.error({
        action: LogAction.MAP_FAILED,
        err,
        [LogContext.EVENT_ID]: event.eventId,
        [LogContext.STREAM_ID]: event.streamId,
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      }, "이벤트 매핑(검증) 실패");
      throw err;
    }

    this.logger.debug({
      action: LogAction.EVENT_MAPPED,
      [LogContext.PROJECTOR_NAME]: this.name,
      [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
      [LogContext.ATTEMPT_NUM]: event.attemptNum,
      [LogContext.GLOBAL_SEQ]: event.globalSeq,
    }, "이벤트 매핑");

    return {
      objectName: payload.objects[0].class_name,
      gripperTemperature: parseFloat(payload.gripper_temperature),
      gripSucceed: payload.grip_succeed,
      occurredAt: event.occurredAt,
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripperTemperatureInsert): Promise<void> {
    await tx
      .insert(readGripperTemperature)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripperTemperature.objectName],
        set: {
          gripperTemperature: row.gripperTemperature,
          gripSucceed: row.gripSucceed,
          occurredAt: row.occurredAt,
          sceneKey: row.sceneKey,
          attemptNum: row.attemptNum,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```

### 버전 교체 코드 — `src/projection/projection.service.ts` (modifyFile)

```typescript
import { GripperTemperatureProjector } from '@/projection/projector/gripper-temperature.projector';

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly gripperTemperature: GripperTemperatureProjector,
    private readonly insertService: InsertService,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  async catchUpGripperTemperature(): Promise<ProjectionResult> {
    return this.runner.run(this.gripperTemperature);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();
    const gripperTemperature: ProjectionResult = await this.catchUpGripperTemperature();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult, gripperTemperature };
  }
}
```
