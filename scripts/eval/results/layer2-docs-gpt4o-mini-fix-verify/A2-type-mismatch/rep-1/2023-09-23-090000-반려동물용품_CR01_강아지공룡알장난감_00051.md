- (반려동물용품_CR01_강아지공룡알장난감_00056#2, `grip3dPose` / grip3dPose) 관측 `z 최솟값 0.086 ≤ 0` vs 기준 `grip3dPoseZ_depth` [0.01, 0.30] m → 델타 0.086 m · 물리적으로 불가능한 음수 깊이 값이 관측됨.
- (반려동물용품_CR01_강아지공룡알장난감_00055#3, `robotTf` / robotTfTranslation) 관측 `y=0.755` vs 기준 `robotTfTranslationY_workspace` [0.65, 0.95] m → 델타 0.755 m · robotTfTranslation y 값이 기대 범위 내에 있음.
- (반려동물용품_CR01_강아지공룡알장난감_00051#2, `robotTf` / robotTfTranslation) 관측 `z=1.03805` vs 기준 `robotTfTranslationZ_workspace` [0.95, 1.15] m → 델타 1.03805 m · robotTfTranslation z 값이 기대 범위 내에 있음.

### 관찰

- grip3dPose z 최솟값이 물리적으로 불가능한 음수 깊이로 판별됨.
- robotTfTranslation y 값이 기대 범위 내에 있음.
- robotTfTranslation z 값이 기대 범위 내에 있음.

### 영향 범위

- read_grip_result

### 근본원인 — upstreamSensorImplausible

1. grip3dPose z 값이 물리적으로 불가능하여 오염됨.
2. robotTfTranslation y 값이 기준선 내에 있어야 하며, grip3dPoseZ가 [0.01, 0.30] m 범위 내에 있어야 하는 규칙이 제대로 적용되지 않음.
3. 이상값이 발생한 이유는 센서의 물리적 한계를 초과한 값이 기록되었기 때문임.
4. 이로 인해 시스템이 올바른 값을 판별하지 못하고 잘못된 데이터를 기록하게 됨.
5. 결국, 이러한 문제는 센서의 정확도와 신뢰성에 대한 의문을 제기함.

### 의사결정 기준

- 기준선 규칙 위반 여부
- 센서 데이터의 물리적 정합성
- 이상값의 발생 원인 분석

### 해결책 옵션 (contain → fix → harden)

#### [contain] 오염된 데이터 격리
- 접근: 오염 행을 격리하여 원본은 event_store에 보존하고 재투영으로 복원할 수 있도록 함.
- 트레이드오프: 데이터 손실 없이 원본을 보존할 수 있음.
```sql
-- 오염 행 격리: 이상 (scene_key, attempt_num) 행을 Read Model 에서 제거한다.
-- 원본 이벤트는 event_store 에 보존되므로 v2 재투영(무결성 플래그 포함)으로 복원 가능하다.
DELETE FROM read_grip_result WHERE (scene_key, attempt_num) IN (('반려동물용품_CR01_강아지공룡알장난감_00056', 2), ('반려동물용품_CR01_강아지공룡알장난감_00055', 3), ('반려동물용품_CR01_강아지공룡알장난감_00051', 2));
```

#### [fix] 타깃 패치 및 재투영
- 접근: 이상값을 수정하고 재투영하여 올바른 데이터를 기록함.
- 트레이드오프: 데이터의 정확성을 높일 수 있으나, 수정 과정에서 추가적인 리소스가 소모됨.

#### [harden] 베이스라인 규칙 추가
- 접근: 기존 규칙에 새로운 조건을 추가하여 향후 유사한 이상값 발생을 방지함.
- 트레이드오프: 규칙 추가로 인해 시스템의 복잡성이 증가할 수 있음.
```sql
ALTER TABLE read_grip_result ADD CONSTRAINT grip3dPoseZ_depth CHECK ((grip_3d_pose->>'z')::numeric BETWEEN 0.01 AND 0.30);
```

### 권장
- read_grip_result_v2 설계 채택
- 사유: 신규 설계는 데이터의 정확성과 신뢰성을 높이기 위해 필요하며, 기존의 문제를 해결할 수 있는 기반을 제공함.
- 수용하는 트레이드오프: 기존 시스템의 복잡성을 감수하고 새로운 규칙을 도입함.
- 기각한 대안:
  - 기존 read_grip_result 수정은 충분하지 않음.
  - v1 프로젝터 수정만으로는 문제를 해결할 수 없음.

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import { SensorValueMessage } from '@/projection/kafka/sensor-value.message';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripResultV2 } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripResultV2Insert = InferInsertModel<typeof readGripResultV2>;

@Injectable()
export class GripResultV2Projector implements Projector<ReadGripResultV2Insert> {
  readonly name: string = "grip-result-v2-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripResultV2Projector.name);
  }

  map(event: EventStoreEventRow): ReadGripResultV2Insert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (err) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          err,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw err;
    }

    if (payload.objects.length === 0) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
        },
        "objects 비어 있음",
      );

      throw new Error(
        `grip-result-v2 map: empty objects in event ${event.eventId}`,
      );
    }

    const gripOutlierFlag = (payload.grip_data.grip_3d_pose.z1 < 0.01 || payload.grip_data.grip_3d_pose.z1 > 0.30) ? 1 : 0;

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      objectName: payload.objects[0].class_name,
      gripSucceed: payload.grip_succeed,
      gripperType: "finger",
      occurredAt: event.occurredAt,
      grip2dPose: payload.grip_data.grip_2d_pose,
      grip3dPose: payload.grip_data.grip_3d_pose,
      robotTf: payload.robot_tf,
      humanAnnotationGrasp: payload.human_annotation_grasp,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
      gripOutlierFlag,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripResultV2Insert): Promise<void> {
    await tx
      .insert(readGripResultV2)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripResultV2.sceneKey, readGripResultV2.attemptNum],
        set: {
          objectName: row.objectName,
          gripSucceed: row.gripSucceed,
          gripperType: row.gripperType,
          occurredAt: row.occurredAt,
          grip2dPose: row.grip2dPose,
          grip3dPose: row.grip3dPose,
          robotTf: row.robotTf,
          humanAnnotationGrasp: row.humanAnnotationGrasp,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
          gripOutlierFlag: row.gripOutlierFlag,
        },
      });
  }

  toSensorValueMessages(rows: ReadGripResultV2Insert[]): SensorValueMessage[] {
    return rows.map((row) => ({
      sceneKey: row.sceneKey,
      attemptNumber: row.attemptNum,
      streamId: row.streamId,
      globalSequence: row.globalSeq,
      occurredAt: row.occurredAt.toISOString(),
      objectName: row.objectName,
      gripSucceed: row.gripSucceed,
      grip2dPose: row.grip2dPose,
      grip3dPose: row.grip3dPose,
```
