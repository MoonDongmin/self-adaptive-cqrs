## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 40, `payload.schema.drift`) payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) ← 트립 앵커 → 기존 Read Model이 신규 키를 처리할 수 없어 데이터 유실이 발생함을 드러냄. [corr:aadd72c5-1303-4167-b2bb-4a45ce4e5bb7]
- `read_grip_result` 테이블의 `object_name` 컬럼은 파지 대상 객체명을 저장하는데, 신규 키인 `conveyor_speed`와 `gripper_temperature`는 이 테이블에 포함되지 않음.
- `grip_succeed`와 `occurred_at`은 `read_grip_result`에서 사용되지만, 신규 키는 `read_grip_result`에 매핑되지 않음.
- `multimodal.projector.ts`에서 `image2dUri`와 `videoUri`가 null로 설정되어 있어, 신규 키를 처리할 수 있는 로직이 없음.

### Decision Drivers
- 신규 키 유입으로 인한 데이터 유실 방지
- 기존 Read Model과의 호환성 유지
- 신규 데이터 수용 가능성

### Considered Options
#### 신규 Read Model `read_grip_result_drift`의 채택
- 접근: read_grip_result_drift 테이블을 생성하여 신규 키를 수용하도록 함.
- 제안 필드: scene_key, attempt_num, conveyor_speed, gripper_temperature, object_name, grip_succeed, occurred_at, stream_id, global_seq
- 트레이드오프: 신규 Read Model을 통해 데이터 유실을 방지하고, 기존 Read Model과의 호환성을 유지할 수 있음.
```typescript

  scene_key VARCHAR NOT NULL,
  attempt_num SMALLINT NOT NULL,
  conveyor_speed NUMERIC,
  gripper_temperature NUMERIC,

  grip_succeed SMALLINT NOT NULL,
  occurred_at TIMESTAMPTZ NOT NULL,
  stream_id VARCHAR NOT NULL,
  global_seq BIGINT NOT NULL,
  PRIMARY KEY (scene_key, attempt_num)
);
```

### Decision Outcome
신규 Read Model `read_grip_result_drift`의 채택 — 신규 키를 수용하여 데이터 유실을 방지할 수 있음.

### Consequences
- (+) 신규 키를 수용하여 데이터 유실 방지
- (+) 기존 Read Model과의 호환성 유지
- (−) 신규 Read Model 관리 필요
- (−) 기존 시스템과의 통합 작업 필요

### Non-Goals
- 기존 Read Model의 구조적 변경
- 기존 데이터의 손실

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripResultDrift } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripResultDriftInsert = InferInsertModel<typeof readGripResultDrift>;

@Injectable()
export class GripResultDriftProjector implements Projector<ReadGripResultDriftInsert> {
  readonly name: string = "grip-result-drift-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripResultDriftProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripResultDriftInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (err) {
      this.logger.error({
        action: LogAction.MAP_FAILED,
        err,
        [LogContext.EVENT_ID]: event.eventId,
        [LogContext.STREAM_ID]: event.streamId,
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      }, "이벤트 매핑(검증) 실패");
      throw err;
    }

    this.logger.debug({
      action: LogAction.EVENT_MAPPED,
      [LogContext.PROJECTOR_NAME]: this.name,
      [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
      [LogContext.ATTEMPT_NUM]: event.attemptNum,
      [LogContext.GLOBAL_SEQ]: event.globalSeq,
    }, "이벤트 매핑");

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      conveyorSpeed: payload.conveyor_speed,
      gripperTemperature: payload.gripper_temperature,
      objectName: payload.objects[0].class_name,
      gripSucceed: payload.grip_succeed,
      occurredAt: event.occurredAt,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripResultDriftInsert): Promise<void> {
    await tx
      .insert(readGripResultDrift)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripResultDrift.sceneKey, readGripResultDrift.attemptNum],
        set: {
          conveyorSpeed: row.conveyorSpeed,
          gripperTemperature: row.gripperTemperature,
          objectName: row.objectName,
          gripSucceed: row.gripSucceed,
          occurredAt: row.occurredAt,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly gripResultDrift: GripResultDriftProjector,
    private readonly insertService: InsertService,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  catchUpGripResultDrift(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResultDrift);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();
    const gripResultDrift: ProjectionResult = await this.catchUpGripResultDrift();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult, gripResultDrift };
  }
}
