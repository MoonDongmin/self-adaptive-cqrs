## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 20, `insert.file.ok`) - → Successful payload ingestion confirms raw data availability but does not validate semantic consistency with row keys. [corr:-]
- (level 30, `-`) request completed ← 트립 앵커 → Pipeline execution context indicating batch processing initiation, preceding the integrity check failure at level 50. [corr:417ede90-bcea-40df-9479-1dcfb18ad25d] [corr:417ede90-bcea-40df-9479-1dcfb18ad25d]
- read_multimodal primary keys (scene_key, attempt_num) are derived from event.streamId.replace(/^grip-attempt:/, ""), while media filenames (image_2d_file_name, video_file_name) are parsed independently via regex in multimodal.projector.ts. Dual derivation causes mismatch when filenames diverge from stream_id metadata.
- checkIntegrity method detects mismatch but currently only returns IntegrityViolation[] without preventing DB write or flagging the row, allowing contaminated rows to persist.
- image_2d_uri and video_uri columns remain hardcoded to null in map(), leaving URI mapping logic unimplemented and irrelevant to current integrity scope.

### Decision Drivers
- Data Integrity vs Availability Tradeoff
- Schema Stability Requirement
- Operational Cost & Re-execution Policy
- Error Propagation Boundary

### Considered Options
#### skipOnIntegrityViolation
- 접근: Modify MultiModalProjector.map() to invoke checkIntegrity before returning row; if violations exist, return null and log skip event.
- 제안 필드: map(), checkIntegrity()
- 트레이드오프: Prevents DB write but omits row entirely; requires downstream catch-up re-execution for corrected payloads. Low CPU cost, zero schema change.
```typescript
const violations = this.checkIntegrity(row); if (violations.length > 0) { this.logger.warn({ action: LogAction.SKIP_INTEGRITY_VIOLATION }, 'skip mismatched multimodal row'); return null; }
```

#### deadLetterLogOnly
- 접근: Intercept in ProjectionService.catchUpAll() by filtering projector results before DB commit; log violation details as dead-letter metadata without altering projector logic.
- 제안 필드: catchUpAll(), CatchUpRunner
- 트레이드오프: Centralizes error handling but breaks projector encapsulation; adds routing overhead.
```typescript
const rows = await this.runner.run(this.multimodal); const validRows = rows.filter(r => !r.violations?.length); await tx.insert(readMultimodal).values(validRows);
```

### Decision Outcome
skipOnIntegrityViolation — Maintains projector encapsulation, prevents contaminated row insertion, and aligns with dead-letter policy without schema expansion.

### Consequences
- (+) Prevents semantic integrity violations from pollishing the read model
- (+) Zero schema/API version impact
- (+) Clear skip logging enables downstream re-execution
- (−) Omits mismatched rows until corrected payloads arrive
- (−) Requires catch-up runner to handle null returns gracefully
- (−) Slight CPU overhead for pre-validation in map()

### Non-Goals
- URI mapping implementation (image_2d_uri, video_uri)
- Schema expansion or version switching
- LLM-based semantic analysis of payload content
