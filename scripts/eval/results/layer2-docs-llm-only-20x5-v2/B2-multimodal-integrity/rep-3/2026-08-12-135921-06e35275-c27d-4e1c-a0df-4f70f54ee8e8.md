## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 20, `-`) 카드 데이터 조회 → 매핑 단계 진입 시 정합성 검증 로직 개시.
- (level 20, `insight.card.rendered`) insight 카드 렌더 → Read Model 데이터 조회 후 integrity check 실패 감지.
- Insight card의 read_multimodal.image_2d_file_name과 video_file_name은 원천 파일명 저장 컬럼으로, 현재 MultiModalProjector.map()에서 payload["2D_image_file_name"]/payload.video_file_name을 직접 매핑. [corr:-]
- `multimodal.projector.ts`의 checkIntegrity() 메서드는 parseModalFileName() regex로 scene/attempt 추출해 대조하지만, 현재 ProjectionService.catchUpAll() 호출 경로가 runner.run(this.multimodal) 만 호출 map/upsert, checkIntegrity 실행 로직이 미연결되어 정합성 위반 로그(projection.integrity.violation)는 발생하나 행 유입 차단(skip) 조치가 미구현. [corr:-]
- `read_multimodal` 스키마의 scene_key, attempt_num은 Primary Key이나, integrity violation 시 해당 row가 이미 upsert 완료된 경우 오염 데이터가 영구 체우거나, 미투영 시 커서 점프 유실 발생. [corr:-]

### Decision Drivers
- 정합성 위반 감지 로직 연동 가시성
- 원천 데이터 결함 격리 원칙(거절·유지) 준수
- 신규 Read Model/스키마 변경 금지
- 기존 API 엔드포인트 호환 유지

### Considered Options
#### 기전 보강 (Integrity Check 연동)
- 접근: MultiModalProjector.map() 내 checkIntegrity 호출 후 violation 반환 시 throw new IntegrityViolationError(...) 차단 투영
- 제안 필드: IntegrityViolationError
- 트레이드오프: 재투영 비용 증가, poison event 발생으로 catch-up 롤백 필요, 커서 점프 유실 리스크
```typescript
const violations = this.checkIntegrity(row); if (violations.length > 0) throw new IntegrityViolationError(violations[0].detail);
```

#### 정합성 검사 연동 + skip 로직
- 접근: MultiModalProjector.map() 내 checkIntegrity 실행 후 violation 감지 시 return null 또는 custom error handling in ProjectionService로 row 유입 차단, integrity violation log 방출
- 제안 필드: skipLogic
- 트레이드오프: 무해화 처리 미필요(원천 수정 요청), 조회 정합성 유지, 구현 변경 국한
```typescript
const violations = this.checkIntegrity(row); if (violations.length > 0) { this.logger.error({ action: LogAction.INTEGRITY_VIOLATION, detail: violations[0].detail }, "정합성 위반 skip"); return null; }
```

### Decision Outcome
정합성 검사 연동 + skip 로직 - 원천 데이터 결함 격리 원칙 준수(거절·유지)로 무해화 코딩 금지, 구현 국한으로 유지보수 경감.

### Consequences
- (+) integrity check 실패 시 row 유입 차단으로 read_multimodal 정합성 보장
- (+) 원천 수정 요청 가이드 제공으로 데이터 품질 회복
- (−) skip 로직 적용 시 catch-up 커서 점프 미진
- (−) 미투영 이벤트 재실행 overhead 발생

### Non-Goals
- URI 매핑(image_2d_uri, video_uri) 구현
- grip_result projector 변경
- event_store schema 수정
