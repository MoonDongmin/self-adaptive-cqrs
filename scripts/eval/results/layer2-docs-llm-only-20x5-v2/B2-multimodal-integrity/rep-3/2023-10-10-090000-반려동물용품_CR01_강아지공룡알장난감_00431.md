## 1. 권고 (Recommendation)

> 성공(gripSucceed=1) 시도의 grip3dPose x 좌표가 음수(-0.2~-0.36m)로 물리적 정합성 위배되어 이상 판정 확정.

### 심각도 — warning

오염 컬럼은 grip3dPose x 좌표(음수 심도/위도 혼전 가설 실제). 영향 행수는 2건(Seq 22, 23)으로 성공 판정된 데이터이므로 downstream 컨트롤러의 grasp 계획에 치명할 수 있음. event_store 원천 기록 보존되어 재투영(fix)으로 복구 가능하나, 현재 read_grip_result 스키마에는 z>=0.01 및 x/y 합치기 규칙 누락되어 observer 가설이 조용히 투침됨.

### 기대-실측 델타 근거

- (반려동물용품_CR01_강아지공룡알장난감_00431#3, `grip3dPose` / grip3dPose) 관측 `"x5":-0.35732381838962607` vs 기준 `gripSucceed_poseConsistency` grip_succeed=1(성공) 이면 robotTfTranslation 이 workspace 범위 안, grip3dPoseZ 가 [0.01, 0.30] m 안이어야 한다. → 델타 x5=-0.35732381838962607 (기대 >= 0.0) · 프로젝션/파이프라인 오류(좌우 축 반전 또는 프레임 매핑 실패)
- (반려동물용품_CR01_강아지공룡알장난감_00435#2, `grip3dPose` / grip3dPose) 관측 `"x6":-0.3660033997259719` vs 기준 `gripSucceed_poseConsistency` grip_succeed=1(성공) 이면 robotTfTranslation 이 workspace 범위 안, grip3dPoseZ 가 [0.01, 0.30] m 안이어야 한다. → 델타 x6=-0.3660033997259719 (기대 >= 0.0) · 동일 sceneKey 시계열 지속된 projectionOrPipelineFault

### 관찰

- 관자 1차 판정 z 음수 가설은 x/z 혼전된 오류. 실제 이상은 gripSucceed=1 시도의 grip3dPose x 좌표가 음수(-0.2~-0.36m)로 물리적 정합성 위배.
- suddenJump_withinScene 가설은 미제공 이전 시도 데이터이나 현재 Z 평균은 baseline 내.

### 영향 범위

- event_store → grip-result-projector → read_grip_result(grip_3d_pose jsonb) → downstream grasp planner/controller → API version

### 근본원인 — projectionOrPipelineFault

1. 관측: 성공 시도의 3D 포즈 x 좌표가 음수(-0.2~-0.36m) 기록됨.
2. why1: 왜 물리적 정합성 위배(전방 카메라 프레임 기준 양수 위치)로 투영되었는가?
3. why2: 원천 payload 구조(zod) 검증은 통과하나 의미적 값 오류가 발생했음.
4. why3: 프로젝트 매핑(map) 로직이 camera frame 변환 또는 좌우 축 반전 처리를 누락하거나 잘못 적용됨.
5. why4: 왜 이 누락이 감지되지 않았는가?
6. why5: read_grip_result 스키마 level 에 z>=0.01(심도 양수) 및 x/y 합치기 물리적 치기 규칙이 누락되어 zod만 존재.
7. 결정: 구조적 zod만 존재 → 값 이상 판정 부재 → projectionOrPipelineFault.

### 의사결정 기준

- 물리적 정합성 위배 severity
- event_store 원천 보존 가용성
- downstream grasp planner 영향도
- 구현 변경scope 및 유지보수 비용

- 트리거 근거: Seq 22(globalSequence:22) grip3dPose x1..x8 모두 음수(-0.35~-0.22m), z1..z8 양수(~0.14m). Seq 23(globalSequence:23) 동일 패턴. Observer claim 'z 최솟값 -0.357'은 x/z 혼전된 오류. v1 GripResultProjector map() 메서드와 read_grip_result jsonb 스키마에 z>=0.01(심도 양수) 또는 x/y 합 범위 등 물리적 치기 규칙이 누락됨, 따라서 observer 가설이 조용히 투영되어 DB에 기록.
- v1 호환성: v1 테이블(read_grip_result), 라우트(/projection/grip-result), 프로젝터(GripResultProjector)는 완전 무손. 신규 v2 테이블은 동시 존재(coexistence)로 이전 파지 결과 조회 API/DB 스키마 호환성 유지. 컷오버 전 v1 데이터 검증 절차 필요.

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import type { InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripResultV2 } from '@/shared/database/schema/service/read-grip-result-v2';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripResultV2Insert = InferInsertModel<typeof readGripResultV2>;

@Injectable()
export class GripResultV2Projector implements Projector<ReadGripResultV2Insert> {
  readonly name: string = 'grip-result-v2-projector';

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripResultV2Projector.name);
  }

  map(event: EventStoreEventRow): ReadGripResultV2Insert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        '이벤트 매핑(검증) 실패',
      );

      throw error;
    }

    const pose = payload.grip_data.grip_3d_pose;
    const zValues: number[] = [pose.z1, pose.z2, pose.z3, pose.z4, pose.z5, pose.z6, pose.z7, pose.z8];
    const xValues: number[] = [pose.x1, pose.x2, pose.x3, pose.x4, pose.x5, pose.x6, pose.x7, pose.x8];

    const minZDepth: number = Math.min(...zValues);
    const maxXCoord: number = Math.max(...xValues);
    const gripOutlierFlag: number = minZDepth < 0.01 ? 1 : 0;

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ''),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      '이벤트 매핑',
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ''),
      attemptNum: event.attemptNum,
      objectName: payload.objects[0].class_name,
      gripSucceed: payload.grip_succeed,
      occurredAt: event.occurredAt,
      minZDepth,
      maxXCoord,
      gripOutlierFlag,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripResultV2Insert): Promise<void> {
    await tx
      .insert(readGripResultV2)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripResultV2.sceneKey, readGripResultV2.attemptNum],
        set: {
          objectName: row.objectName,
          gripSucceed: row.gripSucceed,
          occurredAt: row.occurredAt,
          minZDepth: row.minZDepth,
          maxXCoord: row.maxXCoord,
          gripOutlierFlag: row.gripOutlierFlag,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```

### 버전 교체 코드 — `src/projection/projection.service.ts` (modifyFile)

```typescript
import { Injectable } from '@nestjs/common';
import { PinoLogger } from 'nestjs-pino';
import { InsertResult, InsertService } from '@/insert/insert.service';
import { GripResultProjector } from '@/projection/projector/grip-result.projector';
import { MultiModalProjector } from '@/projection/projector/multimodal.projector';
import { GripResultV2Projector } from '@/projection/projector/grip-result-v2.projector';
import { ProjectionResult } from '@/projection/projector/projector';
import { CatchUpRunner } from '@/projection/runner/catch-up.runner';
import { LogAction } from '@/shared/logger/logging-context';

export type CatchUpAllResult = {
  multimodal: ProjectionResult;
  gripResult: ProjectionResult;
  gripResultV2: ProjectionResult;
};

export type InsertAndProjectionAllResult = {
  insert: InsertResult;
  projection: CatchUpAllResult;
};

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly gripResultV2: GripResultV2Projector,
    private readonly insertService: InsertService,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  catchUpMultimodal(): Promise<ProjectionResult> {
    return this.runner.run(this.multimodal);
  }

  catchUpGripResult(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResult);
  }

  catchUpGripResultV2(): Promise<ProjectionResult> {
    return this.runner.run(this.gripResultV2);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();
    const gripResultV2: ProjectionResult = await this.catchUpGripResultV2();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult, gripResultV2 };
  }

  async insertAllAndProjectAll(): Promise<InsertAndProjectionAllResult> {
    this.logger.info(
      { action: LogAction.PROJECTION_START },
      "전체 적재+투영 시작",
    );

    const insert: InsertResult = await this.insertService.insertToyData();
    const projection: CatchUpAllResult = await this.catchUpAll();

    this.logger.info(
      { action: LogAction.PROJECTION_DONE },
      "전체 적재+투영 완료",
    );

    return { insert, projection };
  }
}
```
