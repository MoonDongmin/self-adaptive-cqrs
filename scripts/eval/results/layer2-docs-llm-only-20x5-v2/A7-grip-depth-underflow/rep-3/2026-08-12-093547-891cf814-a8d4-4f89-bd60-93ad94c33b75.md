## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 20, `-`) 엔티티 목록 조회 → 시스템의 Entity List 조회 의도 신호가 매분 반복으로 발생하며 Read Model 부재 감지.
- (level 30, `-`) request completed ← 트립 앵커 → 요청 완료 신호 발생이나 LLM 전심 단계에서 HTTP 404 에러(요청 충족 실패)로 판정. [corr:891cf814-a8d4-4f89-bd60-93ad94c33b75]
- Insight 카드 read_grip_result와 read_multimodal은 scene_key/attempt_num 단위로 매핑되어, Entity List 조회 의도(signal)를 충족할 수 있는 aggregation 컬럼(total_attempts, success_count)이 부재. [corr:-]
- ProjectionController의 라우트 패턴에 /projection/multimodal과 /projection/grip-result 엔드포인트만 정의되어, Entity List 조회 요청 시 HTTP 404 에러 발생. [corr:891cf814-a8d4-4f89-bd60-93ad94c33b75]
- GripResultProjector.map()에서 payload.objects[0].class_name을 objectName에 매핑하나, scene별 1:1 투영만 수행하여 Entity List 전산적 집계(cumulative) 로직이 구현되어. [corr:-]

### Decision Drivers
- Read Model 존재성(LLM 전심 의존성)
- 관심 분리(장면별 vs 전산적 집개)
- API 엔드포인트 가용성
- 정격성 규칙 준수

### Considered Options
#### 기존 Read Model 보강 (기각 대안)
- 접근: read_grip_result에 total_attempts, success_count 추가 및 GripResultProjector 수정으로 scene-level aggregation 시도.
- 제안 필드: object_name, total_attempts, success_count
- 트레이드오프: schema 위반(장면별 vs 전산적 집개 혼), 유지보수 비용 증가, LLM 의존성 단절.
```typescript
export class GripResultProjector implements Projector<ReadGripResultInsert> { readonly name = "grip-result-projector"; map(event: EventStoreEventRow): ReadGripResultInsert { const payload = toyDataSchema.parse(event.payload); return { sceneKey: event.streamId.replace(/^grip-attempt:/, ""), attemptNum: event.attemptNum, objectName: payload.objects[0].class_name, gripSucceed: payload.grip_succeed, gripperType: "finger", occurredAt: event.occurredAt, totalAttempts: 1, successCount: payload.grip_succeed, ... }; } async upsert(tx: DrizzleTx, row: ReadGripResultInsert): Promise<void> { await tx.insert(readGripResult).values(row).onConflictDoUpdate({ target: [readGripResult.sceneKey, readGripResult.attemptNum], set: { totalAttempts: readGripResult.totalAttempts + row.totalAttempts, successCount: readGripResult.successCount + row.successCount } }); } }
```

#### 신규 분리 (newReadModel)
- 접근: read_entity_list_v1 테이블 생성, EntityListProjector 구현으로 payload.objects[].class_name 집계 로직 매핑, ProjectionController에 /projection/entity-list 엔드포인트 추가.
- 제안 필드: object_name, total_attempts, success_count, latest_occurred_at
- 트레이드오프: 신규 배포/마이그레이션 비용 발생, 기존 Read Model 무영(무해화), LLM 전심 정지 해결.
```typescript
export class EntityListProjector implements Projector<ReadEntityListInsert> { readonly name = "entity-list-projector"; map(event: EventStoreEventRow): ReadEntityListInsert { const payload = toyDataSchema.parse(event.payload); return { objectName: payload.objects[0].class_name, totalAttempts: 1, successCount: payload.grip_succeed, latestOccurredAt: event.occurredAt, streamId: event.streamId, globalSeq: event.globalSeq }; } async upsert(tx: DrizzleTx, row: ReadEntityListInsert): Promise<void> { await tx.insert(readEntityListV1).values(row).onConflictDoUpdate({ target: [readEntityListV1.objectName], set: { totalAttempts: readEntityListV1.totalAttempts + row.totalAttempts, successCount: readEntityListV1.successCount + row.successCount, latestOccurredAt: row.latestOccurredAt > readEntityListV1.latestOccurredAt ? row.latestOccurredAt : readEntityListV1.latestOccurredAt } }); } }
```

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readEntityList } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';
import { sql } from 'drizzle-orm';

type ReadEntityListInsert = InferInsertModel<typeof readEntityList>;

@Injectable()
export class EntityListProjector implements Projector<ReadEntityListInsert> {
  readonly name: string = "entity-list-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(EntityListProjector.name);
  }

  map(event: EventStoreEventRow): ReadEntityListInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (error) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          error,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw error;
    }

    if (payload.objects.length === 0) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
        },
        "objects 비어 있음",
      );

      throw new Error(`entity-list map: empty objects in event ${event.eventId}`);
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      objectName: payload.objects[0].class_name,
      totalAttempts: 1,
      successCount: payload.grip_succeed,
      latestOccurredAt: event.occurredAt,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadEntityListInsert): Promise<void> {
    await tx
      .insert(readEntityList)
      .values(row)
      .onConflictDoUpdate({
        target: [readEntityList.objectName],
        set: {
          totalAttempts: sql`${readEntityList.totalAttempts} + excluded.total_attempts`,
          successCount: sql`${readEntityList.successCount} + excluded.success_count`,
          latestOccurredAt: sql`CASE WHEN latest_occurred_at IS NULL OR latest_occurred_at < excluded.latest_occurred_at THEN excluded.latest_occurred_at ELSE latest_occurred_at END`,
        },
      });
  }
}
```
