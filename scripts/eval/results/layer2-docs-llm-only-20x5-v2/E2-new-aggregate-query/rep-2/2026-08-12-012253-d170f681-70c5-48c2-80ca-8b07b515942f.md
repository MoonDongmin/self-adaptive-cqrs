### Decision Drivers
- Request specificity (object_name별 집계 요구)
- Existing schema limitation (row-level only)
- Performance vs Storage tradeoff
- Maintenance consistency (decouple aggregation from row projection)

### Considered Options
#### Dedicated Aggregator Projector (newReadModel)
- 접근: 신류 GripResultAggregatedProjector 생성, read_grip_result_aggregated_v1 투영. map()에서 object_name별 attempt_count/ success_count 누적, upsert()로 rate 계산 및 행 갱업.
- 제안 필드: object_name, attempt_count, success_count, success_rate
- 트레이드오프: DB 테이블 추가 및 migration 비용 발생, CPU 소모 증가이나 query latency 0으로 요청 충족. 정합성 검사(checkIntegrity) 병장.
```typescript
export class GripResultAggregatedProjector implements Projector<ReadGripResultAggregatedInsert> { readonly name = "grip-result-aggregated-projector"; map(event: EventStoreEventRow): ReadGripResultAggregatedInsert { const payload = toyDataSchema.parse(event.payload); if (payload.objects.length === 0) throw new Error("empty objects"); return { objectName: payload.objects[0].class_name, attemptCount: 1, successCount: payload.grip_succeed, successRate: Number((payload.grip_succeed / 1).toFixed(4)), }; } async upsert(tx: DrizzleTx, row: ReadGripResultAggregatedInsert): Promise<void> { await tx.insert(readGripResultAggregatedV1).values(row); } }
```

#### Query-time Aggregation via SQL View (versionSwitch alternative)
- 접근: 기존 read_grip_result 그대로 유지, API 레이어에서 GROUP BY 집계 수행.
- 제안 필드: object_name, attempt_count, success_count, success_rate
- 트레이드오프: DB 추가 비용 제로, but query latency 증가, 실시간 일관성 유지 어려움(투영 vs 조회 시점 차이).

### Decision Outcome
Dedicated Aggregator Projector (newReadModel)

### Consequences
- (+) Direct query support
- (+) Decoupled aggregation logic from row projection
- (−) Storage overhead & migration cost
- (−) CPU 소모 증가

### Non-Goals
- Not modifying existing read_grip_result schema
- Not implementing UI layer

- 사유: 기존 v1 GripResultProjector는 payload.objects[0].class_name만 추출하여 row-level 데이터만 저장[corr:d170f681-...]。사용자가 object_name별 집계(시도/성/비율)를 요청하나, 이에 대한 aggregated Insight Card가 미구현되어 insight.card.miss 발생[corr:5852f519-...]。신규 v2 테이블·프로젝터를 추가하여 DB-level aggregation을 지원하며 기존 row-level Read Model은 무손상 유지.
- 트리거 근거: | 16:22:53.243 | 40 | insight.card.miss | d170f681-70c5-48c2-80ca-8b07b515942f | - | - | - | insight 카드 없음: 객체(object_name)별 파지 성공률을 한 번에 조회하고 싶다. 시도 수, 성공 수, 성공률이 필요하다. ← 트립 앵커 |
- v1 호환성: 기존 read_grip_result 테이블·프로젝터·라우트·DI를 완전히 보존[corr:d170f681-...]。신규 v2 aggregation은 additive-only 변경으로 기존 API/DB 호환성 유지.

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import type { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripResultAggregated } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';
import { sql } from 'drizzle-orm';

type ReadGripResultAggregatedInsert = InferInsertModel<typeof readGripResultAggregated>;

@Injectable()
export class GripResultAggregatedProjector implements Projector<ReadGripResultAggregatedInsert> {
  readonly name: string = "grip-result-aggregated-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripResultAggregatedProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripResultAggregatedInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (err) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          err,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw err;
    }

    if (payload.objects.length === 0) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
        },
        "objects 비어 있음",
      );

      throw new Error(
        `grip-result-aggregated map: empty objects in event ${event.eventId}`,
      );
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    const objectName = payload.objects[0].class_name;
    const successCount = payload.grip_succeed;

    return {
      objectName,
      attemptCount: 1,
      successCount,
      // 초기값은 0.0, 실제 값은 upsert에서 계산
      successRate: 0.0,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripResultAggregatedInsert): Promise<void> {
    await tx
      .insert(readGripResultAggregated)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripResultAggregated.objectName],
        set: {
          attemptCount: sql`${readGripResultAggregated.attemptCount} + excluded.attemptCount`,
          successCount: sql`${readGripResultAggregated.successCount} + excluded.successCount`,
          successRate: sql`(success_count + ${row.successCount}) / (attempt_count + ${row.attemptCount})`,
        },
      });
  }
}
```
