## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 40, `payload.schema.drift`) payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) ← 트립 앵커 → 기존 Read Model이 신규 키를 처리할 수 없어 데이터 유실이 발생하고 있음을 드러냄. [corr:742b2850-c491-4c0d-a568-c34464912c85]
- `read_grip_result.object_name`은 payload.objects[0].class_name에서 가져오며, 이는 정상적으로 매핑되고 있음. 그러나 `read_multimodal.image_2d_uri`는 현재 null로 설정되어 있어, 신규 키에 대한 정보가 누락됨. (multimodal.projector.ts에서 image2dUri를 null로 둠)
- `read_grip_result.gripper_temperature`와 `read_grip_result.conveyor_speed`는 신규 Read Model인 `read_grip_drift_result`에 추가되어야 하며, 이는 기존 Read Model에서는 처리되지 않음.

### Decision Drivers
- 신규 키 유입에 대한 처리 필요
- 기존 Read Model의 한계
- 데이터 유실 방지

### Considered Options
#### 신규 Read Model `read_grip_drift_result` 채택
- 접근: `multimodal.projector.ts`에서 신규 Read Model로의 매핑 추가
- 제안 필드: read_grip_drift_result.object_name, read_grip_drift_result.conveyor_speed, read_grip_drift_result.gripper_temperature
- 트레이드오프: 기존 Read Model을 수정하는 것보다 신규 Read Model을 생성하는 것이 더 안전하고, 향후 유지보수에 유리함.
```typescript
return { object_name: payload.objects[0].class_name, conveyor_speed: payload.conveyor_speed, gripper_temperature: payload.gripper_temperature, occurred_at: event.occurredAt, stream_id: event.streamId, global_seq: event.globalSeq, }
```

### Decision Outcome
신규 Read Model `read_grip_drift_result` 채택 — 신규 키 유입에 대한 요구를 충족하기 위해 필요.

### Consequences
- (+) 신규 키에 대한 데이터 유실 방지
- (+) Read Model의 확장성 증가
- (−) 기존 시스템에 대한 추가적인 유지보수 필요

### Non-Goals
- 기존 Read Model의 구조 변경
- 기존 데이터의 손실
