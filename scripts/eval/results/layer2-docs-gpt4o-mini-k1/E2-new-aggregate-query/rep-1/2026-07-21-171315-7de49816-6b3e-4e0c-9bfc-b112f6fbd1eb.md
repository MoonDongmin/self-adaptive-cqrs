## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 40, `insight.card.miss`) insight 카드 없음: 객체(object_name)별 파지 성공률을 한 번에 조회하고 싶다. 시도 수, 성공 수, 성공률이 필요하다. → 기존 Read Model인 read_grip_result는 객체별 파지 성공률을 조회할 수 있는 구조적 부족이 있다. [corr:7de49816-6b3e-4e0c-9bfc-b112f6fbd1eb]
- read_grip_result 모델은 object_name, total_attempts, successful_attempts, success_rate 컬럼이 없다.
- GripResultProjector의 map() 메서드에서 payload.objects[0].class_name을 사용하여 object_name을 설정하고 있으나, 성공률을 계산할 수 있는 필드가 없다. (src/projection/projector/grip-result.projector.ts)
- read_grip_result 테이블은 파지 성공 여부(grip_succeed)만을 저장하고 있으며, 총 시도 수와 성공 수를 집계할 수 있는 구조가 아니다.

### Decision Drivers
- 기존 Read Model의 구조적 부족 해결
- 사용자 요구 충족
- 데이터 분석 용이성

### Considered Options
#### 신규 Read Model 생성
- 접근: read_object_success_rate 테이블 생성
- 제안 필드: object_name, total_attempts, successful_attempts, success_rate, occurred_at
- 트레이드오프: 기존 Read Model을 보강하는 대신 새로운 테이블을 생성하여 데이터 집계 및 조회를 용이하게 한다.
```typescript
return { object_name: payload.objects[0].class_name, total_attempts: 1, successful_attempts: payload.grip_succeed, success_rate: payload.grip_succeed ? 1 : 0, occurred_at: event.occurredAt, };
```

#### 기존 Read Model 수정
- 접근: read_grip_result 모델 수정
- 제안 필드: total_attempts, successful_attempts, success_rate
- 트레이드오프: 기존 모델의 구조를 변경하여 데이터의 일관성을 유지할 수 있지만, 기존 데이터와의 호환성 문제 발생 가능.
```typescript
await tx.insert(read_grip_result).values(row).onConflictDoUpdate({ target: [read_grip_result.sceneKey, read_grip_result.attemptNum], set: { total_attempts: row.total_attempts, successful_attempts: row.successful_attempts, success_rate: row.success_rate, }, });
```

### Decision Outcome
신규 Read Model인 read_object_success_rate의 채택 — 기존 Read Model의 구조적 부족을 해결하고, 객체별 파지 성공률을 효율적으로 조회할 수 있는 방법이기 때문.

### Consequences
- (+) 새로운 Read Model을 통해 객체별 파지 성공률을 쉽게 조회할 수 있으며, 데이터 분석이 용이해진다.
- (−) 기존 시스템과의 통합 및 데이터 마이그레이션이 필요할 수 있다.

### Non-Goals
- 기존 read_grip_result 모델의 데이터 구조 변경은 포함하지 않는다.

```ts
import { read_object_success_rate } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadObjectSuccessRateInsert = InferInsertModel<typeof read_object_success_rate>;

@Injectable()
export class ObjectSuccessRateProjector implements Projector<ReadObjectSuccessRateInsert> {
  readonly name: string = "object-success-rate-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(ObjectSuccessRateProjector.name);
  }

  map(event: EventStoreEventRow): ReadObjectSuccessRateInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (err) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          err,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw err;
    }

    const objectName = payload.objects[0].class_name;
    const gripSucceed = payload.grip_succeed;

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      objectName: objectName,
      totalAttempts: 1,
      successfulAttempts: gripSucceed,
      successRate: gripSucceed * 100,
      occurredAt: event.occurredAt,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadObjectSuccessRateInsert): Promise<void> {
    await tx
      .insert(read_object_success_rate)
      .values(row)
      .onConflictDoUpdate({
        target: [read_object_success_rate.objectName],
        set: {
          totalAttempts: sql`${read_object_success_rate.totalAttempts} + 1`,
          successfulAttempts: sql`${read_object_success_rate.successfulAttempts} + ${row.successfulAttempts}`,
          successRate: sql`(${read_object_success_rate.successfulAttempts} + ${row.successfulAttempts}) * 100 / (${read_object_success_rate.totalAttempts} + 1)`,
        },
      });
  }

```

```typescript
import { ObjectSuccessRateProjector } from '@/projection/projector/object-success-rate.projector';

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly objectSuccessRate: ObjectSuccessRateProjector,
    private readonly insertService: InsertService,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  async catchUpObjectSuccessRate(): Promise<ProjectionResult> {
    return this.runner.run(this.objectSuccessRate);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();
    const objectSuccessRate: ProjectionResult = await this.catchUpObjectSuccessRate();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult, objectSuccessRate };
  }
}
```
