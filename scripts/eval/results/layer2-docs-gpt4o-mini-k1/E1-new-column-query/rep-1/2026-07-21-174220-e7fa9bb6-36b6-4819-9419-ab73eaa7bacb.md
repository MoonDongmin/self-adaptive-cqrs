## 1. 권고 (Recommendation)

### Status
proposed

### Context (근거)
- (level 40, `payload.schema.drift`) payload 에 스키마가 모르는 신규 키 유입 — 적재 시 유실됨(Read Model 후보) ← 트립 앵커 → gripper_temperature 필드가 Read Model에 존재하지 않음을 드러냄 [corr:e7fa9bb6-36b6-4819-9419-ab73eaa7bacb]
- Insight 카드의 read_grip_result 테이블에서 gripper_temperature 필드가 현재 null로 존재하지 않음.
- 기존 구현 소스인 GripResultProjector의 map() 메서드에서 gripper_temperature를 처리하지 않음. (src/projection/projector/grip-result.projector.ts)
- Insight 카드에서 사용자가 gripper_temperature 필드를 시간대별로 조회하고 싶어했으나, 해당 필드가 Read Model에 존재하지 않아 조회 요청이 실패함.

### Decision Drivers
- 사용자의 요구 충족
- 기존 Read Model과의 호환성
- 데이터베이스 구조 변경 최소화

### Considered Options
#### 신규 Read Model 생성
- 접근: read_grip_temperature 테이블을 생성하여 gripper_temperature 필드를 추가
- 제안 필드: scene_key, attempt_num, gripper_temperature, occurred_at, stream_id, global_seq
- 트레이드오프: 신규 Read Model 생성으로 인해 데이터베이스 구조가 변경되며, 기존 API와의 호환성 문제를 해결해야 함.
```typescript
return {
  sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
  attemptNum: event.attemptNum,
  gripperTemperature: payload.gripper_temperature, // 신규 필드 추가
  occurredAt: event.occurredAt,
  streamId: event.streamId,
  globalSeq: event.globalSeq,
};
```

### Decision Outcome
신규 Read Model 생성 — gripper_temperature 필드를 추가하여 사용자의 요구를 충족할 수 있음.

### Consequences
- (+) 사용자의 요구를 충족하여 데이터 조회 가능
- (+) Read Model의 유연성 증가
- (−) 기존 API와의 호환성 문제 발생 가능성
- (−) 데이터베이스 구조 변경에 따른 리스크

### Non-Goals
- 기존 Read Model의 구조 변경
- 기존 API의 기능 변경

### 신규 Read Model — Projector

```ts
import { Injectable } from '@nestjs/common';
import { type InferInsertModel } from 'drizzle-orm';
import { PinoLogger } from 'nestjs-pino';
import { type ToyDataDto, toyDataSchema } from '@/insert/dto/toy-data.dto';
import { Projector } from '@/projection/projector/projector';
import type { EventStoreEventRow } from '@/projection/repository/event-store-reader.repository';
import { DrizzleTx } from '@/shared/database/drizzle.provider';
import { readGripTemperature } from '@/shared/database/schema';
import { LogAction, LogContext } from '@/shared/logger/logging-context';

type ReadGripTemperatureInsert = InferInsertModel<typeof readGripTemperature>;

@Injectable()
export class GripTemperatureProjector implements Projector<ReadGripTemperatureInsert> {
  readonly name: string = "grip-temperature-projector";

  constructor(private readonly logger: PinoLogger) {
    this.logger.setContext(GripTemperatureProjector.name);
  }

  map(event: EventStoreEventRow): ReadGripTemperatureInsert {
    let payload: ToyDataDto;
    try {
      payload = toyDataSchema.parse(event.payload);
    } catch (err) {
      this.logger.error(
        {
          action: LogAction.MAP_FAILED,
          err,
          [LogContext.EVENT_ID]: event.eventId,
          [LogContext.STREAM_ID]: event.streamId,
          [LogContext.ATTEMPT_NUM]: event.attemptNum,
          [LogContext.GLOBAL_SEQ]: event.globalSeq,
        },
        "이벤트 매핑(검증) 실패",
      );

      throw err;
    }

    this.logger.debug(
      {
        action: LogAction.EVENT_MAPPED,
        [LogContext.PROJECTOR_NAME]: this.name,
        [LogContext.SCENE_KEY]: event.streamId.replace(/^grip-attempt:/, ""),
        [LogContext.ATTEMPT_NUM]: event.attemptNum,
        [LogContext.GLOBAL_SEQ]: event.globalSeq,
      },
      "이벤트 매핑",
    );

    return {
      sceneKey: event.streamId.replace(/^grip-attempt:/, ""),
      attemptNum: event.attemptNum,
      gripperTemperature: { value: payload.gripper_temperature },
      occurredAt: event.occurredAt,
      streamId: event.streamId,
      globalSeq: event.globalSeq,
    };
  }

  async upsert(tx: DrizzleTx, row: ReadGripTemperatureInsert): Promise<void> {
    await tx
      .insert(readGripTemperature)
      .values(row)
      .onConflictDoUpdate({
        target: [readGripTemperature.sceneKey, readGripTemperature.attemptNum],
        set: {
          gripperTemperature: row.gripperTemperature,
          occurredAt: row.occurredAt,
          streamId: row.streamId,
          globalSeq: row.globalSeq,
        },
      });
  }
}
```

```typescript
import { GripTemperatureProjector } from '@/projection/projector/grip-temperature.projector';

@Injectable()
export class ProjectionService {
  constructor(
    private readonly logger: PinoLogger,
    private readonly runner: CatchUpRunner,
    private readonly multimodal: MultiModalProjector,
    private readonly gripResult: GripResultProjector,
    private readonly gripTemperature: GripTemperatureProjector,
    private readonly insertService: InsertService,
  ) {
    this.logger.setContext(ProjectionService.name);
  }

  catchUpGripTemperature(): Promise<ProjectionResult> {
    return this.runner.run(this.gripTemperature);
  }

  async catchUpAll(): Promise<CatchUpAllResult> {
    this.logger.info({ action: LogAction.PROJECTION_START }, "전체 투영 시작");

    const multimodal: ProjectionResult = await this.catchUpMultimodal();
    const gripResult: ProjectionResult = await this.catchUpGripResult();
    const gripTemperature: ProjectionResult = await this.catchUpGripTemperature();

    this.logger.info({ action: LogAction.PROJECTION_DONE }, "전체 투영 완료");

    return { multimodal, gripResult, gripTemperature };
  }
}
```
